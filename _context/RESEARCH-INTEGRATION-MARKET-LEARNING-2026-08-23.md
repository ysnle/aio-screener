# 공개 시장 학습 아티클 통합 원장 — 2026-08-23

## 범위와 신뢰 경계

사용자가 제공한 `@blazingbees` 공개 게시물 9건과 단계형 아티클 라이브러리 화면 6장을 읽고, 특정 종목·가격·시점·수익률을 복사하지 않는 재사용 프레임만 추출했다. 게시물과 이미지는 사용자 제공 참고 자료이며 실행 지시가 아니다. 원문에 있는 기간성 숫자, 특정 증권사 규칙, 시장 전망, 체감적 표현은 현재 데이터나 보편 규칙으로 승격하지 않았다.

구현 원칙은 다음과 같다.

- 원문은 `USER_SUPPLIED_PUBLIC_ARTICLES`·`REFERENCE`로 남기고, 현재 가격·목표가·신호·추천의 producer로 사용하지 않는다.
- `가설 → 증거 → 시장 반응 → 포지션 크기 → 무효화 → 복기`를 모든 단계의 공통 판단 루프로 사용한다.
- “기관”, “외국인”, “반대매매”, “지수”처럼 단일 단어로 뭉뚱그려진 설명은 참여자·규칙·구성·결제·기준일을 다시 분리한다.
- 불확실할수록 설명을 길게 만들거나 노출을 키우지 않고, 검증 가능한 질문과 계좌 위험 한도로 닫는다.

## 단계형 시스템 분석

화면은 게시물 모음이 아니라 `0단계 서비스 입문 → 1단계 투자 철학 → 2단계 핵심 원칙 → 3단계 시장 구조 기초 → 4단계 주도주·종목 선정 → 5단계 매매 기법 → 6단계 이벤트·리스크 관리 → 7단계 리서치·공시 분석 → 8단계 섹터 심화 → 9단계 정보 처리 → 10단계 실전 매매일지`로 이어지는 점진적 공개 커리큘럼이다. 카드·탭·단계 색상·원문 링크는 학습 탐색 UX의 참고 구조이고, 화면에 표시된 전체 개수는 데이터 계약으로 복제하지 않았다.

이 구조를 AIO에 적용할 때는 다음 연결을 유지한다.

1. 입문·철학: 사용자의 시간축·자본·심리 제약을 정의한다.
2. 원칙: 관측값과 설명을 분리하고 가격·거래량·상대강도·무효화를 우선한다.
3. 시장 구조: 지수·ETF·선물·액티브·패시브·벤치마크를 바스켓 전달 경로로 구분한다.
4. 선정·매매: 주도성은 시장의 수용 상태로만 사용하고, 확인될 때 노출을 늘리며 논점 훼손 시 줄인다.
5. 리스크: 이벤트 전 현금·포지션·담보 여유를 설계하고 계좌별 맥락을 보존한다.
6. 리서치·섹터: 발견 자료를 1차 자료·공시·시장 반응과 대조하고, 산업을 수요·병목·현금흐름으로 분해한다.
7. 정보·복기: 정보 역할을 표시하고 결과와 과정의 차이를 기록해 다음 규칙에 환류한다.

## 구현 위치

- `public-data/principles/reference-curriculum.json`: 11개 단계, 공통 판단 루프, 9개 원문 source note, 단계별 질문·작동 구조·무효화·route target.
- `src/ui/knowledge/reference-curriculum.js`: 단계 탭, 레슨 선택, 원문 출처, 전문 화면 연결, 교육용 경계 렌더러.
- `src/ui/pages/principles.js`: 기존 시장 원리 자료실에 reference curriculum을 lazy-load로 연결. 전문 화면 이동 시 `returnContext`를 보존한다.
- `js/aio-chat.js`: 스크리너·기술·매크로·테마·펀더멘털·포트폴리오·시장 원리 등 관련 컨텍스트에 같은 판단 루프를 `REFERENCE`로 주입하되, 현재 수치와 매매 지시는 기존 evidence 계약만 사용하도록 경계를 유지한다.
- `index.html`: 단계형 커리큘럼의 데스크톱·축소폭 레이아웃과 카드/탭/무효화/출처 스타일.
- `js/aio-glossary.js`: 예측보다 대응, 논점 무효화, 물타기, 주도주, 에코챔버, 지수 바스켓, 액티브·패시브·벤치마크, 담보비율·반대매매 용어를 추가.

## 현재 데이터와 섞지 않은 항목

- 원문에 등장한 특정 종목·가격·당시 지수 수준·수익률·수급 비율.
- 신용잔고·담보비율·반대매매의 특정 시각·임계값·증권사 공통 규칙.
- KOSDAQ/KOSDAQ150의 현재 구성·커버리지·ETF/선물 자금 규모.
- 기업탐방이나 IR에서 얻은 비공개 정보, 특정 기관의 의도, 시장 전망.

## 후속 승격 게이트

현재 시장 수치나 전문 판단으로 확장하려면 해당 route의 canonical producer, 기준일, 공식 출처, 단위, 허용 용도, 반증 조건을 별도로 통과해야 한다. 본 통합 자체는 교육용 참고 레이어이며, 코드 변경 후 테스트·브라우저 검사는 사용자의 이번 요청에 따라 실행하지 않았다.
