## 0. 이번 설계의 핵심 결정

신규 1번 페이지는 단순한 투자 입문서나 긴 칼럼이 아니다. AIO 전체에서 반복 사용되는 **개념의 기준점(canonical concept hub)** 으로 만든다.

- 사이드바 라벨 권장안: **시장 원리**
- 페이지 브랜드 타이틀 권장안: **자본의 지도**
- 한 줄 설명: **돈은 어디서 만들어지고, 어디로 흐르며, 누가 이익을 얻는가**
- 내부 route 후보: `principles` 또는 `academy`
- 기본 독자: 투자 초보자이지만, 심화 전환 시 기존 투자자도 참고 가능한 수준
- 핵심 역할: 기존 전문 페이지의 숫자·차트·신호를 이해하기 위한 정신모형과 산업 구조 제공
- 비역할: 실시간 시황, 종목 추천, 가격 전망, 매매 신호, 테마 수익률 순위의 중복 제공

### 0-1. 사용자가 제기한 중복 문제에 대한 결론

**엔캐리, 미국채 금리의 중요성, 반도체 가치사슬을 이 페이지에도 넣는 것이 맞다.** 다만 기존 페이지와 동일한 내용을 복사하지 않는다.

| 주제 | 시장 원리 페이지의 역할 | 기존 전문 페이지의 역할 |
|---|---|---|
| 미국채 금리 | 왜 무위험금리가 모든 자산의 기준이 되는지, 할인율·기회비용·담보·달러 유동성 연결 설명 | 현재 2Y·10Y·30Y, 수익률 곡선, MOVE, 스프레드, 당일 변화 확인 |
| 엔캐리 | 저금리 통화 차입→고수익 자산 투자→환율/변동성 충격→포지션 축소의 구조 설명 | 현재 USD/JPY, 금리차, VIX/HYG 등 관찰 프록시와 위험 상태 확인 |
| 반도체 | 원재료→장비→설계→제조→메모리→패키징→서버→데이터센터로 이어지는 산업 구조와 병목 설명 | 현재 테마 강도, RRG, 종목 퍼포먼스, 뉴스, 주도/부진 기업 확인 |
| 전력 | 발전→송전→변전→배전→저장→수요자의 물리 흐름과 규제/투자 구조 설명 | 현재 전력·원전·그리드 테마의 가격·뉴스·종목 흐름 확인 |
| 인플레이션 | 화폐 구매력, 수요/공급, 임금, 기대, 재정·통화의 원리 설명 | 현재 CPI/PCE/임금/유가/금리 수치 확인 |

한 문장으로 정리하면 다음과 같다.

> **시장 원리 페이지는 “왜 그런가”를 가르치고, 기존 전문 페이지는 “지금 실제로 어떤가”를 보여준다.**

### 0-2. 중복을 막는 단일 소유권 원칙

1. 긴 개념 설명의 canonical owner는 `시장 원리` 페이지다.
2. 현재값·차트·시그널의 canonical owner는 각 전문 페이지다.
3. 한 문장 정의의 canonical owner는 `용어 사전`이다.
4. 기존 페이지의 교육 블록은 2~4문장 요약+`시장 원리에서 자세히 보기` 링크만 유지한다.
5. 동일 문단을 여러 페이지에 복사하지 않는다.
6. 시장 원리에서 전문 페이지로 `현재 데이터로 확인` CTA를 제공한다.
7. 전문 페이지에서 시장 원리의 대응 lesson으로 `원리 이해하기` 역링크를 제공한다.

## 1. 기존 교육 설계와의 관계

`FABLE-EDU-OVERHAUL-DESIGN-2026-07-09.md`는 각 전문 페이지에 E1 개념/E2 원리/E5 실전 적용을 넣기 위한 설계였고, 이후 `AIO_PAGE_FUNDAMENTALS`로 구현된 상태다. 신규 페이지는 이를 폐기하는 것이 아니라 상위 교육 체계로 재구성한다.

### 유지

- 불변 원리와 현재 시장 데이터를 분리하는 R291 취지
- 정적 교육 콘텐츠에 현재 레벨·날짜·방향 단정문을 넣지 않는 원칙
- 페이지별 `concept / why / how / action / terms` 구조
- 용어 사전 연결

### 변경

- 기존 2~4문장 교육 블록만으로는 자본주의·금융시스템·산업 가치사슬을 충분히 설명할 수 없다.
- 전문 페이지의 교육 블록은 “빠른 이해” 역할로 축소한다.
- 상세 원고와 시각적 관계도는 신규 시장 원리 페이지가 소유한다.
- 기존 `guide` 페이지는 제품 사용 설명서로 정리하고 투자 배경지식 장문은 신규 페이지로 이관한다.

### 금지

- 기존 교육 블록 20개를 그대로 합쳐 거대한 문서로 만드는 방식
- 전문 페이지의 현재 수치나 정적 스냅샷을 시장 원리 페이지에 복제하는 방식
- 테마/트렌드의 종목 랭킹을 시장 원리 페이지에 재구현하는 방식
- 모든 내용을 한 번에 펼치는 무한 스크롤

## 2. 사용자와 학습 목표

### 2-1. 주요 사용자

1. **완전 초보자**
   - 주식이 기업의 소유권이라는 개념부터 필요하다.
   - 금리·채권·달러·반도체가 왜 한 시장에서 연결되는지 모른다.
   - 어려운 단어보다 생활 비유와 인과 흐름이 필요하다.

2. **단편 지식 보유자**
   - CPI, 10년물, HBM 같은 단어는 알지만 서로 어떻게 연결되는지 모른다.
   - 뉴스마다 판단이 흔들리며 하나의 세계관이 없다.

3. **실전 중심 사용자**
   - 기존 AIO 페이지에서 지표를 보지만 지표의 의미와 한계를 복습하고 싶다.
   - 특정 섹터의 구조·병목·기업 역할을 빠르게 확인하고 싶다.

4. **심화 사용자**
   - 개념 정의보다 이익 풀, 가격 결정력, CAPEX, 공급 탄력성, 산업 주기 연결이 필요하다.

### 2-2. 완료 후 사용자가 답할 수 있어야 하는 질문

- 돈의 구매력은 왜 변하는가?
- 금리는 왜 돈의 가격이자 자산가격의 중력인가?
- 중앙은행이 금리를 바꾸면 어떤 경로로 실물경제와 주식에 영향을 주는가?
- 채권 가격과 금리는 왜 반대로 움직이는가?
- 미국채와 달러가 왜 세계 금융의 기준인가?
- 기업은 왜 주식을 발행하고 투자자는 무엇을 소유하는가?
- 주가가 실적과 다르게 움직이는 이유는 무엇인가?
- 유동성, 이익, 밸류에이션은 각각 주가에 어떤 역할을 하는가?
- 한 산업의 돈 흐름과 병목을 어떻게 찾는가?
- AI 수요가 왜 반도체·네트워크·냉각·전력망 수요로 연결되는가?
- 반도체 산업에서 설계·장비·파운드리·메모리·패키징 기업은 무엇이 다른가?
- 가격 상승과 실제 가치 창출을 어떻게 구분하는가?
- 투자 가설과 사실, 현재 관찰을 어떻게 구분하는가?
- 시장 원리를 기존 AIO의 어떤 페이지에서 실측할 수 있는가?

## 4. 전체 개념 지도

페이지의 핵심 경쟁력은 개념의 수보다 **연결 관계**다. 다음 관계를 그래프의 고정 뼈대로 사용한다.

```text
생산성·인구·자원·제도
        ↓
     경제 성장
        ↓
소득·기업이익·세수·재정여력
        ↓
소비·저축·투자·정부지출
        ↓
은행 신용·채권·주식·직접투자
        ↓
공장·기술·인프라·고용·공급능력
        ↓
가격·임금·물가·자산가치
        ↓
중앙은행·정부 정책과 다시 연결
```

보조 연결망:

```text
AI 수요
  → 컴퓨팅 수요
  → GPU/ASIC
  → HBM/패키징/네트워크
  → 데이터센터
  → 냉각·변압기·송전망·발전
  → 원자재·토지·인력·규제
  → CAPEX·자금조달
  → 금리·채권·현금흐름
```

```text
인플레이션 상승
  → 실질 구매력 하락
  → 중앙은행 긴축 기대
  → 단기금리·채권금리 변화
  → 할인율·달러·신용비용 변화
  → 주식 밸류에이션·주택·투자 변화
  → 수요 둔화 또는 공급 확대
  → 다시 물가에 영향
```

```text
엔화 저금리
  → 엔화 차입
  → 해외 고수익 자산 투자
  → 레버리지 축적
  → 일본 금리 상승/엔화 급등/변동성 확대
  → 환헤지 비용·마진 압력
  → 포지션 축소
  → 글로벌 위험자산 매도 가능성
```

## 5. 상세 커리큘럼

아래는 최대 범위의 전체 설계다. MVP에서는 ★ 표시 chapter를 우선 구현한다.

### A. 세상을 보는 출발점 ★

#### A1. 희소성과 선택
- 자원은 유한하고 욕구는 많다는 경제의 출발점
- 기회비용
- 가격이 정보와 유인을 전달하는 방식
- 효율성과 형평성의 충돌
- 시장 실패와 정부 실패

#### A2. 생산성과 부
- 노동·자본·기술·제도의 역할
- 생산성이 임금과 생활수준에 미치는 영향
- 명목 성장과 실질 성장
- 한 국가가 부유해지는 과정
- 생산성 향상과 자산 소유의 관계

#### A3. 자본주의의 엔진
- 사유재산, 계약, 이윤, 경쟁
- 자본 축적과 재투자
- 파산과 구조조정이 갖는 기능
- 독점·규제·외부효과
- 자본주의가 효율적이지만 공평하지 않을 수 있는 이유

#### A4. 경제주체의 순환
- 가계: 노동·소비·저축·투자
- 기업: 고용·생산·이익·CAPEX
- 정부: 세금·지출·규제·이전
- 금융기관: 저축을 대출과 투자로 연결
- 해외: 무역·환율·자본 흐름

### B. 돈과 구매력 ★

#### B1. 돈이란 무엇인가
- 교환수단, 회계단위, 가치저장
- 현금·예금·지급결제의 차이
- 법정화폐와 신뢰
- 통화량과 유동성의 차이
- 돈이 자산이지만 생산적 자산은 아닌 이유

#### B2. 인플레이션과 디플레이션
- 가격 수준과 물가상승률
- 수요견인·비용상승·통화/재정 요인
- 헤드라인·근원 물가
- 상품·서비스·자산 인플레이션 구분
- 디스인플레이션과 디플레이션 구분
- 물가의 관성과 기대 인플레이션

#### B3. 구매력
- 명목금액과 실질가치
- 개인별 체감물가가 다른 이유
- 실질임금
- 실질수익률
- 현금 보유가 갖는 장점과 비용

#### B4. 복리와 시간
- 단리와 복리
- 수익률 순서 위험
- 손실의 비대칭: -50% 후 +100% 필요
- 인플레이션을 차감한 복리
- 비용·세금·수수료의 장기 효과

### C. 신용·은행·부채 ★

#### C1. 신용은 미래 소득의 현재화
- 빌리는 사람과 빌려주는 사람
- 원금·이자·만기·담보
- 신용위험과 위험 프리미엄
- 만기 변환
- 신용이 성장과 위기를 모두 확대하는 이유

#### C2. 은행의 역할
- 예금과 대출
- 은행의 자산·부채 구조
- 대출이 통화와 수요를 확대하는 경로
- 지급준비·자본규제의 개념

## 6. 모든 레슨의 공통 콘텐츠 템플릿

### 필수 필드

1. `question`: 사용자가 실제로 묻는 질문
2. `answer30s`: 2~4문장 핵심 답변
3. `analogy`: 생활 비유
4. `mechanism`: 3~7단계 작동 순서
5. `diagram`: 노드/엣지 정의
6. `example`: 역사적 또는 구조적 사례
7. `counterexample`: 언제 작동하지 않거나 반대로 보이는가
8. `investorLens`: 투자자가 확인할 항목
9. `relatedLessons`: 선수/후속 개념
10. `relatedRoutes`: 기존 AIO 전문 페이지
11. `terms`: 용어사전 키
12. `sources`: 출처, 발행/접근일
13. `reviewedAt`: 마지막 내용 검토일
14. `contentKind`: PRINCIPLE / OBSERVATION / THESIS / CAUTION
15. `level`: BEGINNER / INTERMEDIATE / ADVANCED

### 문장 구조

```text
질문 → 한 줄 답 → 비유 → 작동 순서 → 그림 → 실제 사례 → 반례 → 현재 데이터로 확인
```

### 난이도 표현

- 기본 화면은 `입문`만 보인다.
- `한 단계 더`를 누르면 중급 설명이 열린다.
- 수식·회계·시장 미시구조는 `심화`에서만 제공한다.
- 초보자 문장과 전문가 문장을 한 문단에 섞지 않는다.

### 사실·관점 라벨

- `원리`: 검증 가능한 일반 메커니즘
- `역사 사례`: 날짜와 출처가 있는 과거 사례
- `현재 관찰`: 실시간/최근 데이터의 기준일 필수
- `가설`: 저자의 해석이며 반대 증거 동반
- `주의`: 과잉 단순화·오해·데이터 한계

Desktop:

```text
┌─ chapter rail 220px ─┬─ article 760~820px ─────────────┐
│ 이전/현재/다음 lesson │ breadcrumb                      │
│ 선수 개념             │ 질문형 제목                     │
```

Mobile:

- chapter rail은 상단 드롭다운 또는 drawer

## 8. 산업 가치사슬 노드의 기업 표시 원칙

기업 목록은 추천 리스트가 아니라 **역할 예시**다.

### 각 기업 레코드에 필요한 정보

- 회사명
- ticker 또는 `private/unlisted`
- 국가
- 가치사슬 node
- 실제 역할 1문장
- 수익모델
- 주요 고객군
- 대체 가능성/집중도
- 공개기업 여부
- 확인 출처
- 검토일

### 표시 규칙

- `대표기업`이 아니라 `역할 예시`라고 표시한다.
- 시총·주가·현재 순위는 시장 원리 페이지에서 제공하지 않는다.
- 비상장 기업을 유사 ticker에 매핑하지 않는다(R11).
- 모회사/자회사/사업부를 구분한다(R12).
- 동일 회사가 여러 node에 걸치면 primary role과 secondary role을 분리한다.
- 회사별 투자 판단 대신 산업 내 역할과 협상력을 설명한다.
- 기업 목록은 반기 또는 구조 변화 시 검토한다.

| 불변 원리 | 복리, 채권 가격-금리 관계, 주식 소유권 | 연 1회 검토 또는 오류 발견 시 |
| 제도/규칙 | 거래제도, 세금, 중앙은행 체계 | 제도 변경 시 + 반기 검토 |
| 산업 구조 | 반도체·전력 가치사슬 | 반기 검토 또는 구조적 사건 발생 시 |
| 기업 역할 | 가치사슬별 회사 목록 | 분기~반기 |
| 역사 사례 | 금융위기, 인플레이션 사례 | 출처 오류 시 또는 더 좋은 사례 추가 시 |
| 현재 관찰 | 현재 병목·CAPEX·정책 | 가능하면 전문 페이지로 넘기고, 포함 시 기준일+분기 검토 |
| 출처 링크 | 공식 문서 URL | 반기 link check |

### 설계상 권장

- MVP의 본문은 `PRINCIPLE`과 `HISTORICAL_CASE` 중심으로 구성한다.
- `CURRENT_OBSERVATION`은 최소화한다.
- 현재 시장 연결은 수치를 복제하지 않고 전문 페이지 CTA로 해결한다.
- 이 방식이면 최초 구축 후 간헐적 업데이트만 필요하다.

## 11. 원문 DOCX를 콘텐츠로 전환하는 규칙

원문은 서사적 출발점으로 사용하되 그대로 게시하지 않는다.

### 유지할 강점

- 로또·10만원·예금 같은 생활 질문에서 출발
- `금리는 돈의 가격` 같은 직관적 표현
- 돈의 흐름을 금리·채권·달러·주식으로 연결
- AI→데이터센터→반도체→전력이라는 물리적 연결
- 리스크 관리를 생존 구조로 설명

### 구조적으로 분리할 내용

- 불변 원리와 현재 시장 평가
- 사실과 필자 의견
- 투자 필요성과 주식 투자 권유
- AI의 장기 생산성 가설과 현재 기업 수익성
- 유동성 설명과 특정 중소형주 상승 원인 추정

### 문장 교정 원칙

- `앞으로 물가는 계속 오른다` → 물가가 장기적으로 상승해 온 이유와 반대 사례를 함께 설명
- `주식을 해야 한다` → 생산적 자산 보유의 의미와 주식이 적합하지 않을 수 있는 조건을 병행
- `현재 시장은 AI 하나로 설명된다` → AI 관련 자본지출이 중요한 축이라는 가설과 다른 이익/유동성 요인을 병행
- `미국채 신뢰가 흔들린다` → 인플레이션·공급·재정·term premium·수요 등 복수 원인으로 분해
- `채권은 담보다` → 레포·파생·금융기관 담보 체계의 구체적 범위와 한계를 설명

## 13. 이 페이지의 완료 기준

### 콘텐츠
- MVP chapter가 최소 하나의 완전한 학습 경로를 이룬다.
- 각 lesson에 30초 답변·메커니즘·반례·관련 전문 페이지가 있다.
- 모든 현재형 수치에 기준일/출처가 있거나 현재형 수치를 사용하지 않는다.
- 사실/관찰/가설/주의 라벨이 구분된다.
- 동일 긴 설명의 canonical owner가 하나다.

### UX
- 초보자가 3번 이내 클릭으로 `왜 미국채 금리가 중요한가`에 도달한다.
- 반도체 전체 가치사슬을 한 화면에서 조망하고 각 node로 이동할 수 있다.
- lesson에서 현재 전문 페이지로 이동할 수 있다.
- 모바일에서 가로 overflow 없이 읽을 수 있다.
- 현재 위치·이전·다음이 명확하다.

### 기술
- 모든 콘텐츠를 index.html에 초기 렌더하지 않는다.
- route/page/chat/evidence contracts에 등록된다.
- 정적 콘텐츠가 stale market claim을 만들지 않는다.
- source와 reviewedAt 누락을 validator가 차단한다.
- 접근성 full-route gate에 포함된다.

## 15. 사용자에게 필요한 결정

다음 중 5개만 사용자 결정이 꼭 필요하다. 나머지는 권장 기본값으로 구현 가능하다.

- 대안: `투자 아카데미`, `시장과 자본`, `세상을 움직이는 돈`

### D2. 논조
- 권장: **금융 문해력 중심의 중립적 설명**
- 대안: 주식투자의 필요성을 더 강하게 주장하는 칼럼형
- 영향: `왜 주식을 해야 하는가`를 `왜 생산적 자산을 보유하는가`로 바꿀지 결정

### D3. MVP 산업 범위
- 권장: **AI 원리 + 반도체 + AI 데이터센터 + 전력**만 심화
- 나머지 산업은 1페이지 가치사슬 개요 카드
- 대안: 처음부터 방산·로봇·우주까지 심화

### D4. 지역 범위
- 권장: 원리는 글로벌, 사례는 미국 중심, 각 chapter에 한국 투자자 연결 추가
- 대안: 미국 전용 또는 한국/미국 50:50

### D5. 기업 예시 범위
- 권장: 미국·한국·일본·대만·유럽의 상장사를 역할 예시로 포함하고 비상장사는 별도 표시
- 대안: 미국/한국 상장사만

- 입문 기본+심화 토글
- 진행률은 MVP 제외
