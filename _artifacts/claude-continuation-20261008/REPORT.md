`main`은 데이터 봇이 계속 커밋하므로 AGENTS.md 절차를 따릅니다: `git pull --no-rebase origin main`, 생성물 충돌은 `node scripts/resolve-generated-conflicts.mjs`가 출력하는 게이트로 처리. 이 브랜치의 `worker/wrangler.proxy.toml`이 v57.30으로 바뀌어 있어, `main`에 들어가면 프록시 Worker가 재배포됩니다.

하위 에이전트(Haiku)의 보고는 모두 주장으로 취급해 코드·실행으로 검증했습니다. 틀렸거나 따르지 않은 것: `aio-ui.js` 사이클 라벨 줄 번호 오인용(해당 문구 없음), `productionStatus` 표시 제안(레지스트리 경계와 충돌), `daily-diff`의 `signed(null)`(호출부가 모두 막고 있어 도달 불가), `lastSuccessfulAt` 수정 제안(생산자 의미 결정으로 보류).

### 7.3 소유자 결정·운영 작업이 필요한 것
1. **0-100 시장 점수 헤더**: AGENTS.md 두 문장이 충돌한다. 검증상 예측력이 없으므로 권장안은 헤더에서 숫자를 빼고 상세 화면의 '참고값'으로만 두는 것.
2. **접근 통제**: 공개 상수 토큰·위조 가능한 Origin·하루 300건 한도로 $10 예산이 소진될 수 있다. Cloudflare Access(또는 서명된 사용자 토큰) 설정은 계정 소유자가 해야 한다.
3. **Chart.js 보조 CDN(cdnjs)에 SRI 없음**: 샌드박스에서 cdnjs/jsDelivr가 차단돼 해시를 계산하지 못했다. `curl … | openssl dgst -sha384 -binary | openssl base64 -A`로 계산해 `index.html`의 보조 로더에 `integrity`를 추가하거나 Chart.js를 저장소에 포함해야 한다.
4. **볼트 PIN**: 4자리 PIN은 PBKDF2 310k여도 오프라인 전수 대입이 쉽다. 영숫자 암호 옵션 + 확인 입력이 필요하다(e2e 계약 변경 동반이라 별도 작업).
5. **13F 원장 297MB를 main 이력에 보관**: 단일 파일 최대 58MiB로 GitHub 100MiB 한도에 근접. 객체 저장소 이전 또는 파일당 크기 경고 게이트가 필요하다.
6. **워치독 임계 360분**(갱신 주기 30분의 12배), 발행 게이트 fail-open(회귀 기준선 부재 시 통과), 증명 문구 'exact tested release'가 봇 경로의 축소된 게이트 집합과 불일치.
7. **미국 소매판매 일정**이 2026-10-15에 소진된다(경고 상태). `macro-calendar-review` 워크플로로 Census 일정을 추가해야 한다.
8. **KR 수출 참고값(관세청 7월 상순)**은 사람이 입력한 수치다. 공식 API 키를 연결하거나 항목을 폐기해야 한다(현재는 stale 상태로 AI 스냅샷에서 제외).
9. **문서 정합**: RULES R315·R474/R669, EXECUTION-STATUS의 '모바일 완전 제거'와 '반응형 유지' 문장, HANDOFF.md '모바일 4G 기준', QA-CHECKLIST의 열린 모바일 항목은 원장 수기 편집 금지 규칙 때문에 `record-fix`로만 고칠 수 있어 이번에는 R698이 R315를 대체한다고만 기록했다.
10. 개인 키 Google CSE 직접 호출(`aio-chat.js` 약 4588~4650)은 사용자 본인 키 경로라 제거하지 않았다. 공급자·예산 결정과 함께 정리 여부를 정해 달라.
