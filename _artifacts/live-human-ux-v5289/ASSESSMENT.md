# AIO Screener v52.89 Live Human UX Assessment

- 실행일: 2026-07-14
- 대상: `https://ysnle.github.io/aio-screener/` 공개 v52.89
- 범위: 19개 기본 페이지 + 용어사전 오버레이 = 20개 사용자 표면
- 화면: 1440×900 데스크톱 20면 + 390×844 모바일 20면
- 사용자 과업: 뒤로가기, 가이드 검색, 용어 검색/Escape, 포트폴리오 입력 노출, 점진 공개, 모바일 메뉴, 키보드 Tab 순회

## 최종 판정

**PARTIAL / 추가 수정 필요.** 시안의 아이보리 톤, 헤어라인, 넓은 여백, 핵심 우선 정보구조와 모바일 1열 전환은 전체 20면에 일관되게 반영됐다. 그러나 기능 완료 상태와 화면 상태가 어긋나는 표면, 닫힌 패널 키보드 초점, 압축되지 않은 장문/결측 행이 남아 있어 “여러 사용자 관점에서 불편 없음”으로 판정할 수 없다.

## 확인된 장점

- 40개 공개 표면 모두 수평 오버플로우 0px.
- 일반 경로에서 PUBLIC STATUS, pipeline, debug 같은 개발자 문구 0건.
- 20면 전체에서 중복 페이지 제목 0건, 깨진 이미지 0건.
- 데스크톱과 모바일의 타이포그래피·여백·버튼 톤이 일관됨.
- 브라우저 뒤로가기, 모바일 메뉴, 용어사전 검색/Escape, 포트폴리오 입력 노출, 스크리너/국내 테마 더보기 동작.
- 가이드 검색은 `포트폴리오`에 대해 3건의 클릭 가능한 결과를 표시함.
- 공개 v52.89 라이브 불변식, 배포 CI, 22 내부 라우트×4 뷰포트, 접근성/핵심 10면/Portfolio E2E는 모두 통과함.

## 재발 방지용 바이너리 수용 조건

- **HUX-01 기업 분석 종료성**: 검색 후 8초 내 결과 또는 명시적 부분 실패 화면 중 하나가 표시되고 `조회 중`만 남지 않아야 한다.
- **HUX-02 뉴스 상태 단일화**: 기사 1건 이상 렌더 시 감성·24h 수집·기준시각도 같은 surface model에서 값 또는 `계산 불가` 사유를 표시해야 한다.
- **HUX-03 점진 공개 소유권**: `news-load-more-wrap`는 `#page-market-news`의 자손이어야 하고 `visible < eligible`이면 조작 가능한 더보기가 보여야 한다.
- **HUX-04 닫힌 오버레이 초점 차단**: `aria-hidden=true`인 패널 내부로 Tab 초점이 0건이어야 한다(`inert` 또는 tabindex 관리).
- **HUX-05 국내 테마 압축**: 기본 3개 카드의 카드당 서술을 400자 이하로 제한하고 장문 리서치는 명시적 펼치기로 이동한다. 결측 행 비율이 임계값을 넘으면 행 나열 대신 단일 미수신 상태를 표시한다.
- **HUX-06 폴백 요청 상한**: 한 페이지 진입에서 동일 원천 실패 로그/요청은 정해진 상한을 넘지 않고, 사용자에게는 중복 없이 하나의 상태 요약만 보여야 한다.

## 검증 한계

- 앱 내 브라우저 제어는 런타임 초기화 충돌(`Cannot redefine property: process`)로 사용할 수 없어 공개 URL을 실제 로컬 Chromium/Playwright로 검증했다.
- NVDA/VoiceOver 실기기, 실제 초보자·전문 투자자 인터뷰, Firefox/WebKit은 이번 점검에 포함하지 않았다.
- 외부 API 원천 값 자체의 금융 데이터 정확성은 이번 UI/UX 점검 범위가 아니다.
