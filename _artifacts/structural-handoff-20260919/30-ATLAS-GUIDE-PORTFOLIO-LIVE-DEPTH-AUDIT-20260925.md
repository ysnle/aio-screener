**LC-74 — 학습 깊이·근거 상태와 CTA의 약속 불일치 (`B+I+C`, 콘텐츠 계약).** 공개 상단의 `근거는 상세에서 확인`, 원문 버튼, 본문의 `최신 수치·기업 자료` 탐색 경로를 한 맥락에서 읽으면 30개 미연결 원문과 0개 직접 관측값의 상태가 늦게 드러난다. 현재 로컬 `src/ui/knowledge/lesson.js:32`도 모든 원문을 짧은 참고라고 고정한다. 구조 개편은 `concept → short explanation → authored deep lesson → exact-section source → dated observation`의 서로 다른 완료 상태를 하나의 콘텐츠 레지스트리에서 표현한다. 버튼은 실제 단계에 따라 `짧은 참고 더 읽기`, `원전 보기`, `현재 관측 없음`으로 분기한다. 원문 연결이 없는 30개에는 검색/데이터 카드로 건너뛰는 가짜 깊이 약속을 제거하고, 실제 집필·직접 근거를 채운 뒤에만 심층/출처 배지를 올린다. 인수: 54개 고유 개념 각각의 공개 깊이·원전 유무·관측값 n과 사용자가 예상한 결과가 일치하고, 출처 링크를 눌러 같은 주장을 찾을 수 있다.

[29 LC-62](29-SECOND-PASS-LIVE-CONTENT-AUDIT-20260925.md)의 SCORE 결측 노출 문장과 같은 출판 정책 문제다. 한 화면에서 경고를 읽는 숙련 사용자와 위 10단계만 읽는 초보 사용자가 반대 결론에 이를 수 있다.

설명서의 `브리핑 24시간 이내`, `시장 폭 200일선 위 비율`, `NAAIM 종합`, `테마 히트맵/RRG`, `Ticker 차트/기술지표/재무/뉴스 통합` 등의 현재 제공 서술은 이번 배포의 135일 경과 브리핑, 5/20/50일선만 표시된 시장 폭, NAAIM 미수신, RRG 0/11, Ticker 가격 이력 탭 소실(LC-18)과 일치하지 않는다. 결측을 제품이 드러내는 점은 양호하지만 설명서가 현재 사용 가능성을 별도 배지 없이 일반형으로 약속한다. **로컬 v56.37 P1220이 45점 단정과 200일/McClellan/NAAIM 일부 문구를 이미 손댔으나 원격 SHA에는 아직 없다.** `20점`·10단계·전략 본문을 포함한 전체 guide claim과 새 로컬 변경 범위는 다음 원격 배포에서 다시 대조한다.

**LC-78 — 기능 범위 9/9 PASS가 설명서 전체 문장 품질을 보증하지 못함 (`B+I+C`, 출판 게이트).** 현재 로컬 `index.html:12556`에는 `20점 환경 스코어`가, `index.html:12969`에는 `현금 비중 확대`가 남는다. `9/9`는 제한된 capability manifest의 검증 상태로만 이름 붙이고 설명서의 각 문장에 `metricId/scale`, `capabilityId + current status`, `claimType`, `allowedUse`, `data cut`, `source`를 매핑한다. 같은 점수의 20점/100점·45/75 기준은 한 정본으로 만들며 검증 전 오류 문장을 퇴역한다. 과거 사례/조건부 전략은 현재 개인 행동 지시와 분리한다. 브리핑·시장 폭·NAAIM·RRG·Ticker는 화면의 실제 데이터 상태를 사용법 옆에 표시한다. 인수: 9/9가 통과해도 본문에 금지된 방향 지시·척도 불일치·미제공 기능 약속이 있으면 **Guide 게시 게이트는 실패**하고, 초보/숙련 사용자 과업에서 두 문장을 읽고 같은 의미를 설명할 수 있다.

접힌 `투자 필수 배경지식`도 직접 열어 주식·금리·FX·채권·기술·매크로 여섯 묶음의 문장을 읽었다. 장 시간은 `9:30~16:00 EST (한국 23:30~06:00)`로 사계절 고정인데, [NYSE 정규장은 ET](https://www.nyse.com/trade/trading-information)이고 [NIST는 EST UTC−5/EDT UTC−4를 구분](https://www.nist.gov/pml/time-and-frequency-division/local-time-faqs)한다. 서머타임에는 한국 시각이 한 시간 빨라지므로 계절 표기가 필수다. `DXY 100 이상이면 달러가 강한 상태`의 100은 [ICE 정본의 1973년 시작 지수 기준점](https://www.ice.com/publicdocs/futures_us/USDX_Futures_Contract.pdf)이며 현재 시장의 독립적인 강세 판정선으로 곧바로 쓰기 어렵다. `가격↑+거래량↑="진짜" 상승(기관 매집)`, `RSI 70↑=단기 하락 가능`, `골든크로스=강세 시작`, `CPI 예상 상회→주가 하락`, `PMI 48 미만=경기침체 경고`는 관측·휴리스틱·원인·확률을 건너뛰는 단정형 또는 조건 없는 경계다. 특히 Fed의 [물가 발표·정책 기대 연구](https://www.federalreserve.gov/events/conferences/irfmp2003/pdf/Fratzscher.pdf)는 예상과 정책 반응에 따라 효과가 달라짐을 보여 주므로 CPI 문장을 결정적 주가 방향 규칙으로 게시할 수 없다. 각 규칙의 출처·표본·시장·시간축·반례는 이 컷에서 전수 원문 대사하지 않았다.

**LC-81 — 배경지식 문장의 시각·지수 기준·인과 등급 계약 (`B+I+E 일부`, 교육 콘텐츠).** 시간 문장은 거래소 timezone `America/New_York`와 날짜별 KST 변환을 정본으로 생성한다. DXY는 기준 지수 수준과 시점 대비 변화·실효환율 판단을 분리한다. 이동평균·RSI·거래량·CPI·PMI 문장은 `정의/관측/연구된 관계/가능한 해석/행동`으로 분해하고, 조건·분모·반례·원전이 없는 임계값/원인/행동 문구는 교육용 사실처럼 노출하지 않는다. 같은 규칙이 Guide·Glossary·Signal·AI 답변에서 다른 뜻으로 재생산되지 않게 claim ID를 공유한다. 인수: 날짜 두 개(EST/EDT)를 넣어 한국 장 시간을 검증하고, 기초 원고 전 문장의 타입·직접 근거·허용 용도를 리뷰한다. 외부 E는 위 세 원전과 해당 세 주장에만 해당한다.

접힌 `공개 이용 정책`도 직접 열어 개인정보·이용약관·면책·GitHub Issues 경로를 읽었다. 정책은 `PIN을 설정한 민감 데이터는 AES-GCM으로 암호화`라고 하지만 일반 공개 포트폴리오에서 PIN 동선의 접근·설정·잠금/복구와 실제 저장 경계는 아직 시험하지 않았다. `기본적으로 이 브라우저의 저장소에만 보관`, `외부 API를 직접 연결하면 요청이 전송`이라는 단서는 유용하지만, 초보 사용자가 `PIN 설정 전의 저장`과 `PIN 설정 후 저장 완료`를 같은 보호 상태로 받아들일 여지가 있다. 화면에는 AES-256 설명도 있어 알고리즘/키 길이/적용 데이터 범위를 하나의 계약으로 맞춰야 한다.

**LC-82 — 정책의 보안 약속과 실제 포트폴리오 상태 연결 (`B+I`, 보안·신뢰 UX).** 공개 정책·포트폴리오 배지·설정 UI가 `PIN 미설정`, `설정 중`, `암호화 저장 ack`, `잠김`, `해제`, `저장 실패`, `복구 불가`를 동일한 보안 상태 원천에서 읽도록 한다. 어떤 필드가 평문/암호문이고 키가 어디서 유도·보관되는지 문서화하고, 로컬 저장·외부 전송의 범위를 API 키/시세 요청/AI 요청/포트폴리오로 나눠 설명한다. PIN을 임의 입력한 실계정 테스트로 대신하지 말고 격리 브라우저 fixture에서 저장소와 UI를 함께 검증한다. 실제 암호화/복구 성질은 이번 컷에서 인증하지 않는다.

## 5. 포트폴리오 빈 상태·입력 경계와 좁은 화면

공개 배포의 빈 포트폴리오는 금액을 임의 `0`으로 채우지 않고 `—`로 둔다. `종목 추가`는 티커·수량·매수가·선택 목표가/통화/메모를 노출한다. 빈 채 `추가 / 업데이트`를 누르면 `티커, 수량, 매수 단가를 모두 입력하세요` 토스트가 나오고 행은 생성되지 않았다. `PIN 설정 후 저장 시 AES-256 암호화`, `로컬 저장/서버 전송 없음`의 설명은 읽었다. 실제 암호화 저장·PIN 복구·가져오기/내보내기·현금/FX/원장/백테스트·가격 실패 후 손익은 **개인 보유를 만들지 않았으므로 이 배포에서는 미검증**이다. `index.html:4958–4972`의 공개 CSS는 포트폴리오 고급 `details` 여섯 개(AI 운용 노트, 계좌 원장, FX 근거, 백테스트, 위험/보상, 관심종목)를 일반 화면에서 숨기고 개발 모드에서만 보이게 한다. 그 DOM과 로컬 브라우저 게이트가 존재한다는 것은 공개 사용자가 기능을 실제 사용할 수 있다는 뜻이 아니다.

**LC-79 — 공개 범위·빈 상태·보안/성과 기능의 약속 정리 (`B+I+C`, 제품 범위 결정).** 화면 헤더의 리밸런싱과 Guide의 `JSON 내보내기/정기 백업`은 공개 양성 동선까지 시험해야 한다. 고급 여섯 기능을 공개 제품 범위로 선언할지, dev-only로 보존/퇴역할지 명시적으로 결정한다. 공개라면 포지션 0/1개·현금만·통화 불일치·시세 없음·PIN 설정 전/후·잠금/해제·저장 실패·삭제 실패·다른 기기 복구를 격리 브라우저 fixture로 실제 조작한다. dev-only라면 사용자 설명서/기능 수/성능 주장에 세지 않는다. 저장 암호화 문구는 `PIN 미설정`과 `PIN 설정 및 저장 완료`의 저장 상태를 구별해 노출한다. 기존 P1187~P1203 로컬 게이트는 새 SHA의 공개 수용으로 승격하지 않는다.

390×844 폭의 실제 캡처에서는 포트폴리오 상단에 햄버거 버튼이 두 개 보였고 헤더의 브랜드/시세 문장은 좁은 칸에서 잘렸다. 종목 추가 폼은 화면 아래로 이어졌다. 이것만으로 모든 좁은 화면에서 클릭 불가라고 선언하지 않는다. **LC-80 — 좁은 화면 첫 화면의 중복 메뉴 affordance와 출처/입력 정보 우선순위 (`B+I`, 시각 UX 후보).** 320/390/768 폭에서 두 메뉴 버튼의 역할·접근성 이름·열림 대상·초점, 시세 상태의 전체 내용 접근, 폼의 레이블/오류/버튼 도달, 키보드 및 보조공학 순서를 검증한다. 장식 중복이면 하나를 제거하고 기능이 다르면 서로 다른 이름과 위치를 부여한다. 테스트 후 viewport override는 기본값으로 복원한다.

## 6. 구현/삭제·통합의 인수 순서

1. **콘텐츠 정본과 공개 게이트:** Atlas/Principles/Guide/Glossary/Briefing의 claim/source/capability/current-state를 같은 ID 체계로 연결한다(LC-59/74/76/77/78). 공통 상위 링크를 개별 주장의 직접 근거처럼 복제하는 renderer와 자유 문자열 `PASS`를 통합·퇴역한다. 먼저 한 개 claim을 `원전 절→검토→게시→라우트/Guide/AI`까지 관통하는 파일럿으로 검증한다.
2. **학습 탐색 state:** 54개 고유·55개 배치의 모델을 `conceptId`와 `placementId`로 분리하고, 48개 짧은 원문/6개 입문 카드의 깊이를 선언한다(LC-74/75). 7단계의 중복 개념에서도 전후 navigation이 같은 단계에서 이어지도록 한다.
3. **사용 설명서와 실제 기능:** 현재 route capability/데이터 readiness에서 사용 가능성 문장을 생성하고, 수치 척도와 행동 허용 언어를 모든 카드에 적용한다(LC-78/81). 9/9 기술 검증, 20-route 렌더, 실제 사용자 이해도는 서로 다른 배지로 보여준다.
4. **포트폴리오 공개 결정 후 수명주기:** dev-only 여섯 섹션을 제품 범위에서 분리하거나 공개 설계를 완성한다. 공개한다면 테스트용 격리 프로필에서 저장/내보내기/가져오기/PIN/시세 실패/통화/원장/리밸런싱/삭제 후 복구를 하나의 데이터 정체성으로 검증한다(LC-79/82). `index.html`의 공통 접힘 CSS와 native ESM·legacy 폼 writer 소유권을 함께 정리한다.
5. **모바일·보조공학:** viewport별 상단 메뉴/상태·학습 3열·표/폼 재배치, 순서·초점·음성 이름을 실제 사용 과업으로 점검한다(LC-80). 이번 한 폭 스크린샷을 반응형 전수 PASS로 쓰지 않는다.

## 7. 증거상 열린 항목

- Atlas 학습 **48개 원문의 외부 원전 직접성/정확성** 및 근거 자료실의 14개 후보·40개 원장에 연결된 외부 링크(화면 표시 23+38회, 중복 가능)의 개별 원문 대사, 95개 산업 노드의 기업 최신 실적·공급 관계, 35개 관계의 수학적 인과 증명은 미완료다. 화면 텍스트를 모두 읽은 것과 E 인증을 구분한다.
- 포트폴리오 양성 보유·민감한 사용자 원본·복구·환산·백테스트, screen reader, 320/768 폭, 모집된 실제 초보/숙련/한국·미국 투자자 이해도는 미검증이다. 공개 배포는 가격 일부·RRG 이력이 미수신이라 양성 계산 결과도 미인수다.
- Principles 확장 원고 112/112의 새 원격 컷 열람과 Masters 38/38 기본 프로필 순회 결과는 [31](31-PRINCIPLES-MASTERS-LIVE-CONTENT-AND-SEC-AUDIT-20260925.md)에서 별도 통합한다. 원문 직접성·37개 SEC 원행 대사는 여전히 완료가 아니다.
