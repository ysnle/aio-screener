## 4. 라우트 밖 용어 사전 275개: 빠졌던 콘텐츠 범위

상단 `용어 사전` 버튼으로 `role=dialog`인 `투자 용어 사전 · 275개`를 열었다. 이 대화상자는 20개 라우트 레지스트리의 한 행이 아니며, [28](28-PAGE-BY-PAGE-LIVE-USER-AUDIT-20260924.md)의 Guide 빠른 이동 `용어사전` 실패 관찰과도 다른 실제 콘텐츠 표면이다. 라이브 DOM의 **275개 렌더된 항목을 추출해 제목·카테고리·설명 필드를 전수 분류**하고, 정의/행동/수치/시점 문장을 위험별로 읽었다. 각 항목의 출처 링크는 **0개**였다. 기계적 표현 선별에서는 72개 항목에 숫자+기간/비율/bp 형태, 48개 항목에 `매수/매도/최적/권장/추천/확증/확정` 중 하나가 있었다(중복 가능·정규식 후보 수). 개별 주장 275개의 외부 원전 사실성을 모두 인증한 것은 아니다.

**LC-56 — 275 표시와 찾을 수 있는 고유 정의/분류가 다름 (`B+I+C`).** `맥스페인(Max Pain)`은 7·196번째에 중복되고 `평균회귀(Mean Reversion)`/`평균 회귀(Mean Reversion)`은 공백만 다른 249·266번째다. 정규화한 고유 표제는 273개다. `기술` 2개(RRG/ZBT), `심화` 2개(Sortino/F-score)는 어떤 카테고리 버튼으로도 직접 탐색할 수 없다. 실제 `차트분석` 필터에서 34개만 나오고, 그 상태로 `RRG`를 검색하니 `검색 결과가 없습니다`가 나왔다. `js/aio-ui.js:4594–4646`은 10개 수동 분류 목록과 카테고리 범위 검색을 쓰고, `js/aio-glossary.js`의 실제 `cat`과 동기화하지 않는다. **설계:** 용어 ID·정규화된 별칭·한 개의 정본 정의·카테고리/필터 목록을 같은 레지스트리에서 생성하고, `275개 항목 / 273개 고유 개념` 또는 중복 통합 뒤 정직한 총수를 표시한다. 선택 카테고리 안의 검색임을 검색창에 드러내거나 전체 검색으로 자동 전환한다. 필터 12개/전체·검색/초점/닫기 복귀를 키보드와 브라우저에서 인수한다.

대화상자의 **ESC 닫기와 `용어 사전` 버튼으로의 초점 복귀는 이번 배포에서 실제 확인**했다. 이 긍정 결과가 275개 본문의 사실성·검색 적합성까지 인증하지는 않는다.

**LC-57 — 사전의 연구 주장과 제품 기능 범위가 분리되지 않음 (`B+C`, 문구/출처 심사 대상).** `시장 폭(Breadth)` 설명은 `200일선 위 70%`와 시장폭 페이지 이동을 함께 쓰지만 현재 화면은 5/20/50일선만 제공한다([28 LC-21](28-PAGE-BY-PAGE-LIVE-USER-AUDIT-20260924.md)). `NAAIM`은 라이브 원천 미수신인데 `25% 이하 + AAII Bear 50%+ → 6개월 후 S&P500 평균 +15%`, `Put/Call`은 `역발상 매수 신호`, `ZBT`는 강세장 개시 `확증`, `거래량 분석`은 `기관 매집`이라고 말한다. 이는 **원천·표본·기간·반례 없이 현재 행동 근거처럼 읽힐 수 있는 문장**이라는 UX/근거 문제이며, 여기서 그 수치의 역사적 참거짓을 확정하지 않는다. `js/aio-glossary.js`의 각 행은 `term/cat/def`뿐이라 출처 URL, 게시/검증일, 학습 설명과 현재 제공 지표의 구분이 없다. **설계:** definition, educational heuristic, empirical claim, current product capability, action language를 분리하고 주장별 source/조사기간/표본/조건/검증상태/허용 용도를 부여한다. 실제 route가 제공하지 않는 200일선·NAAIM을 현재 제공으로 연결하지 않는다. 원전 미확인 예측 수치와 행동 문구는 게시 보류 또는 조건부 교육 설명으로 한정한다.

**LC-58 — 옵션 손익과 ITM/OTM의 직접적 정의 오류 (`B+C+E`).** 공개 사전의 `행사가(Strike Price)`는 `ITM=수익 상태, OTM=손실 상태`라고 한다(`js/aio-glossary.js:210`). ITM/OTM은 **기초자산 가격과 행사가의 관계**이며 매수자가 낸 프리미엄을 포함한 순손익 상태가 아니다. 예를 들어 콜을 프리미엄 3에 사서 행사가보다 기초자산이 1 높으면 ITM이어도 만기 순손익은 −2(비용 전)다. [Options Industry Council의 옵션 정의](https://www.optionseducation.org/optionsoverview/what-is-an-option)와 [가격 구성 설명](https://www.optionseducation.org/optionsoverview/options-pricing)은 ITM을 내재가치로, 순이익은 프리미엄 비용을 뺀 값으로 구분한다. **설계:** `콜: 기초자산 > 행사가, 풋: 기초자산 < 행사가`와 `손익분기점은 지급/수취 프리미엄과 비용을 포함`으로 정정하고, 단일 숫자 예시를 교육 문장에 붙인다. 옵션 관련 26개 용어에서 intrinsic value, premium, break-even, max loss를 같은 계약으로 재검수한다.

## 5. 시장 원리 112개 세부 레슨과 8개 경로

배포 `#principles`에서 선택 학습→참고 자료실→`112개 세부 레슨 보기`를 펼쳐 6페이지(20+20+20+20+20+12)를 순회했다. **112/112 카드의 정의·작동 원리·가상 분석 예시·반례/실패 조건·선행/연결·표시 출처를 읽었다.** 화면은 이를 `짧은 참고 원고`로 한정하고 추가 집필·검증 필요를 알린다. 카드마다 별도 `개념 원문·출처 불러오기`가 있어 N9 1개만 열었으며, 나머지 **111개 확장 article 전문은 미검증**이다. N9 확장 원고는 자동 구조화·사람 검토 미완료·현재 수치/매매 판단으로 승격 금지라는 경계를 실제 표시한다.

카드 112개 가운데 D6 `중립금리와 정책 스탠스`는 2026-06-17 기준 연준 target range 중간값 3.625%, SEP 장기 중앙값 3.1%를 비교해 약 +50bp라고 설명하는 **날짜 있는 역사 사례**다. 공식 [FOMC 결정문](https://www.federalreserve.gov/newsevents/pressreleases/monetary20260617a.htm)과 [SEP](https://www.federalreserve.gov/monetarypolicy/fomcprojtabl20260617.htm)에 대한 별도 확인에서 반올림 차이를 포함한 근사 비교가 맞았다. 화면도 r* 참값이나 오늘의 정책값이 아니라고 밝힌다. 다른 111개 카드는 특정 시장 수치를 주장하기보다 조건부 원리와 점검 질문 위주였지만, 외부 원전 직접성은 아래와 별개의 문제다.

**LC-59 — 카드별 출처의 직접성이 약함 (`B+I+C`, claim/source).** N1–N15는 NIST AI 개요·Tesla AI/로보틱스·Rocket Lab 우주선 포트폴리오의 같은 3개 링크를 공유한다. N9 금융은 결제·대출·보험의 신용손실/자본비율/유동성, N11 소비재는 가격·브랜드·유통재고/마진, N13 건설·부동산은 토지·허가·공사비·분양/임대 현금흐름/재융자 위험을 설명하지만 세 링크는 그 메커니즘의 직접 근거가 아니다(N14 통신·N15 식량도 같은 링크). O1–O5는 한은·KRX·SEC 입문 홈페이지를 재사용해 O5 세금/계좌/환전비용 등 세부 문장의 직접 근거가 약하다. L1–L16과 M1–M12도 주제 접점은 있지만 각 레슨의 단위 주장에는 공통 상위 페이지를 반복한다. 공식기관 URL이라는 형식만으로 해당 문장의 근거 충분성을 인정할 수 없다. **설계:** 카드/문장 단위 `claimId → primary source exact section/date → supports/contradicts/unknown`을 기록한다. 배경 링크는 `배경`으로, 산업별 원전이 없는 예시는 `가상 사례`로 표기하고 직접 근거 없는 문장에는 `추가 원전 검토 필요`를 인라인 표시한다. 원전과 출처 사용권을 검수하기 전 AI/검색 인용으로 승격하지 않는다.

**LC-65 — 허용 범위 밖 builder 입력의 무음 무시 (`B+I+C`, 재현).** UI가 자유 숫자를 받는 것처럼 보이면 95를 허용해 정확한 정의로 계산하거나, 허용값 목록/범위를 먼저 보여 주고 95를 명시적으로 거부해야 한다. 무효 입력에서 이전 preview hash/run이 그대로 남는 경우 `95를 실행했다`고 읽히지 않게 필드·상태줄·접근성 오류를 연결한다. 0/40/50/65/80과 경계 밖/비숫자/빈 값, 키보드 Enter·클릭, preset 전환을 같은 parser/validator로 검증한다.

**양성 경로:** rank 80의 실행 뒤 `입력 로컬 보관됨`, pass 174/unavailable 27, 표 필터 Technology+rank80 38행을 확인했다. 새 보관 행의 `저장 입력으로 재현`을 누르니 `보관한 입력으로 재현됨 · 현재 시장 상태가 아닌 당시 결과입니다`가 표시되고 universe/ready/pass/unavailable **873/844/174/27**, 표 38행이 복원됐다. 새 보관 시각은 2026-09-25T00:37이었고 이전 보관을 삭제하지 않았다. **runId는 화면/접근성 트리에서 확인되지 않았다.** 이 한 양성 과업이 여섯 프리셋 전체·모든 결측 조합·기기 간 보관·시장 데이터가 바뀐 뒤의 frozen replay를 인증하지 않는다.

시총 `대형 ($10B~1T)` 표 필터는 결과 0행과 `조건에 맞는 종목이 없습니다`를 표시했고 위 실행 funnel은 그대로였다. 첫 12개 보이는 종목의 시총은 모두 `—`였다. 현재 로컬 별도 컷의 `public-data/screener.json` 846행에도 양수 `mcap` 적격이 0이며 필터는 시총 미수신을 제외한다. **LC-73 — 필터 0건의 거절과 데이터 미상 혼동 (`B+I+C+D`, 원격 전 행 확인 대기).** 이 컷의 0행은 시총 결측으로 설명 가능하며 시총 계산/필터 산술 결함으로 확정하지 않는다. 빈 상태는 `조건을 충족한 0건 / 시총 정보가 없어 판정 보류 n건`을 분리하고, 873 원격 전체의 적격 n/N과 적용 컷을 공개한다. 로컬 846과 원격 844 ready/873 universe를 같은 분모로 합치지 않는다.
