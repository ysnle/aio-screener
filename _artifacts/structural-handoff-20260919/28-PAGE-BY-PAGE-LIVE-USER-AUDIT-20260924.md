## 4. 사용자 과업과 기능 인수 순서

1. **현재 상태 이해**: 홈→신호→시장폭/심리의 점수·결측·부분 수신이 같은 컷과 의미로 읽혀야 한다. `매매 지시`로 오해할 문구를 제거하고 모드 전환을 검증한다. LC-19·20·21·26·29를 먼저 다룬다.
2. **후보 검증**: 스크리너 조건 미리보기→실행→873 전체 진단/342 통과/29 부족 구별→Why→AAPL 티커→SEC 재무→차트 기간→저장/replay. LC-18을 탭 blocker로 우선 해결하고 LC-25·27 및 [27 LC-12](27-LIVE-LOCAL-CODE-SEMANTIC-AUDIT-20260924.md)를 연결한다.
3. **맥락과 비교**: 브리핑→뉴스 원문·24시간 컷, macro→fxbond 동일 금리차, 테마→ETF/바스켓·breadth, 옵션→심리 SKEW. 각 수치에 metric/unit/source/observedAt/allowedUse와 비교집단을 보여준다. LC-17·20·23·24·28 및 [27 LC-06·07·09·10·11·14·15](27-LIVE-LOCAL-CODE-SEMANTIC-AUDIT-20260924.md)를 함께 인수한다.
4. **학습과 출처 확인**: Guide 빠른 이동/검색→Principles 5모드→Atlas 4탭/7층→Masters 원문·분기 비교→원래 화면 복귀. 열람 자체를 이해도 성공으로 취급하지 않는다. 실제 사람이 현재/참고/미제공을 구분하고 반대 근거를 찾는지 시험한다.
5. **개인 자료**: 포트폴리오 0/결측·혼합 통화·PIN·백업·복원·원장/백테스트와 계좌/주식 부분 분모를 가짜 테스트 계좌로 로컬/배포 각 버전에서 분리 검증한다. 실계좌·개인 키는 사용하지 않는다.

각 과업의 독립 증거는 `route, action, displayed section, first paint/final, sourceSha, app/data revision, input fixture, expected/actual, viewport, screenshot/DOM trace, console/network, result, unresolved`를 기록한다. 출시 인수 전에는 20개 화면 각각의 모든 토글·필터·검색·탭·복원·실패·좁은 뷰포트·키보드/스크린리더·외부 원문 정확성을 별도 행으로 채운다. 이 실행의 표본 브라우저 PASS를 그 행들의 PASS로 자동 복제하지 않는다.

## 5. 아직 검증되지 않은 것과 다음 기준

- **실제 사용자 이해도 U 미실시**: 사용자가 `참고`, `매매 승인 아님`, `현재 원천 미수신`, 서로 다른 분모/통화를 실제로 올바르게 설명하는지 관찰하지 않았다. 초보·숙련 사용자의 사전 등록 과업에서 오해·완료시간·도움 요청을 측정한다.
- **화면 전체 상태 미인수**: Principles의 12개 이야기 장은 v56.33에서 본문까지 읽었지만 112개 심화 레슨은 카드 순회와 대표 A1 본문만, Atlas는 NAND 대표 경로만, Masters는 Berkshire 8뷰와 AAPL 역조회만 깊이 확인했다. 각 라우트의 긴 페이지 전체 스크롤, 다른 37개 Masters 프로필의 SEC 원행·27개 테마 상세·95개 Atlas 산업 노드/11패킷/40근거 원문, 모든 데이터 조합·필터, 저장/복구, 좁은 뷰포트와 보조공학은 전수 실행하지 않았다. 코드 인벤토리는 이 미검증 목록의 출발점이다.
- **외부 사실 E 미실시**: SEC/시장시세/FRED/뉴스의 숫자와 경제적 인과·인용이 실제 원천과 일치하는지는 별도 원문 대사·권리 검토가 필요하다. WAB와 비트코인 Yahoo 원문 2건은 직접 열어 보려 했으나 HTTP 429로 본문을 받지 못했다. 화면에 보인 제목과 실제 기사 본문의 동치·인과는 인증하지 않는다.
- **배포 버전 차이**: v56.24 로컬 변경이 v56.15 라이브에 반영됐다는 주장을 하지 않는다. 코드를 수정한 다음 동일 시나리오를 새 배포 `sourceSha`에서 다시 수행해야 닫힌다. 커밋·푸시·배포는 이 감사에서 하지 않았다.

## 7. 사용자 관점별로 실제 읽은 흐름과 남은 검증
