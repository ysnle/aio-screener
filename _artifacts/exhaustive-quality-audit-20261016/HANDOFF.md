## 영역별 전문적 판단

* **제품 규모·정보구조:** 약5명·무료·1인 운영에는 계정·결제·멀티테넌트나 대형 프레임워크보다 현재 셸·native ESM이 합리적이다.8화면·결론→차트→근거·3초 원칙은 유용한 경험칙이며 모든 글·표의 절대 형식으로 강제할 이유는 없다. 실제 이해·근거 도달·작은 화면 과업을 우선한다.
* **지식·리서치:** 공식 출처의 권위, 주제 관련성, 명제 직접 지지, 현재성, 연구 완료는 다르다. 연구 템플릿·현재성 경계·반증 지시문을 실제 조사 결과로 인용하면 품질이 과대 표시된다. 추가 문서 수보다 잘못된 승격을 줄이는 편이 가치가 높다.
* **데이터·통계:** 최신 완료 세션·발표 주기·관측일·수집일·null 구분은 유지한다. 조건 수는 확률이 아니며6개 팩터 백분위도 상승 확률이 아니다. n10/30·VIX25·HY450·buffer 등은 제품상 기준이므로 보편적 최적값처럼 부르지 않는다. 생존편향/PIT·비중첩·표본외 성과 한계를 지키며 연구 참고로 사용한다.
* **시나리오·AI:** 미래 가능성과 선택별 비용 설명은 사용자 가치가 있다. 방향 일치가 원인 확증은 아니고 ‘상대적으로 유리’는 무엇의 비용·기간·조건을 비교하는지 있어야 한다. 사용자가 유지하기로 한 conditional favored를 감사만으로 폐지하지 않는다. 동일한 사실성·시간·개인화 경계를 prompt·planner·renderer에 적용한다.
* **회계·성과·위험:** 계산 결과뿐 아니라 대상·기간·통화·추정 방법·비용 포함 여부를 같이 전달한다. 현행 FX/EPS/peer/CVaR/TWR 개선은 유지한다. 내부 안정성 인증을 예측력·최대손실 보장으로 읽지 않게 한다.
* **구조·성능:** 한 owner·명시적 lifecycle·결정론적 part/digest는 유지한다. 파일 분할·번들링 자체는 부팅·메모리·캐시·라우트 반복 이동 개선의 증명이 아니다. 변경마다 실제 payload/부팅/반복 탐색 결과를 필요한 범위에서 확인하고 프레임워크 전환을 목표로 삼지 않는다.
* **보안·개인정보·비용:** Secrets·atomic 예산·PIN/대화 삭제·실제 전송 고지·명시적 배포 권한은 유지한다. 이번 패스는 침투시험·청구서 대사·개인 데이터 전송 전수 인증이 아니다. 과거 보안 지적을 최신 취약점 확인 없이 미수정으로 재기록하지 않는다.
* **운영·법규·권리:** 무료 가족용에 정식 모집·SLO 인증·공급자별 license audit를 완료 장벽으로 둘 필요는 없다. 실제 약관·저작권·예산·데이터 정직성과 행위별 범위는 별개다. 규제기관급 절차를 덧붙이기보다 실제 게시·전송·수집 행위에 맞는 최소 절차를 쓴다.
* **QA·문서·에이전트:** PASS 개수·정해진 문구·긴 원장·이진 fixture의 존재는 의미 품질의 대리 지표로 충분하지 않다. 실제 잘못된 입력/정의/연결과 정상 설명을 함께 확인한다. 역사 기록은 보존하되 현재 강제·열린 backlog와 분리해 탐색 비용을 줄인다. 권한 안의 로컬 진행에 중복 승인을 요구하지 않는다.

## 아직 인증하지 않은 범위

전체 외부 원문199개·북마크834건·이미지2379개 전편 재열람, 모든 P 이력과 모든 과거 QA 본문, 코드베이스의 모든 줄·모든 장애 조합, 실제 provider 청구서·비밀키 설정·장기 운영률, 실 iOS Safari·보조기기·교육효과·개인화 AI 오류율은 인증하지 않았다. source hash 수나 지도 범위를 전편 의미 검수의 증거로 바꾸지 않는다. 정식 사용자 연구/SLO/권리 감사의 미수행은 새 가족용 정책상 제품 완료 blocker가 아니다.

‘완벽하며 빠뜨린 것이 없다’고 선언할 수는 없다. 대신 이번에 확정한 범위·개별 판정·반례·해소 상태·남은 경계를 재현 가능하게 남겼다. 발견된 제품 수정 제안은 아직 이 감사가 적용하지 않았다. **감사 문서·읽기 영수증·합성 재현기만 변경했으며 commit/push/deploy/producer/workflow dispatch는 수행하지 않았다.**
