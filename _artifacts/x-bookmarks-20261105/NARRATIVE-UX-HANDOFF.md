# 시장·AI 내러티브를 이해하고 추적하는 화면 기획

작성 2026-11-05 · **설계 제안 / 부분 조사 / 구현 전**. 기존 [10월 이후 연구 종합](OCTOBER-SYNTHESIS-HANDOFF.md), [전체 화면 재설계](SCREEN-REDESIGN-HANDOFF.md)와 함께 읽는다. 이 문서는 조사 원장의 해석을 재사용하며, 작성자가 해당 X 원문의 댓글·인용·영상·이미지를 새로 전수 독해했다는 뜻이 아니다. 범위와 직접 읽은 부분은 [색인](README.md)의 각 독해 기록을 따른다. 현재 화면에 관한 아래 관찰은 코드 정적 조사이며 브라우저 실측은 아니다.

## 제품이 답할 질문과 설계 원칙

사용자는 뉴스를 모르는 상태로 들어와도 ① **지금 무슨 이야기가 중요한가** ② **이전과 무엇이 바뀌었나** ③ **어떤 사실과 어떤 해석이 연결되는가** ④ **다른 설명도 가능한가** ⑤ **다음에 무엇이 확인되면 해석이 달라지나**를 한 흐름에서 이해해야 한다. 시장 내러티브는 가격·금리·시장 폭·예정 사건을 잇는 해석이고, AI 산업 내러티브는 수요·설비·전력·조달·공급·실적·가격을 연결하는 해석이다. 서로 관련되지만 하나의 확정 원인으로 합치지 않는다.

**제안하는 공통 흐름:** 한 줄 결론과 기준일 → 축이 보이는 핵심 관측 → 이전 읽기 이후 달라진 사실 → 설명 후보와 반대 근거 → 다음 공식 이벤트의 조건별 전개 → 원문과 데이터 정의. 화면 전체를 기사 목록이나 긴 AI 문단으로 바꾸지 않는다. 증거가 약할 때는 ‘이유 미확인’을 표시해 이야기를 채우지 않는다. 가격 변화는 최신 완료된 미국 정규장 종가를 기본으로 하며, 장중·한국·분기·월간 데이터는 각각의 기준과 지연을 따로 밝힌다.

현재 `scripts/lib/narrative-context.mjs`는 리서치 채널 요약과 스크리너 종목 뉴스에서 정의된 주제를 찾아 최근 시간대·종목 움직임을 이용해 읽기용 후보를 고른다. 이 자료를 이차 자료로 취급해 수치 증거와 구별한다. `scripts/producer/market-narrative.mjs`는 이를 시장 분석 생성 입력에 연결하며, `src/domain/market/page-flow.js`는 시장 화면의 여러 근거를 하나의 흐름으로 설명하는 경로가 있다. 다음 설계는 이 기능이 이미 전부 구현됐다는 뜻이 아니다. 기존의 주제 분류·문장·사실 원장을 확인해 확장하고 별도 통합 원장을 곧바로 신설하지 않는다.

## 사용자가 보는 ‘이야기’ 단위

하나의 이슈는 기사 수가 아니라 **사용자가 답을 얻을 질문**으로 묶는다. 예: ‘AI 투자 확대가 주문과 수익으로 이어지는가?’, ‘반도체 약세가 실적 기대 때문인가, 다른 위험 축소 때문인가?’. 하나의 카드와 연결된 상세에 다음 정보를 둔다.

| 영역 | 사용자가 보는 내용 | 사실·표시 규칙 |
|---|---|---|
| 한 줄 | 현재 확인된 변화와 아직 모르는 점 | ‘업종은 하락, 원인은 여러 설명이 경쟁’처럼 관측과 해석을 분리. 예측·매매 권유 금지 |
| 바뀐 점 | 이전 읽기 대비 새 발표, 수정, 반박, 일정 변경 | 비교할 이전 기록이 실제로 있을 때만 표시. 새 날짜만 생기거나 생성 문구만 바뀌면 ‘새 사실’이 아니다 |
| 관측 | 차트와 값, 기간, 분모, 단위, 데이터 기준일 | 가격·업계 통계·기업 분기·뉴스 시간을 구별. 직접 관측하지 못한 자금 유출·매도자 의도는 쓰지 않음 |
| 해석 A/B | 연결 고리와 각 가설을 지지·약화하는 관측 | 출처의 발언, 보도, 모델의 추론을 구분. 출처가 같은 재인용은 여러 독립 근거가 아님 |
| 다음에 볼 것 | 예정 발표와 결과별 가능한 전파 경로 | 기대치 미확보, 일정 미정, 아직 발표 전을 따로 보임. 미래를 한 경로로 단정하지 않음 |
| 더 보기 | 정의·기간·작성/공개 시각·원문·이전 버전 | 조작 가능 차트와 텍스트 대안, 근거별 접근·상태, 원래 자료로 이동. 사용자에게 기술 용어를 강요하지 않음 |

조건별 선택의 비용과 도움이 되는 조건은 일반적 설명으로 제시한다. 종목·가격·수량·시점을 개인에게 지시하지 않으며 임의 확률이나 검증되지 않은 종합 점수를 만들지 않는다. 작은 표본의 과거 사례는 표본 수와 기준을 함께 밝히고 현상 설명으로만 쓴다.

## 시간에 따라 변하는 이야기를 보여 주는 방식

**시간선은 뉴스 게시 순위가 아니라 판단 변화의 기록**이다. 각 점에 ‘사건이 일어난/자료가 가리키는 기간’, ‘원문이 공개된 시각’, ‘AIO가 실제로 입수해 읽기에 반영한 시각’을 보존한다. 가격은 관측 세션일과 함께 표시하고, 수정 공시는 원래 사실을 덮어쓰지 않고 수정으로 연결한다. 종가에 기반한 진단과 장중에 발표된 속보를 구분하고, 서로 다르면 한 문장으로 같은 시점처럼 합치지 않는다.

```text
이 이야기의 변화                                    마지막 확인: 날짜·시각
① 새 발표   [발표 내용] · 출처 · 공개 시각
② 관측      [해당 종가 반응] · 세션일
③ 해석 변화 [기존 A 유지 / 반론 추가 / 판단 보류] · 이유와 근거
④ 다음 확인 [예정된 공식 발표] · 일정 / 미정
```

이전 읽기와 현재 읽기에 공통된 사실 ID·대상·기간이 있을 때만 비교한다. 새 근거가 빠지거나 출처가 취소되면 **철회/수정**, 수집 실패나 시간이 오래되어 확인할 수 없으면 **확인 불가**, 별도 근거 없이 이전 결론을 유지할 수 없으면 **판단 보류**다. 이 상태는 예측 적중 여부가 아니다. 이력이나 사전 기대치가 없으면 ‘이전과 비교할 기록 없음’으로 표시한다. 최신 시각에 재생성됐다는 사실을 데이터가 최신이라는 뜻으로 쓰지 않는다.

### 내러티브의 생애주기 제안

후보 → 관측 중 → 새 근거 또는 반론 추가 → 해석 보류·수정 → 비활성/보관. 후보와 단계는 내부 정리 상태이지 투자 신호가 아니다. 수집 건수·새로움은 어떤 이야기를 읽을지 **후보를 찾는 신호**일 수 있으나 진실성이나 가격 인과의 강도로 표현하지 않는다. 상충하는 주장은 한쪽을 자동 승자로 만들지 않는다. 같은 주제의 ‘아무 변화 없음’은 기존 근거가 여전히 유효할 때만 짧게 보이고, 수집 불능을 변화 없음으로 오인하지 않는다.

### 예시: 반도체와 AI 인프라

아래는 **배치 예시**이며 현재 투자 판단이나 검증된 원인 규칙이 아니다.

```text
반도체와 AI 투자 | 업종 가격은 약해졌지만 수요 훼손 여부는 확인 중
관측: 업종 가격의 해당 세션 변화 + 공개된 산업 매출·기업 실적의 각 기준 시점
해석 A: 실적·주문 기대가 낮아지는 경로  → 확인: 새 공시·전망, 반대: 유지·상향 공시
해석 B: 위험 축소·포지션 조정 경로       → 확인: 신뢰 가능한 포지션 자료, 없으면 미확인
반론: 성장률이 둔화해도 매출 수준은 늘 수 있고, 주문 지연이 수요 소멸을 뜻하지 않음
다음: 공개 예정 실적·산업 통계 → 결과가 어느 고리를 바꾸는지 확인
자세히: 매출 수준 / 전년 증가율 / 증가율 변화(pp) / 가격은 서로 다른 지표
```

WSTS의 8월 통계는 10월 5일에 공개된 3개월 이동평균이다([SIA 발표](https://www.semiconductors.org/year-to-date-global-semiconductor-sales-top-1-trillion-through-august/)). 과거 시간선에서 10월 5일 이전에 이를 알려진 사실로 끼워 넣지 않는다. [추가 직접 독해](CONTINUED-F.md)에 적힌 성장률 차트와 현장 발언은 해석 구조를 이해하는 참고이며 가격 하락의 원인이나 미래 경로를 증명하지 않는다.

## 기존 화면 9개와 연결

| 화면 | 제공할 역할과 연결 |
|---|---|
| 오늘 | 중요도가 높은 변화 1~2개와 ‘무슨 사실이 바뀌었나’를 짧게 보여 주고 시장 상태·관련 테마로 연결한다. 브리핑·뉴스는 오늘의 하위 경험으로 사건·원문·공개 시각을 제공한다. |
| 시장 상태 | 지수·시장 참여·금리·신용의 현재 관측과 상충 해석, 다음 공식 이벤트별 분기를 하나의 결론 아래 엮는다. 시장 폭과 심리는 독립 위젯을 늘리기보다 해당 논리의 증거로 통합한다. |
| 매크로 | 금리·달러·원자재·신용 변화를 보여 주고 기업 자본비용·수요에 전달될 수 있는 경로와 반대 설명을 연결한다. 공개 신용지수로 사모신용 상황을 대체하지 않는다. |
| 기술적 분석 | 내러티브에 등장한 지수·종목의 동일한 기간 차트와 가격 수준 후보를 보여 준다. 차트 패턴을 원인·예측이나 매매 지시로 취급하지 않는다. |
| 테마·섹터 | AI 수요 → 수주·자금 → 전력·장비 → 공급·인도 → 수익·현금흐름의 단계와 각 병목·반대 근거를 표시한다. 근거가 없는 고리는 미확인으로 둔다. |
| 스크리너 | 이야기에서 파생 가능한 **관측 조건**만 사용자가 직접 확인할 수 있게 연결한다. 대상·조건 계산 가능·필터 통과·표시 행의 분모와 누락을 각각 밝히며 이야기의 인기도로 종목을 추천하지 않는다. |
| 종목 | 관련 이야기, 회사가 공시한 역할, 실적 발표 전 기대·실제·다음 전망·이후 가격 반응을 별도로 보여 준다. 회사와 공급망 연결은 확인된 문서가 있을 때만 표시한다. |
| 포트폴리오 | 입력된 보유 항목의 공통 업종·테마 노출이 확인되는 범위와 미확인 범위를 보여 주고 일반적 선택지의 조건과 비용을 설명한다. 개인 맞춤 매매 지시는 하지 않는다. |
| 리서치 라이브러리 | 성장률과 가속도, 수주와 매출, 신용과 자금조달의 차이, 관련 역사적 사례·반론을 설명한다. 현재 이슈로 되돌아갈 수 있게 한다. |

링크를 따라가면 해당 주제와 기준 시점을 가능한 범위에서 유지하고, 직접 화면에 들어온 사용자도 대상·시각을 볼 수 있어야 한다. 한 화면의 사실과 다른 화면의 같은 사실은 같은 근거 ID·단위·시점으로 연결한다. 화면마다 다른 날짜가 정당하게 필요하면 이유를 보인다.

## 정보 구조와 갱신 운영 제안

1. **관측 수집:** 이미 있는 가격·매크로·기업 공시·이벤트·뉴스·연구 자료를 먼저 이용한다. 각 자료에 출처, 대상, 기간, 발표/관측 시각, 이용 가능 시각, 수집 시각, 수정·이월 여부를 보존한다. 자료 확보·사용 권한과 실제 비용은 구현 전에 확인한다.
2. **후보 발견:** 뉴스와 기존 리서치 프레임을 이용해 질문별 이슈 후보를 찾는다. 새 주제 미분류·동일 기사 재인용·한국과 미국 사건의 혼합을 검토한다. 기사 수나 댓글 수는 관심의 단서이지 증거 품질이 아니다.
3. **연결·구성:** 각 이슈는 관련 사실, 출처가 있는 주장, 가능 해석, 반론, 예정 이벤트와 연결한다. 상대 주장 간 근거가 독립적인지와 정보 시점을 확인한다. 수치가 없는 가설을 관측 수치처럼 채우지 않는다.
4. **변경 판단:** 이전 발행본의 실제 내용·근거와 새 사실을 비교한다. 중요 사건·정정·새 반론·기준 갱신은 재검토 후보지만, 작은 문구 변화나 단순 수집 시각 변화로 매번 새 내러티브를 만들지 않는다. 실제 갱신 주기와 AI 사용량은 기존 워크플로·공유 예산 안에서 운영한다.
5. **발행·보류:** 출처와 시점이 확인되는 관측만 발행한다. 새 생성에 실패하면 이전 읽기를 현재 근거와 대조해 쓸 수 있는지 확인하고 원래 작성 시각과 지연을 표시한다. 대조할 수 없거나 현재 사실과 모순되면 해당 해석은 보류한다. 새로 작성하지 못한 사실을 숨기지 않는다.

‘자주 바뀌는 이야기’에 대응한다고 매분 AI 호출을 약속하지 않는다. 가격·거시·기업 공시마다 데이터 주기가 다르며, 공식 발표와 가격 마감의 불일치·누락은 각기 표시한다. AI 생성 글은 원천 관측을 대체하지 않고 AI가 이용한 사실과 문장을 추적할 수 있어야 한다. 사용자가 묻는 AI 응답도 동일한 사실·기준일을 참조하도록 기존 AI 근거 전달 경로부터 점검한다.

## 상태, 반응형 및 접근성

- **초기/로딩:** 이전 읽기가 있으면 그 날짜를 유지한 채 갱신 중임을 표시하고, 없으면 표시할 정보가 아직 없음을 명확히 한다.
- **일부 누락:** 확인 가능한 내용은 보여 주되 빠진 근거가 설명에 어떤 제한을 주는지 밝힌다. 실제 미공개, 아직 미수집, 수집 실패를 구분한다.
- **지연·오래된 해석:** 한 카드의 상태는 최신/지연/참고/없음 중 하나로 간결히 표시하고, 각 원천의 날짜·이유는 상세에서 열람한다. 실패했을 때 가짜 ‘변화 없음’이나 오늘 날짜를 붙이지 않는다.
- **의견 대립·정정:** 서로 다른 출처와 시점, 정정의 이유를 나란히 놓는다. 개인 의견·소문·익명 보도·공식 발표를 구별한다.
- **모바일·태블릿:** 결론·변화·핵심 차트를 우선하고 근거와 반론은 같은 순서의 펼침 영역에 둔다. 표의 주요 열, 가로 스크롤 힌트, 상세 링크가 손가락으로 접근 가능해야 한다.
- **접근성:** 키보드로 펼침·차트 대체표·출처에 접근하고 포커스가 유지돼야 한다. 변화·지연·반론을 색만으로 표현하지 않으며, 차트에는 제목·축·단위·텍스트 요약을 제공한다. 날짜나 용어 정의를 마우스 hover에만 숨기지 않는다.

## 단계와 검증 가능한 수용 조건

1. **현행 확인:** 현재 main에서 시장 읽기, 뉴스 묶음, 테마·종목·스크리너·AI 응답의 실제 동선과 데이터 기준을 데스크톱·모바일·태블릿에서 관찰한다. 정적 코드가 존재한다는 사실을 화면 제공의 증거로 삼지 않는다.
2. **작은 수직 연결:** 하나의 실제 시장 이슈를 골라 기존 시장 사실 → 이야기 → 테마 → 종목/스크리너까지 동일 근거 ID로 연결한다. 내용·시간과 누락 상태가 화면마다 어긋나지 않아야 한다.
3. **변화 기록:** 실제로 기록된 이전/현재 발행본만 비교해 신규 사실·반론·정정·보류를 구분한다. 10월 5일 발표 자료는 이전 날짜 재생에서 보이지 않는 사례, 수정과 지연 사례를 검증한다.
4. **심화와 검증:** AI 수요·설비·자금·수익 흐름을 공개 근거가 있는 고리부터 확장하고 나머지는 미확인으로 남긴다. 독립 원천 중복·기대치 미보유·지연된 종가·표본 부족·모델 오류·인용 실패·기존 텍스트의 모순에 대한 테스트를 실시한다.
5. **사용자 동선 확인:** 직접 진입, 뒤로 가기, 화면 간 기준시점 유지, 작은 화면 표·차트, 키보드·스크린리더, 실패·정정·빈 상태를 실제 브라우저에서 확인한다. 지표 기준·원문·의견의 구분을 사용자가 이해할 수 있는지 검토한다.

완료 판정에는 근거의 링크가 실제로 주장과 연결되는지, AI가 의견을 사실로 바꾸지 않는지, 새 정보가 없을 때 변화했다고 말하지 않는지, 과거 기록에 미래 자료가 섞이지 않는지, 상충하는 주장이 유지되는지, 매매 지시·미검증 확률·가격 목표가 없는지를 포함한다.
