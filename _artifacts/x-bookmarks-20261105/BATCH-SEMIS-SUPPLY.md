# 반도체·AI 공급망 추가 직접 독해와 반영 설계

기록: 2026-11-05. 다음 4건은 인증된 X 브라우저에서 본문을 이번에 직접 읽었다. 글이 작성된 날짜는 사용자가 북마크한 날짜가 아니며, 아직 10월 이후 저장분 전체를 열거한 것은 아니다. 종목 목록은 분석의 대상일 뿐 매수 목록이 아니다. 각 항목에서 실제 확인 범위와 미확인 범위를 따로 적는다.

## 1. 메모리 장기 공급 계약: 기간과 이익의 지속성

- [Trader Jesse, 10/28 글](https://x.com/Trader_Jesse_/status/2115383561234821175) 본문 전체, 화면에 열린 작성자 후속 글 4건과 제3자 댓글 일부, [인용한 동일 작성자의 요약 글](https://x.com/Trader_Jesse_/status/2115381350844997906)을 직접 읽었다. 본문 자체에 첨부 이미지는 없었다. 모든 답글의 대댓글과 인용 목록 전체는 읽지 않았다.
- **사고 흐름:** 메모리 기업이 낮은 배수로 거래되는 이유를 작성자는 이익이 얼마나 지속될지 모른다는 할인으로 설명한다. 고객이 더 긴 공급 계약을 요청한다면 공급량·가격·현금흐름의 가시성이 높아질 가능성을 세우고, 동일한 연간 현금흐름의 5년과 10년 현재가치를 비교한다. 글은 요청 단계이지 체결이 아니며, 기간이 길어졌다고 기업가치가 곧바로 같은 비율로 변하는 것은 아니라고 밝힌다.
- **반론과 검증:** 화면의 [한 답글](https://x.com/afterwork2604/status/2115399884744601846)은 파기의 경제적 부담과 계약 세부 공개가 핵심이라고 지적한다. [BusinessKorea 10/28 보도](https://www.businesskorea.co.kr/news/articleView.html?idxno=279863)는 일부 중국 클라우드 사업자의 장기 공급 요청을 보도하면서 확정 계약이 아니고 조건도 불명확하다고 적었다. 이는 익명 산업계 취재 보도이지 당사자의 계약 공시가 아니다. 할인율 10%, 연말에 같은 현금흐름을 받는다는 가정에서 연금계수 `(1 - 1.1^-n) / 0.1`은 5년 약 3.79, 10년 약 6.14이고 상대 차이는 약 62%다. 이 계산은 숫자만 확인한 교육용 민감도이며 장래 영업이익이나 주가를 증명하지 않는다. 가격 연동·최소 물량·해지 조건이 불명이면 계약 기간을 고정 매출이나 이익 보장으로 환산하지 않는다.
- **표현 설계:** ‘계약 요청 → 협의 → 체결 → 가격·최소 물량·해지 조항 공개 → 실제 인도’ 단계를 사건 시간선으로 분리한다. 기존 연구 프레임 `contract-duration-multiple`에는 이미 현가 설명이 있으므로 새 교과서를 중복하지 말고, 테마·종목 화면에서 해당 사건과 공개된 조건만 연결한다. 분기 실적 옆에는 `가격 방식: 미공개`, `최소 물량: 미공개`, `해지 조건: 미공개`를 둘 수 있다. 기업별 목표주가·배수나 추천으로 변환하지 않는다.

## 2. 데이터센터: 발표 용량, 전력 인입, 실제 가동

- [Nuradu, 10/20 글](https://x.com/NURadu_/status/2112457108239405213) 본문 전체와 화면에서 열린 댓글·작성자 답글 일부를 직접 읽었다. 본문에 첨부된 차트는 없었다. 표시된 답글 6건의 전체 대댓글·인용과 작성자가 예고한 별도 아티클은 확인하지 않았다.
- **사고 흐름:** 부지만 보유 → 건물 완공 → 실제 사용 가능한 전력과 냉각 확보 → 고객 서비스 가동 및 현금흐름의 단계를 나누어, 같은 발표 MW여도 공급 가능 시기와 계약 조건이 다르면 동일 자산으로 볼 수 없다고 말한다. 전력 공급 ‘계약’과 ‘오늘 사용할 수 있음’의 차이를 분명히 짚고, 가동 중이라도 건설비·금융비·유지비를 감당하지 못하면 수익성이 보장되지 않는다고 스스로 제한한다.
- **근거의 범위:** 작성자의 단계 분류는 유용한 분석 틀이지만 구체 기업의 시설·가동률을 입증하는 자료는 아니다. [미국 에너지부의 대형 전력부하 설명](https://www.energy.gov/oe/articles/microgrids-large-electric-loads-grid-support-how-leverage-microgrids-support-utilities)은 데이터센터 구축에 계통 용량과 연결 시기가 제약이 될 수 있음을 설명한다. [버클리연구소 대기열 자료](https://emp.lbl.gov/queues)는 발전·저장 설비의 계통 연결 대기열로, **데이터센터의 수요 접속 대기열과 다른 모집단**이다. 이 자료의 대기 시간·성사율을 개별 데이터센터에 대입하지 않는다.
- **구현 가능한 정보 구조 제안:** 테마의 기존 AI 투자 흐름 안에 `계획 MW / 계약 MW / 인입 가능 MW / 가동 MW`를 서로 합산하지 않는 별개 항목으로 두고, 회사·시설·지역·문서별 적용 기간·전력회사 확인 여부를 보여준다. 전력 계약, 실제 계통 인입, 고객의 가동은 상태 전이가 단방향이라고 추정하지 않는다. 계획·계약이 취소·변경된 경우 기존 기록과 수정 사유를 보존한다. 데이터가 비공개면 ‘미공개’, 수집 실패면 ‘수집 실패’로 분리한다. AI 서비스 매출이 특정 시설의 공시 값으로 연결되지 않으면 시설별 수익으로 계산하지 않는다.

## 3. 산업의 이익이 누구에게 언제 전해지는가

- [Trader Jesse, 10/31 글](https://x.com/Trader_Jesse_/status/2116233205116481850)의 본문 전체와 표시된 작성자 후속 글 3건을 직접 읽었다. 인용된 예전 글은 화면의 미리보기만 보았으며, 그 원문과 전체 인용·대댓글은 열람하지 않았다. 본문에 도표는 없었다.
- **사고 흐름:** 여러 국가와 기업을 보는 이유는 종목 수집이 아니라 `수요 발생 → 공정의 병목 → 가격 결정력 → 신규 수주 → 매출·이익 → 기대에 반영된 가격`의 시간차와 누가 이익을 확보하는지 파악하기 위해서다. 같은 빅테크 CAPEX가 모든 장비·메모리·광통신 기업에 같은 속도로 반영되지는 않는다. 글에서 언급한 개별 기업의 고객 관계, 수익 기여, 증설·수주를 이 글 자체가 증명하는 것은 아니다. ‘청산 때문에 내렸다’는 저자의 대안 설명도 투자자별 거래 증거 없이는 가설이다.
- **구체 반영:** 테마 상세의 기존 세부 테마·종목 표에 `공급망 역할`, `확인된 수요/수주`, `실적 반영 기간`, `제약·반대 근거`, `원문`으로 펼쳐지는 근거 행을 제안한다. 역할 관계는 공식 공시 또는 회사 IR 등에서 확인한 범위만 연결하고, 업체명이 비슷하다는 이유로 종목을 추정하지 않는다. 재무·가격은 각각 자기 기준일을 갖게 하며 한국·미국·일본·대만을 한 집합으로 섞지 않는다. 스크리너의 결과는 각 조건의 충족/미충족/미확인을 보여줄 뿐 업종 관련성을 매수 추천으로 바꾸지 않는다.

## 4. 메모리 호황은 지속적인 가격결정력인가, 다시 돌아오는 순환인가

- [Chamath, 10/30 X 아티클](https://x.com/chamath/status/2115921893786280267)의 공개 본문 전체를 읽었다. 첨부 4장 중 3장(고점 대비 하락 비교, 마이크론 매출총이익률 추이, 별도 연구의 목차)을 직접 보았다. 나머지 이미지 1장, 표시된 답글 68개와 인용 전체는 보지 않았다. [연결된 Social Capital 글](https://research.socialcapital.com/p/memory)은 공개 소개문 뒤의 심층 연구가 유료 회원 전용으로 표시되어 있어 해당 전문은 열람하지 않았다.
- **사고 흐름:** 기록적 현재 이익과 고점 대비 약세가 공존하는 현상을 제시한다. AI 수요와 공급자 협상력 강화가 사이클의 구조를 바꿀 수 있지만, 반대로 신규 공장·경쟁 공급 확대·고객 재고 소화로 가격과 출하가 동시에 약해질 수 있다고 놓는다. ‘산업이 영구적으로 구조 전환했다’와 ‘과거의 반복이다’를 확정하지 않고 최종 수요·결제 주체·재고·증설 시점을 다음 질문으로 제시한다.
- **시각자료 판독:** FY2016~FY2026 막대는 마이크론 **GAAP 매출총이익률**이며 세후 순이익률이나 현금흐름이 아니다. FY2023 약 -9%, FY2026 80.7%로 표기됐고 FY는 회계연도다. [마이크론 FY2026 공식 실적 발표](https://investors.micron.com/news/press-release/2026/Micron-Technology-Inc--Reports-Record-Fiscal-Fourth-Quarter-and-Full-Year-2026-Results/default.aspx)는 FY2026 매출 1,331.88억 달러, FY2025 373.78억 달러, FY2026 GAAP 매출총이익률 80.7%를 공시해 해당 두 연도의 수치와 부합한다. 계산상 매출 증가율은 약 256.3%다. 이것은 과거 실적 확인이며 이익 지속성의 검증이 아니다.
- **차트 해석 주의:** 또 다른 막대는 각 회사의 2026년 종가 고점에서 10/29 종가까지의 낙폭을 비교하고, S&P 500의 고점은 별도 날짜라고 표시한다. 본문에는 대략 22~65%, 확인한 그래프에는 23~60%로 나타나 범위가 다르다. 표본·기준시점 또는 반올림 차이일 수 있으나 원자료 대조 전 이유를 단정하지 않는다. 개별 고점 날짜가 다른 낙폭 비교는 같은 기간의 수익률이나 자금유출 비교가 아니다. 중국 업체 점유율·증설 시점·재고 원인 등 다른 수치는 이번에 독립 검증하지 않았다.
- **제품 설계:** 산업 상세에 `공급·재고·가격·마진·주가 기대`를 하나의 숫자나 점수로 합치지 말고 각 관측의 기간과 출처를 나란히 둔다. 실제 마진의 회계 기준과 연도, 기업 공시의 CAPEX 계획·가동 예정일, 계약 상태를 각각 구분한다. 공급이 늘어나면 구매자의 원가 부담 완화 가능성과 공급자의 가격·마진 압박 가능성을 동시에 설명하되 확인 가능한 데이터가 없으면 가설로 남긴다.

## 기존 구조와 우선 개편 제안

| 현재 코드에서 확인한 기반 | 제안과 확인할 공백 |
|---|---|
| `src/domain/research/packet-20261028-x-bookmarks.js`에 계약 기간과 데이터센터 단계가 교육 프레임으로 이미 존재 | 프레임의 교훈을 재작성하기보다 최신 사건의 상태·조건·출처와 연결한다. 과거에 읽었다고 기록된 자료를 이번 전수 재독으로 세지 않는다. |
| `src/domain/themes/ai-capex-flow.js`와 `src/ui/components/theme-strength.js`에 AI 설비투자 분해 및 납기 참고가 있다 | 2026-08 투자 분해와 2026-09-14 납기는 과거 인용이다. 정적 코드에서 납기 기준은 `title`에 들어가므로 터치·키보드에도 보이게 할지 실제 화면을 확인한다. 코드의 ‘칩은 제때’라는 문장은 같은 배열의 HBM 40~52주 등 품목별 차이를 흐릴 수 있어 실제 수요·계약별 증거 없이 현재 병목의 확정 서술로 확장하지 않는다. |
| `src/ui/pages/themes.js`에는 세부 테마 구성과 종목 간 가격 차, 데이터 기준이 있으며 `src/ui/pages/screener.js`에는 FCF 마진·CAPEX 강도 조건이 있다 | 계획·실제 가동·수주와 재무 흐름은 같은 지표가 아니므로 별도 근거와 기준일을 연결한다. 현장 운영 현황을 FCF나 가격으로 추정하지 않는다. 실제 화면과 각 데이터 수집 가능성은 브라우저·원천 확인이 필요하다. |

**구현 수용 예:** 장기 계약 요청의 보도만 있으면 ‘요청/조건 미공개’로 표시하고 체결·고정가격으로 바꾸지 않는다. 전력 연결 계획만 있으면 가동 MW를 0 또는 발표 MW로 추정하지 않는다. 회계연도 총이익률을 분기 영업이익률과 섞지 않고, 기업별 고점 이후 낙폭은 공통 기간 수익률과 분리한다. 기존 참고 납기 수치에는 관측 당시 날짜를 시각적으로 표시한다. 누락·정정·접근 불가와 출처 충돌은 조용히 숨기지 않는다.
