## #59 테마와 순환매

[원문](https://x.com/AlexZio00/status/2111281262875095429)은 정책·기술·지정학 사건 → 기대와 주가 → 초기·가속·과열·붕괴의 생애주기 → 대장주와 2·3차 종목의 시간차 → 거래량과 실적을 통한 확인 순서다. 투자자가 테마의 발생 배경과 기업의 실제 매출을 다른 질문으로 보는 데 유용하다. 단계별 소제목과 예시가 읽기 쉽지만, 숫자·대상·사례를 실증한 데이터와 비교군은 제시하지 않는다.

**비판적 검토:** 산업의 기대만으로 가격이나 관련성을 설명할 수 없고, 큰 종목이 반드시 먼저 움직이거나 2차 종목이 일정 시차 후 움직이는 보편적 규칙도 입증되지 않았다. 3차 종목 상승이 곧 과열·대장주 약세가 곧 테마 붕괴라는 판정은 반례와 객관적 정의가 필요하다. 상대성과·거래량 변화만으로 자금이 한 종목에서 다른 종목으로 이동했거나 특정 주체가 매도했다고 볼 수 없다. 실적이 없는 기업의 PER 사례도 해당 수익의 의미와 기준을 확인해야 한다. 글의 단계별 진입·청산 제안은 제품의 개인별 매매 지시로 옮기지 않는다.

**AIO 인계:** `src/ui/pages/themes.js`의 기존 RRG·관련 종목·사건을 확장해 `이야기/사건 → 관측된 섹터와 구성종목의 가격 상대성과 → 기업의 확인된 사업 노출 → 발표된 실적 → 다음 확인 자료`를 연결하는 방안을 검토한다. 단계는 검증 전 판정 라벨 대신 확인 질문으로 둔다. 종목별 역할·공시일·매출 기여의 공개 여부와 서로 다른 구성집합을 드러낸다. **수용:** 가격의 상대적 상승과 실제 순유입을 구분, 저자 정의에 맞는 대장주·비교집합과 기준일을 명시, 관련 사업 매출 미공개 시 추정하지 않음, 대장주와 나머지 종목이 반대로 움직이거나 수요가 지속되는 반례를 함께 확인한다.

## #60 거래량의 진실

[원문](https://x.com/AlexZio00/status/2111700787747590238)은 가격 방향과 거래량을 결합한 네 경우 → 거래량 급증의 여러 해석 → 돌파 → 예외 다섯 가지 → 거래량이 알려주지 않는 참가자·목적 순서다. 신고가·거래 제한·갭·액면분할·만기와 지수 변경 등 기계적인 해석의 한계를 스스로 함께 제시하는 구성은 유용하다. 20일 평균의 1.5~2배와 신고가 돌파의 성과에 관한 주장은 원문에 검증 가능한 표본·구체 출처가 충분히 제시되지 않아 독립 확인 전이다.

**비판적 검토:** 모든 체결은 매수와 매도가 짝을 이룬다. 가격 상승과 거래량 증가만으로 누가 더 ‘확신’했는지, 신규 기관 매수·매도자의 소진·공포의 끝을 알 수 없다. 52주 신고가 위에도 더 오래 보유해 손실인 투자자가 있을 수 있고 사상 최고가라도 보유자가 전혀 팔지 않는다는 뜻은 아니다. 거래량의 차이는 참가자 수·유동성·주식 수·거래 시간·분할 조정·기업 이벤트에도 좌우된다. 가격 움직임에서 섹터 간 실제 자금 이동을 계산하거나 만기일 거래를 모두 포지션 청산이라고 단정하지 않는다.

**AIO 인계:** `src/domain/screener/setup-profile.js`의 기존 거래량·상대강도 후보와 기술적 분석 화면의 가격/거래량을 연결한다. 종목의 당일 거래량을 해당 종목의 과거 분포·동일 세션과 비교하고, 가용할 때 거래대금·유통주식 회전율과 기업 이벤트의 출처·기준일을 별도로 보여준다. 실제 거래대금이 없을 때 단순 종가×거래량은 근사치로 명시한다. **수용:** 분할 전후 조정 불일치, 평균기간 및 결측·0, 유통주식 수 부재, 미국 정규장/장외 차이와 장중/종가 데이터 구분, 저거래량 신고가 및 재이탈 사례를 검증한다. 어느 경우에도 기관의 의도·참가자 구성을 가격과 거래량만으로 확정하지 않는다.

## #66 공급 충격과 촉매의 시간

[원문](https://x.com/AlexZio00/status/2114952002182713716)은 촉매 발생 → 해석 → 반영 → 소멸의 틀로 시작해 공급·수요 충격을 구별하고 이익 영향·지속기간·인식 속도를 묻는다. 사건을 섹터와 개별 기업에 이어 그 영향이 언제 확인될지 물어보는 것은 내러티브 설계에 유용하다. 현재 글은 예시 중심의 설명이며 각 체제에 대한 체계적 관측·대조군이나 기업별 효과 계산은 제시하지 않는다.

**비판적 검토:** 공급 쇼크가 언제나 일시적이고 가격이 원위치하며 수요 쇼크가 더 오래간다는 법칙은 성립하지 않는다. 복구 시간, 재고, 대체 공급, 가격 계약, 정책과 수요의 동시 변화에 따라 달라진다. 사건이 알려진 시각과 주가 갭만으로 시장의 사전 기대나 반영 정도를 측정할 수 없다. 영향 금액을 계산하지 못한다고 사건이 무의미한 것은 아니지만, 미확정 숫자를 만들어서는 안 된다. 발생→소멸을 자동 확정하거나 단계에 근거해 매매 시점을 제시하지 않는다.

**AIO 인계:** `src/domain/market-day/facts.js`의 사건·가격과 `src/domain/briefing/day-account.js`, 테마·기업의 기존 사실을 출발점으로 `발생 및 출처 → 공급/수요 전달 가설 → 회사별 노출과 상반된 영향 → 확인 가능한 계약·생산·실적 → 대안과 다음 발표`를 연결한다. 시장 사실의 현재 하루 집계가 장기 수정 이력을 이미 보유한다고 가정하지 않는다. **수용:** 사건 시각·관측 시각·종가 기준을 분리하고 회사별 노출이 없으면 미확인, 수정 공시는 이력을 유지, 유사 뉴스 중복은 하나의 원천 계보로 묶고, 공급 지속/복구 및 수요 상반 시나리오와 근거를 함께 제시한다. 사전 기대치가 실제로 확보되지 않으면 이미 반영 여부는 미확인이다.

남은 일: 각 링크의 인용 목록과 외부 원천·표지 #60/#66, 4막 목록의 다른 게시물을 따로 열어 기록한다. 각 글의 매매 조언, 경험칙과 사례는 정확한 근거 및 제품 정책 검토 전 수치화하거나 자동 판정에 사용하지 않는다.
