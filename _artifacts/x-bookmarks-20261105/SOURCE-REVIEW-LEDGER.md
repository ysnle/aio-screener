## 각 자료의 추가 기록 양식

1. 원본 URL, 최초·재열람 시각, 북마크 상태와 저장일 확인 방법. 저장일 확인이 불가능하면 ‘불명’으로 남긴다.
2. 본문, 작성자 후속 스레드, 댓글·하위 답글, 인용 글, 이미지·동영상·외부 링크를 각각 `전체 확인 / 일부 / 미확인 / 확인 불가 / 해당 없음`으로 기록한다. 전체 수가 확인된 매체만 `확인 수/전체 수`를 쓴다.
3. 저자의 핵심 주장과 사고 순서, 관측·해석·전망, 반대 사례, 이해관계를 구분한다. 데이터는 원천·대상·기준일·공표일·단위·정의·계산과 독립 확인 여부를 기록한다.
4. 글의 구성과 시각자료가 주장을 전달하는 방식·오해 가능성을 기록한다. 이미지나 영상 미열람 시 해당 매체의 품질을 평가한 것처럼 쓰지 않는다.
5. 현행 코드·화면과 차이, 적용할 사용자 질문·구체 설계·실패 상태·수용 시험·후속 확인 자료를 [통합 매트릭스](BATCH-INTEGRATION-MATRIX.md)에 연결한다. 실제 구현 및 브라우저 검증과 설계를 구분한다.
