## 핵심 판단

- 스크리너에 이미 존재하는 시장·테마·종목·이벤트·근거 기능의 연결을 우선 재구성한다. 화면은 결론 → 축이 있는 차트 → 사실과 반대 근거 → 자세한 자료 순서다. 직접 진입, 기준일, 빈 상태와 맥락 복원도 설계한다.
- 선택된 관심목록과 전체 시장, 고점 5% 이내와 실제 신고가, 가격 상대강도와 실제 자금 흐름을 혼동하지 않는다. 한 주간 글은 본문과 차트의 분모·재무 성장률·패턴 정의가 어긋나 보이므로 원장에 기록했으며, 공식 공시와 기준 비교 전 수치의 정오는 미확인이다.
- 거시·AI 분석은 공급·수요·가격·자본비용·수익화를 별개로 다룬다. 다른 단위의 차트 접합, 이중축·시차 조정, 선택된 기간의 상관을 예측이나 인과로 승격하지 않는다.
- 시장·AI 이야기는 기존 시장 사실과 해석을 활용하여 **현재 관측 → 이전과 달라진 사실 → 대안과 반론 → 다음 확인 사건**으로 연결한다. 공시·뉴스의 공개 시각과 종가 기준을 분리하고 새 반론이나 정정을 기록하되, 호출·갱신은 기존 공유 예산 및 주기와 결합한다. 구체적인 UX와 시스템 설계는 위 두 내러티브 문서를 본다.
- 시각적으로 간결하게 하되 날짜·기간·단위·출처·접근성 이름을 지우지 않는다. 로딩, 지연, 부분 누락, 수집 실패와 결과 없음은 서로 다른 상태로 설계한다.

## 재개 순서

1. 현재 X 목록을 끝까지 순차 열거하고 북마크와 인용·답글을 구별하는 원장을 만든다. 게시물 날짜는 저장 순서의 대용이 아니다. 삭제·비공개·X의 동적 정렬로 완전성을 증명할 수 없는 항목을 명시한다.
2. 각 파일의 ‘미열람’부터 원문, 스레드, 댓글·인용, 첨부와 외부 자료를 확인한다. 김대미 기사 24장과 Raoul Pal 기사 11장은 확인했으나 댓글·인용은 일부만 보았다. 결과와 당시 열람 시각을 갱신한다.
3. 연결된 한국투자증권 반도체 보고서는 표지·목차·요약과 일부 화면만 확인했다. 신한투자증권 745쪽 보고서는 발췌만 읽었고 PDF는 브라우저와 웹에서 접근되지 않았다. 이 둘을 전문 독해로 취급하지 않는다.
4. 중요 주장에 대해 공시·공식 원천과 공표시점·단위·정의·권리를 대조한다. 지금 문서의 개선안은 가설과 설계로서 정량 사실·실제 구현·화면 검증이 아니다.
5. 현행 main에서 직접 화면 동선을 검증하고, 다른 worktree의 과거 화면 감사는 재현할 후보로만 활용한다. 실측 이후 구현 배치와 우선순위를 조정한다.
