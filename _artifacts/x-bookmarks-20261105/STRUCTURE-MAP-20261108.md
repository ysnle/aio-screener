## 4. 이전 반영과 달라진 판단

1. **ai-infra-stage-gap → delay-or-demand-loss.** 단계 나열은 10/28 data-center-stages와 중복이었다. 새 틀은 바뀐 숫자의 종류(가동 연도 vs 주문·투자·잔고)로 판정하고, 가격·신용 지표는 판정에서 뺀다.
2. **FTD 출처의 확인 수준.** 계산 원천(나스닥 종합)과 그림 원천(QQQ)이 달라 CONSISTENT로 두었으나, 날짜·상승률은 AIO 이력으로 재현돼 VERIFIED 항목을 더했다.
3. **"새 출처 9건" 중 1건(blazingbees)은 10/30 원장에서 이미 읽은 글.** 수는 그대로 두고 감사 항목에 표시했다.
4. **반등 시도 문장.** 지난 반영에서는 리서치 레슨만 고쳤으나, 같은 단정이 시장 상태 화면의 두 문장과 코드 주석에도 있었다.
5. **MRVL "1,200억 달러".** 글은 거래 규모처럼 썼으나 실제로는 워런트 전량 확정 조건(상한)이다.
