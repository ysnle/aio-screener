# 실제 AI 질문과 응답 검토

2026-10-13 KST. 배포 브라우저 v57.44 / GPT-6 Luna / 공용 Worker. 최신 로컬 v57.47은 일시 사용 불가. 실제 배포 답변을 최신 작업본의 답변으로 인증하지 않는다. 개인 정보·실제 보유는 전송하지 않는다. 응답이 표시되는 동안 다른 화면으로 이동하면 최종 답변 확인이 끊길 수 있어 완료 확인 후 진행한다.

## A1 — 오늘: 기준일 충돌

질문: “현재 화면은 상단에 10/12 마감이라고 표시하지만 시장 판단은 10/9 종가 기준입니다. 최신 완료 미국장 판단으로 써도 되나요? 화면에 실제로 있는 근거의 기준일·관측값·해석을 구분하고, 누락되거나 오래된 근거는 추정하지 말고 5문장 이내로 설명해 주세요.”

완료: **최신 판단 사용을 거부하는 결론은 맞음 / 문장 후처리 품질 실패**.

실제 표시 중 주요 부분:

```text
※ Web Research 근거 미수신: 최신 사실·수치·원인 단정은 확인 보류합니다.
아니요. 화면에 표시된 10/12 마감일과 시장 판단의 기준일이 다르며, 제공된 근거만으로는 최신 완료 미국장 판단이라고 할 수 없습니다.
기준일과 해석
84, 미 10년물 5. 시장 폭도 10/9 기준으로 20일선 위 50.
누락·확인 필요
서버 산출물 시각은 2026-10-12T19:23:21. 21·미 10년물 5. ([apnews. com](https://apnews. com/article/f07713e8b2e438ac5903b50f5ce97235? utm_source=openai))
```

AP 검색 링크는 별도의 실제 클릭 가능한 링크로 제공되지만 “검색된 링크이며 답변 근거로 검증됐다는 뜻은 아님”이라고 표시. 현재 source publication 필터를 실제 호출해도 URL의 점/물음표에 공백이 삽입됨(`counterexamples.json`). 모델 원답과 렌더링 후처리는 분리해 조사해야 한다.

## A2 — 시장 상태: 조건 개수와 반증

질문: “기관 멀티에셋 PM 관점에서 이 시장 상태 화면의 혼조·집중 유지(조건 4/4)를 검토해 주세요. 조건 개수를 미래 확률로 바꾸지 말고, 금리·신용·시장 폭 중 현재 관측과 해석, 결론을 반증할 자료를 5문장 이내로 구분하세요. 최신 완료 종가가 없으면 그대로 보류하세요.”

실제 접수·분석 중 표시 확인. 최종 응답 확인 전에 거시 화면으로 이동했으므로 **답변 품질 미검증**. 사용자 경로의 navigation/생성 상태 관계도 후속 검증 대상. 미완료를 PASS로 세지 않는다.

## A3 — 거시: 2년물과 정책 경로

질문: “채권 애널리스트 관점에서 2년 국채금리가 연준 기준금리보다 높다는 이유만으로 추가 인상이 예상된다고 단정할 수 있나요? 이 화면의 관측·기간 프리미엄·물가·신용 연결을 구분하고, 같은 시점 근거가 없으면 보류하며 5문장 이내로 답하세요.”

완료: **개념 경계는 적절 / 근거 주입·후처리 개선 필요**.

실제 결론은 추가 인상을 단정할 수 없다고 답함. 기대 단기금리와 기간 프리미엄을 구분하고 동일 시점 자료 부족을 보류. 그러나 화면에는 물가 관측월/발표일이 있음에도 답변은 “화면의 물가 수치에는 관측 기준일이 명시되지 않았다”고 함. 화면 DOM과 AI 주입 근거가 일치하는지 확인할 필요가 있음. 본문 timestamp는 `2026-10-12T19:23:21. 408Z`, URL은 `newyorkfed. org`, `https://www. newyorkfed. org/…? stream=business`로 잘림. 별도 New York Fed 검색 링크는 표시됨. 검색 근거 미수신 경고가 반복된다.

전문가 관점: 모른다고 말하는 것은 좋지만, 화면에 있는 근거를 못 보는 것이 반복되면 자동 검색 비용과 사용자 불신이 늘어난다. 현재 evidence를 기준일·단위·기간과 함께 먼저 주입하고 unsupported 문장을 통째로 보류해야 한다.
