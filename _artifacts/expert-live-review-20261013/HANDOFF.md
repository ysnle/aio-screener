## 마감 기록

- 최신 로컬 v57.47의 8개 화면과 하위 탭을 직접 검토했다. 기관 PM·퀀트·애널리스트·트레이더·성과/리스크·13F/교육 담당자의 판단 질문을 기준으로 통합했다. 22개 검토 항목에는 실행 결함, 표현/정의 문제, 자료 공백, 미공개 기능의 잠재 위험이 함께 있으므로 ‘현재 사용자에게 발생한 버그 22개’라는 집계가 아니다.
- 배포 v57.44에서 실제 AI 8회 전송, 7회 완료를 확인했다. 최초 시장 요청 1회는 화면 이동으로 완료를 확인하지 못했고 재질문으로 완료했다. 공개 정보·교육 질문만 사용했으며 개인 보유는 전송하지 않았다. 최신 로컬 AI와 포트폴리오 실제 위험 계산은 연결/시세 제약으로 보류했다.
- 숫자·URL 파편과 역할/산업 약어→기업 후속 질문을 현재 함수로 재현했다. 시장·테마 AI는 현재 판정을 보류하는 점은 좋지만 실제 화면의 날짜·1개월 값·rank0 이유를 충분히 읽지 못한다. 미래 확률/주문을 만들어 내지 않는 경계는 유지할 가치가 있다.
- 수정 우선순위는 비교지수 계산 → AI 문장/질문 대상 → 공통 현재성/브리핑 기준 → 검증 모집단/모델 지문 → 테마 내부 순위 → 공시 범위/산업 원문 → 뉴스 창/교육·위험 문구다.
- 제품 소스는 변경하지 않았다. 필요한 수정과 이후 검증 절차는 REVIEW.md에 구체적으로 남겼다. commit/push/deploy는 실행하지 않았다.
- 마감 환경 확인(주 담당자): HEAD `47c2baa0` / version v57.47 유지. 이번 전용 server PID 35900 / port 8792만 정리하고 사용자 port 8947은 유지했다. 검토용 Chrome 2탭을 닫았다.

## 중간 기록 1 — 실제 실행과 답변

- 최신 로컬 desktop 사용자 경로: 11개 중 9개 PASS, uncaught error 0. 미국 스크리너는 최신 완료 미국장 10/12에 대해 artifact 10/9이므로 813개 모두 순위 보류. 이 실패는 정직한 데이터 admission이며 결함으로 집계하지 않는다. 배우기 목차 step timeout은 driver와 현재 DOM 대조 중이다.
- 로컬 뉴스 empty state에 `reason=all-news-outside-time-window · lastFetch=unknown`이 실제 노출된다. 사용자에게 검증 뉴스가 없다는 사실은 필요하지만 내부 reason 문자열은 이해를 돕지 않는다.
- 배포 v57.44 상단 10/12 마감과 시장 10/9 기준의 차이를 실제 AI에 질문했다. 답변 첫 문장은 최신 완료 판단으로 사용할 수 없다고 올바르게 답했다. 그러나 본문에는 `84, 미 10년물 5. 시장 폭도 10/9 기준으로 20일선 위 50.` 등 잘린 숫자와 `apnews. com`, `? utm_source`가 남았다. 검색 근거 미수신 경고와 AP 검색 링크가 함께 표시됐다. 최신 v57.47의 실제 답변은 localhost origin에서 일시 사용 불가라 아직 인증할 수 없다.
- 현재 source `src/ai/response/publication.js:50`은 문장을 소수점·URL의 점까지 나누는 정규식으로 자른 뒤 숫자 문장을 제거한다. 배포 답변의 파편과 일치하는 위험이다. 모델 원답 자체의 오류라고 단정하지 않는다.
- 독립 실행 검토: `portfolio-read.js:55`의 SPY return이 한 줄 주석 안에 들어가 valid SPY도 가격 지수를 반환하고 KR는 undefined가 된다. 실제 closure fixture로 확인한 계산 결함이다. 종목/지수 날짜 불일치는 현재 모델이 받아들이지만 실제 artifact의 날짜 불일치 발생은 미확인이다.
- 새 스트레스 사후 통계는 producer 첫 실행 전(`pending-first-producer-run`, bands 비어 있음)이라 현재 보이지 않는다. 소스의 중첩 표본/거래일 축 문제는 잠재 결함으로만 기록한다.
