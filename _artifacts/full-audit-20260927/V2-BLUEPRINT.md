## §7. 가족 개인 데이터 이관 — FOUNDATION에 빠져 있던 치명 항목

**문제**: v2를 Cloudflare(다른 주소)로 옮기면 브라우저 저장소는 **주소(origin)별로 분리**되므로, 현재 `ysnle.github.io`에 저장된 가족의 포트폴리오·원장·일지·관심목록·학습 메모는 **v2에서 보이지 않는다**. 현재 내보내기(`js/aio-workspace.js:1850`)는 **포지션 배열만** 내보낸다.

현재 개인 데이터 키(코드 검색 결과): `aio_portfolio_data` · `aio_portfolio_cash` · `aio_portfolio_ledger` · `aio_portfolio_journal_v1` · `aio_portfolio_fx_legs` · `aio_portfolio_pin`/`aio_vault_salt`(PIN 금고 — 암호화 상태) · `aio_watchlists`/`aio_watchlist_active`/`aio_watchlist` · `aio_price_alerts`/`aio_alerts_v1` · `aio_trader_profile`/`aio_user_profile_v1` · `aio-knowledge-learning-v1`(학습 진도·메모) · `aio_chat_history` · 설정류(`aio_theme`, `aio_beginner`, `aio_analysis_level` 등) · `aio_claude_api_key`(BYOK 비밀 — **이관 제외**, 재입력).

**절차(제안)**
1. **구 사이트 최소 수리에 "전체 백업" 추가**(II-2 항목 6으로 제안): 위 키 전부를 `{format:'aio-backup', version:1, exportedAt, origin, keys:{...}}`로 내보내기. 금고가 켜져 있으면 PIN 입력 후 복호화해 내보내거나, 암호문+salt 그대로 내보내고 v2에서 PIN으로 복호화.
2. v2 `/settings/backup`에 **구형 백업 가져오기**(형식 판별: 포지션 배열 JSON / aio-backup v1) + 미리보기 + 병합/덮어쓰기 선택.
3. M6 전환 체크리스트: 가족 각자 "구 사이트에서 백업 → v2에서 가져오기" 완료 확인 후 주소 전환. 구 사이트는 읽기 전용으로 3개월 유지하며 상단에 "새 주소로 이사, 백업 방법" 안내.
4. v2는 `navigator.storage.persist()` 요청 + 30일 백업 알림(Safari 7일 저장소 삭제 위험 대응, HANDOFF F-21).
