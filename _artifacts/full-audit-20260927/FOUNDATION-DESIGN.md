### 0-2. 처음부터 다시 싹 다 고쳐야 하나?

**설계 제안은 "코드를 백지부터 다시 짜기"보다 "별도 v2를 설계하고 검증된 부품을 선택적으로 이식"하는 방향이다.** 이는 검토안이며, 기존 사이트 동결·새 앱 구축·전환을 승인하거나 지시하지 않는다.

한 문장 근거: **지금 문제의 대부분은 "코드 품질"이 아니라 "설계 방향과 구조"에서 나오고(Part I-8), 그 구조 위에서의 부분 수정은 6개월간 수렴하지 못했다는 것이 측정됐다** — 반면 계산 로직·포트폴리오·SEC 수집·AI 수치 검증 같은 핵심 부품은 실제로 잘 만들어져 있어 버릴 이유가 없다.

**의도했던 구조(ADR-0001)**: 제공자 어댑터 → 검증 → 단일 증거 저장소 → 선택자 → 화면, UI는 fetch·저장소·전역을 직접 만지지 않음.
**실제와의 차이**: 같은 데이터가 **서버·브라우저·Worker 세 곳에서 따로** 수집되고, 계산은 **레거시·네이티브·파이프라인에 흩어져** 있으며, 새 계층(src/)은 옛 계층을 **대체하지 못하고 그 위에 얹혀** 서로를 전역으로 읽는다.

### I-7. UI/UX·디자인 체계 총괄 [에이전트 20, 12–16]

- **사용성 과제 결과**: T1(30초 시장 파악) **실패**(대표 점수 빈칸+설명 없음, 같은 내용 4페이지 분산) · T2(반도체 추세주) 가능하나 힘듦(하위 업종 필터 없음, 결과까지 긴 스크롤) · T3(NVDA 가능, **삼성전자 입력 안내 없음**) · T4(VIX 배우기) 사전은 우수하나 **화면에서 연결 안 됨** · T5(포트폴리오 시작) **우수** · T6(최신 여부) 배지가 암호 같음("일부 실시간 (16개)" 분모 없음).
- **정보구조**: 운영자 설정(API 키·GitHub·PIN)이 가족이 쓰는 메뉴 안에 섞임, "포트폴리오" vs "대가의 포트폴리오" 이름 충돌, 메뉴 밖 라우트 3개.
- **시각 체계**: 상승/하락 색이 미국식(초록=상승)인데 한국 가족 사용자 대상임을 명시한 적 없음 + **적용이 절반만 됨(CSS 캐스케이드 버그)**, 폰트 크기 30종, 상태 문구("판정 보류/BLOCKED/확인 중/미수신") 뜻이 섞임, 배지 과다, 면책 푸터가 모바일 화면의 20–25%.
- **접근성**: 대비는 AA 통과(본문 7.45:1), 스킵 링크 양호, 아이콘 버튼 라벨 누락 0 — 그러나 실제 제목 요소 9개뿐, 모든 라우트가 동시에 DOM에 존재.
- **개발자 관점**: "새 카드 하나를 만드는 공식 방법"이 없음(4가지 경로 공존) → 세션마다 다른 방식으로 추가 → 일관성 붕괴가 구조적으로 재생산됨.

### I-8. 왜 계속 고쳐도 좋아지지 않았나 — 근본 원인

1. **설계 기준점이 한 번도 재설정되지 않았다.** 제품 의도(가족 실매매·학습)와 헌장(공개 리서치 베타)이 달랐고, 모든 수정이 헌장 쪽 기준(증거·면책·게이트)을 강화하는 방향으로 누적됐다.
2. **덧붙이기식 이행.** 새 구조(src/)를 추가했지만 옛 구조를 지우는 것을 완료 조건으로 삼지 않았다 → 두 벌 유지 비용이 매 수정에 붙는다.
3. **국소 최적화의 반복.** 각 에이전트 세션은 "발견한 결함 하나 + 원장 기록 + 게이트 하나"로 끝났다. 전체 구조·화면 흐름·중복을 재설계할 주체와 문서가 없었다(설계 문서 2개 ADR vs 원장 수천 항목).
4. **fail-closed의 오적용.** 데이터 표시 원칙을 운영·배포 흐름에 적용해 1인 운영에서 정지를 양산했다.
5. **콘텐츠를 코드에 넣었다.** 종목 목록·일정·휴장일·참고자료가 코드라서, 콘텐츠 갱신이 곧 코드 수정·버전 범프·배포가 됐다.
6. **디자인 체계 없이 화면을 늘렸다.** 20개 화면이 각자 방식으로 만들어져 일관성·직관성 문제가 화면 수에 비례해 늘었다.

→ 이 여섯 가지는 **기존 코드를 유지하며 부분 수정하는 방식으로는 제거되지 않는다.** 그래서 설계부터 다시 세운다.

### IV-2. 페이지 명세 (요지)

**오늘 / 요약** — 사용자 질문: "오늘 시장 어때? 나는 뭘 봐야 해?"
1. 시장 날씨 카드 4개(미국 지수 / 한국 지수 / 금리·환율 / 변동성·심리) — 각 카드: 원값·변화·표준 구간 라벨(참고)·기준시각. **단일 종합 점수 없음**(I-5).
2. 오늘·이번 주 일정(FOMC·CPI·금통위·실적) — API 자동.
3. 핵심 뉴스 5(중복 없이 "뉴스 탭"으로 링크).
4. 내 종목 변화(보유 상위 변동, 포트폴리오 없으면 시작 안내 — 현 portfolio 빈 상태 패턴).
5. (선택) 섹터 히트맵 — 30초 파악용(Finviz 차용).

**종목 찾기** — "조건에 맞는 종목은?"
- **기본 = 둘러보기 모드**: 첫 화면에 필터 줄 + 결과 표(스크롤 0). 프리셋 칩(추세 강함·가치·배당·낙폭 과대·거래량 급증) = 필터 정의. 시장(미/한) 토글, 섹터·**하위 업종(반도체 등)**, 시총, 밸류(PER·PBR 범위 — TTM 명시), 수익률, RSI.
- 결과 열 기본: 종목·가격(기준시각)·1M/3M·시총·PER·추세 상태·순위(정렬용 표기).
- 행 클릭 → 종목 보기. "왜 이 순위?"는 아이콘(현 Why 서랍 이식).
- **연구 모드**(토글): 저장 화면·조건 편집·실행 이력·백테스트·출처 상세 — 현 작업공간 이식.

**종목 보기** — "이 종목 지금 어때?"
- 헤더: 이름(한/영)·가격·기준시각·시장 상태(휴장 인지).
- 요약 한 줄(규칙 기반 사실 요약: "52주 고점 대비 −8%, 50일선 위, PER 28(TTM), 다음 실적 10/29").
- 탭: 차트(가격+거래량, 이평, RSI) / 추세(단계·추세 템플릿 — 정식 정의) / 실적·밸류(SEC TTM, 동종 비교) / 이벤트·공시 / 뉴스 / 보유 기관(13F, 지연 명시).
- "이 화면에 대해 AI에게 묻기".

**시장 분석** — sentiment의 **단일 ViewModel 패턴**을 모든 탭의 표준으로. 각 탭 = 원값 카드 + 설명(용어 연결) + "심화"(접힘).

**내 투자** — 현 portfolio 기능 이식 + 표/차트 단일 가격 경로 + **전체 백업**(원장·FX·가정 포함, 스키마 버전) + "마지막 백업 N일 전" 안내 + 위험지표는 펼침.

**배우기** — 기본 화면 = "시작하기" 트랙(초보 경로). 원리 12장·산업 지도·대가 아이디어·사전. 각 레슨에 **라이브 예시 위젯**(예: VIX 레슨 안에 오늘 VIX). 모든 레슨은 `content/learn/*.md`(출처·검토일·연결 지표 front-matter).

### IV-3. 화면 공통 규칙
- 페이지 제목 = 질문형 또는 명사형 하나(명령형 금지).
- **상태 어휘 4개만**: `불러오는 중` / `기준시각 지남`(값 표시+흐림) / `참고용`(값 표시, 판단 근거 아님) / `데이터 없음`(사유 한 줄). "판정 보류·BLOCKED·REFERENCE·claim" 등 내부 용어는 화면에 쓰지 않음(연구 모드 상세에만).
- 면책: 첫 방문 1회 안내 + 하단 한 줄 링크(매 화면 대형 블록 폐지).
- 레이아웃: 데스크톱 전용(R474) — 좌측 내비 1개 + 상단 기준시각 표시줄, 1280/1440/1920 뷰포트에서 인수.
