## Cross-route contradictions found
1. **"실시간" framing vs. 31h-stale snapshot**: Home/briefing/signal/technical header badges use "실시간"/"LIVE" language and fresh-looking timestamps ("갱신: 30초 전", "일부 실시간 오후 06:13") while the actual priced data underneath is a snapshot dated 9/26 10:35 KST (briefing, macro) — a ~31h gap the app itself admits only in a sidebar connection-status string ("서버 데이터 31시간 경과").
2. **Weinstein Stage 1 vs. bullish MA stack** (technical page): Stage classification says "바닥 형성" (Stage 1/basing) while the same page's trend text says all timeframes are bullish-aligned with a rising 50/100/200 stack — internally inconsistent signal.
3. **Yield curve "no data" vs. displayed value** (macro page): "수익률 곡선 현재 관측값 미수신" directly contradicts the "2s10s +0.36%p · 정상 양(+) 기울기" figure computed and shown on the same screen from the same 2Y/10Y inputs.
4. **News count "0건" vs. visible list** (market-news, briefing): headline counters read "0건"/"자료 미확보" while a list of 8–12 dated items renders immediately below in the same viewport.
5. **"1일 경과" for 5-month-old data** (briefing footer "과거 참고 자료"): date-math bug — reproduced on both desktop and mobile passes, at two different times.

## Cognitive load for a beginner
- Best-designed for beginners: home, ticker, portfolio (clear empty states, short primary actions).
- Worst for beginners: screener (raw pipeline/debug jargon dominates the first screen), macro (ACM term premium/dealer gamma/TGA-repo-SOFR-OIS-MMF terminology with no beginner glossary link inline), atlas/principles (dense multi-paragraph "lens" essays, 12-17 analytical frameworks per page).
- The guide page's terminology dictionary (용어 사전) is a good beginner aid but is a floating button, easy to miss on first visit.

## How I would redesign the information architecture
1. **Collapse the 20-route sidebar into ~4 primary destinations** grouped by the site's own internal grouping (데일리 / 시장 분석 / 내 투자·도구), with sub-tabs instead of separate top-level nav items: (a) **Today** (home + briefing + market-news merged — these three currently show overlapping/duplicate data such as identical S&P 500/VIX figures and the same Telegram news list), (b) **Market Analysis** (signal + breadth + sentiment + technical + macro + fxbond + themes as tabs of one workspace, since they already cross-reference each other's data), (c) **Research Tools** (screener + fundamental + ticker + options, unified around a single ticker-search context so a user doesn't re-enter a symbol per page), (d) **Portfolio & Learn** (portfolio + principles + masters + atlas + guide).
2. **Merge home/briefing/market-news**: all three independently fetch and narrate the same S&P 500/VIX/KOSPI numbers with slightly different staleness labels — this is the clearest source of the "different numbers on two pages" risk and duplicated engineering surface.
3. **Promote the honest staleness state, don't bury it**: move the "서버 데이터 31시간 경과 — cron 지연" string from the sidebar diagnostic panel to the same header badge that currently says "실시간"/"LIVE", and stop using "실시간"/"LIVE" wording whenever the underlying snapshot is >2h old.
4. **Strip all internal/debug strings before shipping to users** (`DATA_SNAPSHOT`, `preset-balanced(hash)`, `mic_missing·...`, `atlas:tag-id`, "canonical theme-detail", "레거시 secondary surface") — these should be logged to console/telemetry only, never rendered in user copy. This is a quick, high-value fix (a lint rule banning raw snake_case/colon-prefixed tokens in user-facing template strings would catch most of these).
5. **Give the screener a "beginner mode"** that hides factor-engineering metadata by default (session/session-hash/SEC-normalization-version) behind a collapsed "데이터 출처 상세" disclosure, surfacing only rank/1M/3M/RSI/VCP with plain-language labels first.
6. **Create one real Privacy/Terms/Data-Sources page**, linked from the footer of every route (not only reachable by scrolling deep into the 사용 설명서), separate from the FAQ/strategy content currently sharing the guide route.
7. **Primary action per page**: most routes lack a single obvious next action; the redesign should give each of the 4 consolidated destinations one clear default question it answers (e.g. Today = "what happened", Market Analysis = "what's the environment", Research = "is this stock worth a look", Portfolio = "how am I doing").
