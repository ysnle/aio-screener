# 화면 품질 기준 — 2026-11-04 배치

소유자: "실제 화면에서 사용자에게 어떻게 보여질지 생각하면서, 사소한 퀄리티까지 신경쓰면서 작업하자."
모든 세션의 완료 조건에 더한다. 게이트 통과만으로는 완료가 아니다.

## 실제 화면으로 볼 것

데스크톱 1440 · 아이패드 768 · 휴대폰 390, 라이트와 다크 각각. 바꾼 화면은 스크린샷을 직접 열어 본다.

1. 숫자: 부호(`+0.0%`·`-0.0%` 금지), 자릿수, 단위, 천 단위 구분, 날짜 형식이 화면마다 같다. 같은 지표는 모든 화면에서 같은 값과 같은 기준일이다.
2. 글자: 잘림·말줄임·줄바꿈 한 글자 고아·라벨 겹침·축 라벨 충돌이 없다. 한국어 조사(이/가, 은/는)가 값에 맞는다.
3. 정렬: 열 기준선, 카드 높이, 여백 간격이 같은 줄에서 맞는다. 가로 스크롤 없음.
4. 상태: 로딩·빈·오류·지연이 공용 `renderDataState`로 같은 모양이다. '불러오는 중'이 영원히 남지 않는다. 'undefined'·'NaN'·'null'·빈 괄호가 안 보인다.
5. 상호작용: hover·pressed·disabled·focus 링이 모든 버튼에 있다. 탭·보기 전환이 3회 왕복해도 같은 결과다. 전환은 짧고 `prefers-reduced-motion`을 지킨다.
6. 문구: 태그라인·도움말 문단·보조 라벨·'읽는 법'·교과서 말투·이모지 없음. 화면 이름은 '매크로'. 출처 텍스트는 hover나 접힌 '데이터 출처'에만.
7. 구성: 섹션마다 시각 하나 + 짧은 해석, 깊은 내용은 접기. 원천 없는 위젯·근거 없는 등급 없음. 미국 우선.
8. 신선도: 기준일 배지는 `freshnessBadge` 하나로, 날짜가 실제 데이터 기준일과 맞는다.
9. 접근성: 대비 WCAG AA, 차트에 aria-label, 키보드로 모든 조작 가능.

## 보고

바꾼 화면마다 전후 스크린샷 경로와 위 9항 가운데 확인한 항목을 적는다. 못 본 항목은 못 봤다고 적는다.
