## 1. 한 줄 결론

숫자는 거의 다 맞다. 리뷰어들이 약 150개 값을 다시 계산했고 산술 오류는 0건이었다. 틀린 것은 다음 네 가지다.

1. 같은 사실에 화면이나 블록마다 다른 라벨이 붙는다.
2. 숫자의 기간과 날짜가 드러나지 않거나 틀린다.
3. 이미 가진 사건 데이터를 다른 블록이 쓰지 않는다.
4. 생산 단계의 추출 오류가 그대로 화면에 나온다.

여기에 구조 문제가 겹친다. 페이지가 길고(시장 개요 약 14블록, 매크로 폰 약 12화면), 같은 문장과 카드가 탭마다 반복된다. 그래서 개편은 **화면별 수선이 아니라 공통 원인 4개를 한 번씩 닫는 것**으로 설계한다.

## 4. 개편 원칙 (모든 화면 공통)

1. **사실 하나에 레코드 하나.** 화면에 나오는 판정 사실(요인 상태, 신용 수준, VIX 구간, PER, 실적 beat/miss, 흐름명)은 도메인 레코드 하나가 `{값, 기간, 기준일, 기준, 라벨}`을 갖는다. 렌더러는 라벨을 읽기만 하고 다시 판정하지 않는다.
2. **숫자는 기간·기준일과 함께 다닌다.** 겉 숫자 옆에 `5거래일`, `11/6`, `1주` 같은 표시를 단다. "오늘", "지난 24시간"은 기준일이 실제 세션일과 같을 때만 쓴다.
3. **사건은 하나의 색인에서.** 종목과 날짜를 키로 하는 사건 색인 하나(event-briefs, 실적 달력, 보도)를 브리핑, 뉴스, 종목, 포트폴리오가 같이 읽는다.
4. **페이지 = 판정 → 왜 → 무슨 일 → 다음.** 섹션마다 시각 요소 1개, 읽기 3-5줄, 접힘. 같은 문장이나 카드는 한 페이지 안에 한 번만, 같은 허브 안에서도 한 곳만 정본으로 둔다.
5. **생산 단계에서 막는다.** 추출 결과는 화면에 닿기 전에 생산자 검증 게이트를 통과해야 한다. 막힌 값은 비워 두고 '확인 중'으로 표시한다.

### 2단계: 단일 출처와 기간 표시 (위험 중간) — v59.85

- **2a 요인·신용·VIX 라벨 단일화.** `market-read` 판정 레코드에 라벨과 이유를 담는다. 매크로 연결 상자, 장 문장, 시장 상태 확인 조건, 오늘 칩이 모두 이 레코드를 읽는다. 신용 문구는 수준과 변화를 나눠 쓴다(예: "348bp, 20일 +33bp: 수준 보통, 확대 속도 부담"). 이미 충족했거나 이미 잃은 조건 문장은 생성 자체를 막는다.
  - 게이트: 라우트 전체 렌더 텍스트에서 같은 사실 id에 서로 다른 라벨이 붙으면 실패. 조건 문장의 임계값이 현재 상태와 모순되면 실패.
- **2b 흐름명 가드.** 시장 폭이 넓어지고 있을 때(50일선 위 20일 +10%p 이상이고 RSP가 앞설 때)는 '동반 약세' 계열 흐름명을 금지하고 '주도주 이탈·순환' 계열을 쓴다. 이 흐름명은 오늘 화면에도 같이 반영된다.
- **2c 기간·기준일 계약.**
  - 공용 `windowLabel`/`asOfLabel`을 만든다.
  - 매크로 "오늘" 문장은 기준일을 표시한다.
  - 브리핑 머리는 "11/6 미국 마감 이후"로 바꾼다.
  - 오늘 화면 히어로에 "5거래일 기준"을 단다.
  - 테마는 기간 선택 하나로 화면 전체(막대, 지도, 순위, AI 공급망, 상세 헤더)를 움직인다.
  - 게이트: '오늘', '지난 24시간'과 기준일이 다르면 실패. 테마 블록끼리 기간이 다르면 실패.
- **2d 종목 숫자 기준.**
  - 겉 PER과 성장률은 GAAP 최근 4분기로 스크리너와 같게 한다.
  - 조정 EPS PER과 Forward PER은 접힘에 라벨과 함께 둔다.
  - 적자 회사는 "적자"로 표시한다.
  - 재무 타일은 최근 4분기 성장률을 쓴다.
- **2e 스크리너.**
  - 순위 탭 기본 정렬을 순위로 바꾼다.
  - 동점은 반올림 전 점수로 가른다.
  - 검증 탭 겉에 "검증 모델 4요인 ≠ 현재 순위 6요인"을 한 줄로 밝힌다.
  - 한국 종가를 행에 내보낸다(생산자).

### 3단계: 화면 구조 재설계 (위험 중간~큼, 화면별 /prototype 후) — v59.86~

| 화면 | 새 구조 |
|---|---|
| 오늘 | ① 판정 + 6축 띠 시각(0 양호/3 중립/3 부담) + 5일 vs 1일을 맞추는 3줄 ② 핵심 사실 3개 + "연결해서 보면 → 브리핑" ③ 한국. 홈과 브리핑의 중복 카드를 없애고, 브리핑을 24시간 사실 목록의 유일한 정본으로 둔다. |
| 시장 개요 | 4섹션. ① 판정 + 6축 판정 표를 바로 아래에(폰은 '5일 전→지금' 칩 유지) ② "지수 vs 참여" 사분면 하나(순환인지 전반 약세인지 정리) ③ 무슨 일이 있었나 + 일정 ④ 다음: 흐름명, 시나리오, 확인 조건을 각각 한 번씩. 이야기, 1년 위치, 나머지 사분면은 접힘으로 보낸다. |
| 기술적 분석 | 종가 차트를 먼저 둔다. 200일선을 추가하고, 로그 축 또는 좁은 y범위를 쓴다. 실시간 띠는 아래 접힘으로 옮긴다. |

## 6. 소유자 결정이 필요한 항목

1. **단계 순서와 범위 승인.** 1단계는 바로 진행하고, 2단계는 1단계 뒤, 3단계는 화면별 시안을 보여 드린 뒤 진행해도 되는지.
2. **한국 매크로.** ECOS·KOSIS로 한국 기준금리·물가 블록을 새로 만들지(생산자 작업 필요), 아니면 출처 줄을 지울지. 권장: 만든다. 이번 주 가장 큰 사건이 코스피 20일 -23.6%였다.
3. **DART_API_KEY 등록.** 한국 종목 재무 공시 탭이 비어 있는 근본 원인이다. 비밀 키는 소유자만 넣을 수 있다.
4. **폰 탭바 구성.** 포트폴리오를 탭바로 올릴지(현재는 더보기 아래에 있다).
5. **종목 겉 PER 기준.** GAAP 최근 4분기(스크리너와 같게)가 권장안이다. 조정 EPS는 접힘에 둔다.
6. **기술적 분석과 종목 › 차트의 중복.** 둘 다 유지하되 역할을 나눌지(시장 지수 / 개별 종목), 합칠지. 권장: 역할만 분리하고 유지한다.

## 7. 반대 의견과 범위 조정

- 시장 리뷰어는 헤드라인 자체를 틀렸다고 봤다. 실제로는 '주도주 동반 약화'는 맞고 흐름명만 틀렸다. 헤드라인은 유지하고 흐름명만 바꾼다.
