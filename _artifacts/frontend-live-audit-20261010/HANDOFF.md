## 작업 경계와 증거

- 요청: 최신 로컬 작업본을 브라우저에서 직접 열어 UI/UX, 미감, 색감, 배치, 렌더링, 의미 연결, 문구, 접근성을 세밀하게 검토. 스킬 사용 및 코드 작업 금지.
- 추가 요청: 발견한 모든 사항과 판단을 상세한 핸드오프 자료로 중간중간 기록.
- 기준: 2026-10-10 작업 트리의 v57.31. 작업 시작에 `version.json`, `_context/CURRENT-STATE.md`, `git status --short`를 확인했다. 다수의 기존 수정 파일이 있었으며 사용자 소유로 보존했다. 배포 사이트나 깨끗한 HEAD 기준이 아니다.
- 브라우저: Codex in-app browser, 첫 단계1280×720, `http://127.0.0.1:8891/`. 기존 `scripts/start-local-node.mjs`로 로컬 정적 서버를 실행했다. 후속 단계의537×828 표시 영역과 추가 데스크톱 폭 검사 제한은 F23에 기록했다.

- 스킬을 읽거나 적용하지 않았다. 애플리케이션 코드, 데이터, 버전, 원장 및 생성물을 수정하지 않았다. 이 핸드오프는 감사 기록이며 수정 완료 보고가 아니다.

### 판정 읽는 법

- **관찰**: 실제 화면 또는 사용자 조작으로 확인한 현상.
- **판단**: 관찰을 바탕으로 한 디자인·편집·사용성 평가. 선호나 제품 결정이 포함되므로 구현 전에 검토가 필요하다.
- **미확인**: 전체 데이터/정상 연결/모든 상태를 확인하지 못한 항목. 실패 원인이나 계산 오류를 확정하지 않는다.
- **우선 1**: 의미 또는 가독성을 크게 훼손해 먼저 다룰 사항. 보안/거래 사고 등급이라는 뜻은 아니다.
- **우선 2**: 반복 사용에 영향을 주는 구조·편의·설명 개선.
- **우선 3**: 정돈과 완성도를 높이는 편집·미감 개선.

## 종합 판단과 유지할 장점

전체 인상은 차분한 투자 리서치 문서다. 아이보리 배경, 먹색 글자, 세리프 제목, 얇은 구분선이 잘 어울린다. 장식이 과하지 않고, 시장 상황을 우호/중립/부담으로 나누어 보여 주는 방식도 비교적 정직하다. 가장 큰 개선 지점은 새 색상이나 장식이 아니라 **근거가 있는 내용의 우선 배치, 기준 시점의 연결, 화면끼리 일치하는 상태 설명, 읽는 사람 중심의 문구**다.

유지할 만한 요소:

1. 좌측 메뉴의 데일리/시장/내 투자/리서치 묶음과 현재 메뉴 표시가 명료하다.
2. 세리프 제목과 본문 고딕의 대비가 읽는 화면의 성격에 맞는다.
3. 시장 폭·투자 심리의 본격 추이 차트는 날짜 축과 값 축, 기준선, 최근 값 설명이 있어 상대적으로 좋다.
4. 시장 폭에서 장기 추세와 짧은 반등을 구분하는 해석은 의미가 있다.
5. 브리핑의 사실과 가설을 구분하는 문장, 운용사 페이지의 법인 보유와 개인 의사결정 구분은 신뢰에 도움이 된다.
6. 학습 칼럼·레슨의 복리 사례, 희소성의 가계/기업 사례, 클라우드 공급망 비유는 구체적이고 자연스럽다.
7. 스크리너 검색 및 행의 Enter 조작, 용어 검색, 도움말 검색이 실제 작동했다.
8. 용어 사전에서 Escape 닫기 후 원래 메뉴 버튼으로 초점이 돌아왔다.
9. 관찰한 상태에서는 거래 실행이나 AI 자동 전송이 일어나지 않았다.

장점이 있다고 모든 화면을 통과로 판정하지 않는다. 특히 가격 차트의 정상 데이터 수신 상태, 보유 포트폴리오의 정상 시세·환산·손익 산식, 학습 자료 전체의 의미 검수는 미확인이다. 보유 입력/수정/저장 유지와 결측 화면은 후속5차에서 확인했다. 본문은 시점별 기록이며 최신 재현 보정은 F24/F34 등의 후속 항목을 함께 읽어야 한다.

## 발견 사항 — 공통 셸과 시각 언어

### G01 · 우선 2 · 보조 정보의 작은 글자와 약한 대비

**관찰:** 기준일, 공급자/출처 설명, 카드 하단 주석, 사이드바 AI 설명이 작고 회색이다. 1280×720에서 3~4열 카드 안의 문장이 여러 줄로 잘게 끊어진다. **판단:** 핵심 수치와 제목은 잘 보이지만 그 수치를 해석하는 조건은 읽기 어렵다. 단순히 주석을 더 붙이는 방식은 해결이 되기 어렵다. **방향:** 핵심 기준은 더 큰 한 줄로, 세부 조건은 펼침으로 이동. 정확한 WCAG 대비 수치는 아직 측정하지 않았다.

### G02 · 우선 2 · 현재 시세와 종가 판정의 기준 연결

**관찰:** 상단 VIX 14.86/F&G 45와 종가 해석의 VIX 15.4/F&G 40이 다르다. 각 영역에 시점 설명이 있으나 사용자가 스스로 연결해야 한다. **판단:** 값이 틀렸다는 판정이 아니라 비교 기준을 잘못 이해하기 쉬운 문제다. **방향:** 전역 상태, 종가 분석, 현재 시세가 어떤 시점을 쓰는지 짧고 일관되게 표시하고, 두 값을 비교할 때 이름에 시점을 포함한다.

### G03 · 우선 2 · 버튼과 조작 표현의 편차

**관찰:** 밑줄 탭, 사각 버튼, 작은 칩, 접기, 텍스트 링크가 혼재한다. 학습 화면의 연결 항목은 어떤 곳에서는 버튼이고 어떤 곳에서는 일반 문장이다. **판단:** 개별 요소는 무난하지만 무엇이 눌리는지, 선택 상태인지, 단순 설명인지가 통일되어 있지 않다. **방향:** 이동/필터/펼침/실행을 시각적으로 구별하되 같은 역할은 같은 표현을 사용한다.

### G04 · 우선 2 · 작동 불가 AI와 켜짐 상태의 인상

**관찰:** 사이드바 AI 스위치는 켜진 듯 보이지만 `일시 사용 불가`다. `GPT-6 Luna · 공용 AI 연결`, 개인 키 문구가 항상 보인다. 도움말에서 AI 패널을 열면 입력과 전송은 비활성이고 `주요 분석 페이지에서 사용할 수 있습니다`라고 안내한다. **판단:** 활성 설정, 현재 연결 상태, 해당 페이지 지원 여부의 차이가 한눈에 구분되지 않는다. **방향:** 현재 이용 가능 여부를 앞에 두고 모델/키 같은 운영 설명은 설정 상세로 옮긴다. AI 응답 품질은 점검하지 않았다.

### G05 · 우선 3 · 상단 운영 메타데이터

**관찰:** `서버 10/10 04:00 · 16개`가 상단에 보인다. **판단:** 16개의 의미가 사용자에게 불명확하다. 운영 정보를 통해 최신성을 설명하려는 목적은 좋지만 표현이 시스템 중심이다. **방향:** 갱신된 자료 범위나 관측 기준처럼 사용자가 이해할 수 있는 이름을 붙인다.

### G06 · 우선 2 · 큰 화면 안의 여러 독립 스크롤

**관찰:** 리서치 라이브러리는 전역 메뉴 외에 목차, 본문, 연결 열이 각각 스크롤된다. 1280px에서 실제 본문 폭은 약 520px 정도로 좁아진다. **판단:** 읽던 위치와 옆 연결을 함께 유지하기 어렵고, 스크롤 대상이 예상과 달라질 수 있다. **방향:** 목차·연결 폭과 스크롤 책임을 재검토. 이는 제품 배치 제안이며 승인 없이 화면을 통합/제거하라는 뜻이 아니다.

### G07 · 우선 3 · 테마 버튼의 상태/행동 표현

**관찰:** 밝은 화면의 버튼은 `라이트 모드`, 어두운 화면으로 전환하면 `다크 모드`다. **판단:** 현재 상태를 말하는지 누르면 바뀔 상태를 말하는지 모호하다. 기능은 실제 전환됐다. **방향:** 현재 상태 표시와 전환 행동을 구분하거나 명확한 토글 이름 사용.

**관찰:** 추가 버튼은 인라인 폼을 열고 티커에 초점을 준다. 수량/가격 예시와 통화 USD 입력, 선택 목표 값 등이 보인다. **판단:** 원화 매수 사용자에게 가격 통화와 현재 평가 통화를 명확히 연결할 필요가 있다. **미확인:** 저장/보유 평가/손익/통화 전환/위험 분석은 테스트하지 않았다. 사용자의 실제 금융 정보를 입력하지 않았다.

## 문체와 의미 연결에 대한 전체 판단

AI가 썼는지 자체는 판단할 수 없다. 여기서 말하는 'AI 느낌'은 작성 주체가 아니라 **반복되는 문장 틀, 추상적인 접속, 과잉 유의사항, 내부 제작 원칙의 노출**을 뜻한다.

1. `가능성이 있습니다 / 단정할 수 없습니다 / ...와 함께 확인하세요`가 여러 카드에 반복된다. 필요한 경계는 유지하되 공통 유의사항과 개별 분석을 나누면 읽기 흐름이 좋아진다.
2. `반대로`, `이어지면`은 실제 앞뒤 내용이 대비/연속 관계일 때만 쓴다. 테마와 신용 문장은 접속사가 사실 관계보다 먼저 만들어진 인상을 준다.
3. `판정 제외`, `산출물`, `봉투`, `PIT`, `coverage`, `profile.description 미제공`은 분석의 내부 상태다. 사용자에게는 '현재 판단할 수 있는 것/없는 것'과 '왜 확인해야 하는가'가 먼저다.
4. 신뢰는 주석 양보다 같은 화면끼리 같은 기준으로 말하는 데서 생긴다. 기준일/모집단/비용 포함 여부가 빠지면 신중한 문장도 설득력이 약해진다.
5. 학습 화면의 구체적 사례는 좋은 기준이다. 시장 화면도 추상적인 일반론보다 이번 관측값의 변화와 남은 질문으로 말하는 것이 자연스럽다.

다듬기 예시(실제 수정 아님):

| 관찰한 표현/방식 | 개선 방향 예시 |
|---|---|
| 어제와 달라진 점 · 10/7→10/8 | 최근 확보 종가 비교 · 10/7→10/8 |
| HY 5일 확대가 이어지면 | 지금은 5일간 9bp 축소됐습니다. 확대로 바뀌는지 다음 공시에서 확인합니다. |
| 상위 네트워킹… 반대로 네트워킹… | 네트워킹은 이번 구간 상위권입니다. 이전 구간과의 변화는 별도로 설명합니다. |
| FMP profile.description 미제공 | 기업 소개를 아직 받지 못했습니다. |
| 조건부 증거 봉투 · 산출물 대기 | 이 조건의 검증 자료가 아직 없습니다. |
| manager·CUSIP… 검증 전 단계 | 공시 원문을 모은 자료입니다. 회사 연결이 확인된 항목만 종목 분석에 사용합니다. |

표의 예시는 표현 원칙을 설명할 뿐 원천 상태나 내부 기준을 추정해 구현하라는 지시가 아니다.

### E01 · S05 확인 강화 · 밝은/어두운 테마 팩터 그림

같은 NVDA 팩터 위치를 두 테마에서 비교했다. 어두운 테마에서는 제목·축·격자가 보이고, 밝은 테마에서는 흰색 글자/선이 아이보리에 묻혀 거의 사라졌다. DOM의 실제 렌더링 스타일을 읽은 결과 SVG 제목은 `rgb(220,230,240)`, 축 이름은 `rgba(255,255,255,0.35)`, 글자 크기는 10px였다. 소스 코드를 읽거나 수정하지 않고 표시 결과만 확인했다. 특정 WCAG 대비 숫자는 계산하지 않았으나 시각 실패와 테마 연동 부재를 직접 확인했다.

- [어두운 테마 증거](./factor-dark.jpg)
- [밝은 테마 증거](./factor-light.jpg)

테마는 점검 후 원래의 밝은 테마로 되돌렸다. 홈 다크 테마의 전체 인상은 일관되고 지나치게 채도가 높지 않았다. 다크 모드 모든 페이지를 통과시킨 것은 아니다. 팩터 그림은 다크에서도 작은 글자와 낮은 축 대비가 남는다.

### E02 · S06 확인 강화 · 업종 비교의 비어 보이는 중앙 영역

같은 섹터 비교의 숫자와 설명은 있지만, 막대가 있어야 할 것으로 기대되는 중앙 영역은 밝은 테마에서 비어 보인다. 우측 수치 폭이 좁아 `상위 3%`, `ROE(평균 자기자본)`이 여러 줄로 끊긴다. 시각 증거를 저장했다. 내부 원인을 특정하지 않으므로 '막대 DOM이 없다' 또는 '데이터가 없다'라고 단정하지 않는다.

- [업종 비교 증거](./fundamental-comparison.jpg)

### E03 · 우선 1 · 뉴스 표제의 24시간 구간과 기사 날짜

**경로:** 재무 공시의 `뉴스 →`로 이동. **관찰:** 제목은 `10.9 08:00 ~ 10.10 08:00 KST 기사`, 중요 뉴스는 `오늘 08:00까지 24시간`인데 실제 보이는 기사 발행일은 10/8 18:29, 15:52, 09:29였다. 마지막 수집 시각은 10/10 04:00이고 수집 지연 상태다. **판단:** 지연 안내가 있더라도 기사 시간창 표제와 표시 기사가 맞지 않는 인상은 해소되지 않는다. **방향:** 지연 시 실제 표시 자료의 범위에 맞는 제목, 마지막 확보 기사일/기간, 이전 수집본이라는 이름을 함께 제공한다. 기사 원문 날짜와 수집 데이터 자체를 외부 검증한 것은 아니다.

### E04 · 우선 2 · 기업 맥락에서 뉴스로 넘어갈 때 맥락 단절

**관찰:** NVDA 공시의 다음 행동은 `NVDA 실적 발표·가이던스 소식`인데 이동 후 뉴스는 한국 필터가 유지되어 삼성전자/코스피 기사였다. **판단:** 이전 필터 유지 자체는 합리적일 수 있으나 버튼이 약속하는 기업 맥락과 실제 도착 내용이 다르다. **방향:** 기업 뉴스로 범위를 전달하거나, 일반 시장 뉴스로 이동한다는 문구를 사용한다. 버튼 설명에 맞는 결과를 확인할 수 있도록 한다.

### E05 · 우선 2 · 뉴스 종목 태그 중복 및 기호

**관찰:** 같은 기사 앞에 `$$삼성전자`, `$KOSPI`, `$삼성전자`가 함께 보인다. 삼성전자 버튼이 중복되고 한쪽은 달러 기호 두 개다. **판단:** 중복 식별과 원문 표식이 가공되지 않은 인상이다. **방향:** 동일 기업 태그를 합치고 한국 기업명에 불필요한 티커 표식을 정돈한다. `$$삼성전자` 버튼은 실제 삼성전자 005930.KS로 연결됐다. 잘못된 발행사로 바뀌었다고 판정하지 않는다.

- [뉴스 기간·태그·필터 증거](./news-context.jpg)

### E06 · 장점/우선 2 · 한국 종목 및 미등록 입력 상태

삼성전자는 005930.KS로 연결되고 코스피와의 1/3/6개월 수익률 비교, 50/200일선, 환율을 통한 미국 시장의 간접 영향을 설명한다. 한국 종목에 미국 지수 비교를 그대로 복사하지 않는 점은 좋다. 다만 가격 이력 미수신/파생값 계보 문제는 미국 종목과 같다.

`ZZZZZZ` 입력은 다른 기업으로 치환되지 않았다. 입력 그대로 제목이 바뀌고 유니버스 밖/기록 없음 안내가 나온다. 그러나 존재 여부가 확인되지 않은 입력에도 `차트 탭의 일봉과 재무 공시는 그대로 볼 수 있습니다`라고 말한다. **판단:** 유니버스 외의 실제 티커와 존재 여부 미확인을 구별하는 상태 문구가 있으면 좋다. 이 입력이 실제 존재하지 않는다는 외부 검증이나 티커 유효성 로직 검사는 하지 않았다. 정상 외부 조회가 성공한다고 인증하지 않는다. 점검 후 예시 NVDA로 되돌렸다.

### E07 · 키보드 추가 확인

- 메인 콘텐츠로 건너뛰기 링크를 Enter로 실행하면 초점이 `main-content`로 이동했다.
- 용어 사전은 검색 입력에서 Shift+Tab으로 닫기 버튼, 다시 Shift+Tab으로 모달 안 마지막 카테고리 버튼으로 이동했다. 확인한 방향의 초점 순환은 작동했다.
- Escape로 닫기 및 원래 메뉴 복귀를 확인했다.
- 이는 샘플 조작 증거다. 모든 모달/탭/표/화살표/스크린리더 동작이 통과했다는 의미가 아니다.

### E08 · 세부 판단 보정

- L14의 TLT 기호 예시는 오기 없이 실제 보인 `금리↓=TLT↑, 금리↑=TLT↓`로 바로잡았다. 기호 관계가 틀렸다는 이슈가 아니라 문체/설명 깊이의 편차에 대한 평가다.
- 삼성전자 뉴스에서 돌아가기 `← 뉴스`는 진입 맥락에 맞았다. S01은 모든 뒤로가기의 고장으로 확대하지 않고 처음 NVDA 진입에서 본 부적절한 재무 공시 맥락의 사례로 유지한다.
- DOM의 숨은 dialog 존재 자체는 접근성 노출 실패 증거가 아니다. 실제 초점/AX 관찰과 구별한다.

## 3차 추가 확인과 최종 인계

### E09 · T02/T03 재현 강화 · 테마의 실제 표시 문구

상단은 `RRG 관측 보류 · 근거 0개(섹터 관측 11개 중 집계 0)`, `완료 종가, 30거래일 이상`, `SPY 대비 상대가격 히스토리 20개 이상 필요`를 함께 보여 준다. 에너지 상세는 `판정 보류 — 시세 대기`, `시세 근거 미확보 · AIO 참고 테마 분류 · 구성 기준일 미검증` 바로 아래에 `테마 ETF XLE는 섹터 회전에서 선도`를 보여 준다. 이 표시 상태를 다시 재현했다.

### E10 · L01 재현 강화 · 개념 지도와 두 단계 보기

**재현:** 리서치 라이브러리 → 개념 지도 → 희소성과 선택 → 두 단계까지. 제목 아래 그래프에서 `생산성과 부`와 `선택과 산출`의 겹침, 선의 텍스트 상자 통과, 하단 `기업·주식·밸류에이션`과 `검증 프레임`의 좁은 배치를 다시 관찰했다. 두 단계 보기에서는 `자본주의의 엔진` 등 연결이 늘면서 겹침이 남았다. 버튼 전환은 작동했으나 시각 가독성은 개선되지 않았다. 관계 중심 노드는 진하게, 주변 노드는 희미하게 표현하려는 의도는 이해되지만 선/위치 충돌이 그 목적을 방해한다.

### E11 · T09 확인 강화 · 한국 테마 결론과 표시 목록

한국 테마 본문의 약한 테마는 바이오(-15.8%)와 K-방산(-15.6%)인데, 보이는 12개 목록에는 두 테마가 없다. 목록이 상위 일부라면 자연스러운 결과지만, 약한 테마를 설명한 바로 아래에서 그 근거를 펼쳐 볼 방법이 관찰되지 않았다. **방향:** 상·하위 모두 보이게 하거나 전체/하위 보기와 표시 대상 수를 제공한다. 모든 23개 데이터가 누락되었다는 판정은 하지 않는다.

### E12 · L06 범위 보정 · 연결 버튼과 일반 문장

산업 분야의 큰 묶음 `클라우드·AI 플랫폼`에서 우측 하이퍼스케일러/관리형 AI/가동률/약정/감가상각은 버튼이고 실제 상세로 이동한다. 반면 하이퍼스케일러 상세 우측의 `포함하는 하위 개념: 관리형 AI 서비스`, `조건에 따라 영향을 주는 대상: 감가상각 주기`, `함께 필요한 것: GPU·범용 병렬 가속기`는 일반 문장이다. L06을 산업 화면 전체의 연결 실패로 확대하지 않는다. 같은 역할의 문맥 연결이 상세에서 행동으로 이어지지 않는 불일치가 핵심이다.

### E13 · 우선 3/장점 · AI 기초와 관계 가이드의 편집

- AI 기초의 에너지와 전력은 전자레인지/도시 전력 비유 → 에너지와 전력 정의 → 전기·계산·열·냉각 흐름 → 경제적 가치 질문으로 연결된다. 자연스럽고 명확한 샘플이다. 모든 칩의 전력이나 최신 수치를 검증한 것은 아니다.
- `AI 기초 7`은 펼치면 여러 장 아래 많은 레슨을 보여 준다. 7이 레슨 수가 아니라 장 수로 보이므로, `7개 장` 등의 단위를 붙이면 다른 목차의 항목 수와 구분된다.
- 중립금리 관계 가이드는 정의 → 추정 → 정책 판단 → 반론·검증의 순서가 명료하다. 이론적 기준과 실제 관측을 구분하는 설명도 좋다.
- 4단계가 3열 뒤 다음 줄 하나로 이어져 단계적 흐름이 약해지고, 우측 `연결` 영역은 이 샘플에서 비어 있었다. 단계 그림의 읽기 순서와 빈 연결 영역을 정돈할 여지가 있다.
- `정책 스탠스`, `상태공간 추정`, `실시간/사후 추정`은 심화에서 적절할 수 있으나 첫 결론에는 쉬운 말이 있으면 좋다. 예: '지금 금리가 경기를 얼마나 누르는가'.

### E14 · 우선 2/미확인 · 종목 탭의 선택 상태 전달

후반에 NVDA가 상위 종목 탭과 입력에 남아 있는 상태에서 재무 공시로 이동하자, 화면은 `종목 선택 전`/`선택한 종목 없음`을 보여 주면서 이전 팩터 그림/외부 정보는 NVDA로 남아 있었다. `기업 분석`을 누르면 SEC 흐름이 채워졌다. 비동기 전환/로딩 상태인지, 별도 실행이 필요한 설계인지 내부 원인은 미확인이다. **판단:** 같은 화면 안에 '선택 없음'과 선택 기업 자료가 섞이는 중간 상태는 사용자가 이해하기 어렵다. **방향:** 로딩 중인지 실행 전인지, 어느 자료가 이전 결과인지 구별한다. 이 한 번의 관찰을 항상 발생하는 상태 전달 버그로 확정하지 않는다.

### E15 · 우선 2 · AI 안내의 과도한 실행 경계 문구

AI 도움말 패널 상단에는 `투자·법률·세무 조건부 분석과 수치 시나리오`, `불법 실행 절차·주문 실행·확정적 보장은 제외`라는 설명이 보인다. **판단:** 질문 입력 전부터 금지/시스템 범위를 길게 읽게 하며 일반 리서치 흐름과 어울리지 않는다. **방향:** 사용자가 할 수 있는 질문의 예시와 현재 지원 여부를 먼저 보여 주고 상세 이용 범위는 필요할 때 읽게 한다. 안내를 제거하거나 정책을 우회하라는 뜻이 아니다.

### E16 · 우선 3 · 값의 상승 색과 환경 상태 색의 의미

홈의 금리 상승 값/선은 초록이고 금리 축의 부담 상태는 빨강이다. **판단:** 부호 색과 투자 환경 상태 색은 서로 다른 의미라 성립할 수 있다. 다만 초록을 '좋음'으로 받아들이는 사용자에게 혼동 가능성이 있다. **방향:** 변화의 방향 표시와 환경 판정 배지의 의미를 구분하고, 색만으로 해석하지 않게 이름·부호를 유지한다. 색상 정의가 잘못됐다고 확정하지 않는다.

**경로:** 발견 → 컬럼 프리셋 펀더멘털 → 컬럼 선택. 실제 표 헤더는 밸류·퀄리티·구조 분류·최신뉴스가 포함되고 1M·RSI·VCP가 빠진다. 그러나 선택 메뉴에는 밸류/퀄리티/구조 분류/최신뉴스가 unchecked, 1M/RSI/VCP가 checked로 남는다. 여기서 `밸류` 체크를 켜면 표가 발견 컬럼 + 밸류 구성으로 바뀌고 퀄리티·구조 분류·최신뉴스가 사라진다. 프리셋 선택 이름은 여전히 펀더멘털이다. **판정:** 단순 문구 문제가 아니라 컬럼 표시 상태의 동기화 실패. 메뉴를 여는 것만으로 기존 구성 확인이 불가능하고 한 항목 조작이 여러 열을 바꾼다. 프리셋을 재선택하면 펀더멘털 구성은 다시 적용된다. 내부 구현 원인은 코드 조사 없이 미확인이다.

### F10 · 확인/우선 2·3 · 개별 순위 설명의 행동·내용·밀도

행에 Enter를 누르면 선택 상태가 붙고 096770.KS 설명 패널이 열린다. 닫기와 기업 보기/비교 추가 행동이 구분되어 있다. 샘플 패널의 가중 기여 31.1+20.5+0.2+9.2는 표시 가중 합 61.0과 맞고, 가중 합 → 전체 백분위85 → 조건 통과 중134위의 계산 순서를 설명한다. **장점:** 가중 합과 백분위를 다른 숫자로 보이는 이유를 숨기지 않는다. 높은 팩터 상관과 독립 신호 약2.3개를 설명해 지표 수를 근거 수로 착각하지 않게 한다.

**판단:** 헤더에는 필드 coverage48.6%/팩터 근거100%/팩터 원값85.00이 한 줄에 혼재한다. 본문 첫 헤더의 `팩터 점수`, 가중 합61.0, 백분위85, 오늘916종목과 상단913종목은 모집단과 이름을 다시 해독하게 한다. 계산이 틀렸다는 판정은 하지 않는다. `Provenance`, `K-vel`, `w37%`, `Why drawer`, `Wedge Pop` 등은 사용자 화면에서 과도한 기술 용어다. 폭이 좁은 왼쪽 카드에 긴 설명이 몰리고 두 오른쪽 카드는 대부분 빈 공간이라 정보 분배도 좋지 않다. `필요한 값이 모두 있습니다 · 이벤트/리테스트 데이터 미수신`은 순위 필수값과 선택 근거의 범위를 제목에서 나누면 더 자연스럽다. 상세 결론 한 줄 → 막대 → 필요 시 계산 설명 순서가 낫다.

### F11 · 확인/우선 2 · 조건 입력 예시가 허용값과 충돌

직접 조합에서 `최소 rank` 선택 후 abc를 넣으면 `지원하지 않는 값 / 허용값40,50,65,80`으로 거부하고 입력에 초점이 돌아온다. **정상 확인:** 잘못된 문자열 거부와 이유 안내. 하지만 입력의 고정 예시는 `Technology,70,40`이고 실제로 숫자70도 같은 이유로 거부했다. 80은 통과되어 미리보기 조건 통과가371→188로 줄고 `최소 rank80` 조건이 추가됐다. **판정:** 제공한 예시와 입력 계약이 맞지 않는다. 허용값이 유한하면 필드에 맞는 선택지를 제공하거나 예시·단위·범위를 필드별로 바꿔야 한다.

### F12 · 우선 3 · 조건과 표시 필터의 구분 비용

유효 최소rank80 추가 후 `실행 조건 최소rank80 제거(실행 정의 변경)`와 `표시 필터 최소rank80 제거(표 범위만)` 두 칩이 동시에 생겼다. 위 안내는 rank/RSI/3M은 실행 정의, 섹터/분류/검색은 표시 필터만이라고 설명한다. **판단:** 서로 다른 책임은 상세 접근성 이름에 드러나지만 같은 문구의 두 칩이 사용자의 사고 체계를 복잡하게 한다. 입력 → 후보 수 → 확정/저장이라는 중심 흐름보다 실행 정의·funnel·run·ret3m·pctSma200 등 구현 용어가 먼저 읽힌다. '현재 조건/결과 안에서 좁히기/보관한 조건'처럼 사용자가 하는 행동을 기준으로 설명할 필요가 있다. 이번 단계에서는 원래 브라우저에 사용자 실행 기록을 추가하지 않았다.

4차 스크리너 기록을 반영했다. 검사한 표시 조건·정렬·컬럼은 전체 지수/빈 검색/균형 상대 랭킹/발견/백분위 내림차순으로 복구했고 비교 선택을 비웠다. 원래 주소에 사용자 화면이나 실행 기록을 새로 저장하지 않았다.

## 5차 중간 기록 — 분리된 로컬 주소에서 포트폴리오 입력 상태

### F14 · 우선 2 · 화면 간 한국 종목 입력 형식 차이

포트폴리오는 `005930.KS`를 '검증되지 않은 티커'라 거부하며 예시로005930을 제시한다. 같은 입력값에서005930으로 바꾸면 저장된다. 반면 스크리너는 한국 티커를 `.KS/.KQ`로 표시한다. **판정:** 검증되지 않은 입력을 임의 기업으로 저장하지 않는 보호는 좋다. 앱의 다른 화면에서 본 형식을 그대로 사용해도 거부되는 사용자 경험은 불일치다. 형식을 사전에 안내하거나 검증된 동일 종목의 정확한 별칭을 연결하는 방식이 필요하다. 서로 다른 기업을 추정으로 바꾸는 해결은 부적절하다.

### F16 · 우선 2 · 차트 보류 안내와 도넛의 수치가 충돌

시세가 모두—인 상태에서 총 자산/손익/비중 표는 보류하고 `포트폴리오 시세 수신 대기 · 차트 보류`라고 표시한다. 그러나 실제 도넛에는 **2종목/$10.2K**가 남아 있었다. 새로고침 직후에는005930 99.0%/NVDA1.0%, 0종목/$0 헤더와 기존2개 행이 함께 나오는 과도 상태도 관찰했다. 이후 NVDA2주/원가200 USD와005930 원가10000 KRW의 안정 화면에서는 도넛$10.2K와 섹터 `Other98%/Technology2%`가 보였다.

### F17 · 우선 2·3 · 결측 화면의 동선과 반복

### F20 · 확인/우선 3 · FAQ 내용과 구조

FAQ 버튼은 해당 구역을 펼쳐 이동한다. 수신 대기/빈 차트/AI 연결/영어 뉴스/보유 자료 소실/한국 시세에 대해 사용자가 경험하는 질문으로 설명한다. 원인 여러 가지를 인정하고 자료 기준 시각을 보게 하는 점, AI 개인 키가 불필요하고 페이지 자료는 계속 볼 수 있다는 점은 좋다. '모든 데이터는 브라우저 localStorage에 저장됩니다'는 보유/설정의 답변 맥락에서 이해할 수 있으나 전체 시장 원천도 로컬에만 저장되는 듯 넓은 문구다. '보유 내역과 개인 설정'이라고 대상을 좁히면 정확하다. '운영자에게 알려 주세요'에는 화면 이름·상태·기준 시각 등 전달할 내용을 간단히 제시하면 도움 된다. 개인정보 포함 가능성이 있는 로그 다운로드/초기화는 실행하지 않았다.

FAQ 질문과 구역 제목이 실제 접근성 트리에서는 일반 text다. 메뉴 지도/판정표의 heading과 달리 FAQ 질문 사이를 제목으로 이동하기 어렵다. 실제 스크린리더 사용성은 미검증이지만 구조 정보의 차이는 확인했다.

### F21 · 우선 3 · 연결 설정 안내와 행동의 단절

연결 설정을 펼치면 공급자 이름과 개인 키 전송 안내가 나온다. '아래 연결을 설정하세요'라고 하지만 이 구역에서 보이는 것은 시세/AI/뉴스 공급자 텍스트뿐이고 입력이나 설정 위치로 가는 행동은 없다. 좌측 별도의 '연결·키 보안 설정'으로 가야 하는 것으로 보인다. **판정:** 읽기 안내에서 실행 위치로 이어지는 연결이 부족하다. 개인 키를 요청하거나 보안 설정을 변경하지 않았다. 공용 AI와 선택 개인 데이터 조회가 구분되는 설명은 유지할 가치가 있다.

### F22 · 확인/접근성 판단 · 검색 없음·실제 트리·조작 크기

설명서에서 `없는검색어테스트` 검색 시 '검색 결과가 없습니다'가 status로 제공됐다. 잘못된 결과로 이동하지 않았고 빈 검색으로 복구했다. 설명서 실제 native 접근성 트리는 현재 설명서/셸 내용으로 제한되었으며 DOM snapshot에 있던 다수 숨은 '펼치기' 문구는 여기서 관찰되지 않았다. 이를 모든 페이지의 접근성 격리 통과로 확대하지 않는다.

현재 도움말의 보이는 버튼 치수를 읽은 샘플에서 메뉴 버튼은25×22px이었다. 클릭 가능 영역의 여백·인접 간격 예외까지 검사하지 않아 이 값만으로 접근성 기준 위반을 확정하지 않는다. 작은 대상 개선 여지는 있다. 좌측 일반 메뉴 텍스트는13px, 색rgb(87,81,63), 배경rgb(242,238,230), 불투명도1이었다. 이 샘플의 계산 색 대비는 약6.84:1로, 전체를 단순히 '대비 부족'이라 판정할 근거는 아니다. 이전 작은/희미한 각주·차트 지적과 구분한다. 모든 색·그래프·초점 테두리 대비의 전수 인증은 하지 않았다.

### F23 · 환경 한계 · 데스크톱 추가 폭 검사 미완료

5차 이후 브라우저 실제 표시 영역이537×828로 바뀌었다. 앞선1280×720 증거와 같은 배치로 판단하지 않는다. 제품은 데스크톱만 지원하므로537px 화면 깨짐을 모바일 대응 결함으로 기록하지 않는다. 데스크톱1440×900 뷰포트 요청을 시도했지만 실제 DOM rootWidth/rootHeight는537×828로 유지됐고 캡처도 좁은 폭이었다. 요청이 적용되지 않았으므로1440px 통과나 두 해상도 검사 완료라고 보고하지 않는다. 뷰포트 요청은 reset으로 제거했다. 이후 단계는 텍스트·UI 상태·접근성 정보 검사로 계속했고 추가 배치 평가는 제한했다. 브라우저 아래 패널 열기 요청도 queued라 레이아웃 복구 완료로 보지 않는다.

### F24 · 확인/기존 관찰 범위 보정 · 최신 뉴스 날짜와 복합 필터

새 뉴스 상태는 `10/9 08:00~10/10 08:00 KST`, 마지막 수집10/10 11:24를 보여 준다. 한국+에너지+기업 뉴스 조합에서0개가 되고 '현재 조건에서 오늘 자료 미확보 · 이전 수집분25건은 오늘 뉴스가 아닙니다'라고 설명했다. 이 최신 상태에서는 지난 기사를 오늘 목록으로 보여 주던 이전 관찰을 재현하지 않았다. 원래 증거를 삭제하지 않고 최신 재현 여부를 보정한다. 국가/주제 전체로 복구하면36개 일치 중12개 표시로 돌아왔다. 채널 소식은 필터와 무관하다는 별도 안내가 나타나고12개 텔레그램 글은 유지된다. **장점:** 일반 기사와 독립 채널 범위를 이제 문장으로 구분한다. 모든 필터 조합과 원문 사실은 검증하지 않았다.

### F25 · 우선 2 · 뉴스 필터 선택은 시각 스타일에만 존재

한국/에너지 버튼은 선택 후 accent 색·배경·테두리 inline style로 구분되고, 기업 뉴스는 active 클래스가 붙는다. 그러나 세 버튼 모두 aria-pressed/aria-selected가 없으며 실제 native 접근성 트리에도 선택 정보 없이 button으로 나온다. **판정:** 사용자는 현재 선택 조건을 색 없이 확인하기 어렵다. 화면 상태가 시각 표시와 접근성 정보에 함께 전달되도록 해야 한다. 구현 역할은 토글 버튼/단일 선택 탭 등 실제 동작에 맞게 정해야 한다. 모든 필터가 반드시 특정 ARIA 속성을 가져야 한다는 단순 처방은 하지 않는다.

### F26 · 우선 1 · COO 직함이 관련 없는 기업으로 연결됨 — 행동까지 재현

**경로:** 뉴스 → 국가 전체/토픽 전체 → 카테고리별 → `Former FTX COO says Netflix’s ‘Altruists’ trailer…` 기사 옆 `$COO` 버튼 클릭. 클릭 전 COO는 FTX의 직함 맥락이고 클릭 후 종목 요약은 **COO / CooperCompanies / 헬스케어(XLV)**로 열린다. 기사 내용의 회사와 다른 기업이다. **판정:** 뉴스에서 추출된 대문자 직함이 실제 존재하는 동일 티커로 연결되는 오인. 등록된 티커가 존재한다는 검증만으로 뉴스 맥락의 동일 기업을 보장하지 못한다. **방향:** 직함·기관 약어를 티커로 만들지 않고 기사 기업과 검증된 issuer 연관이 있을 때만 행동 버튼을 노출한다. 실제 데이터를 추정으로 다른 기업에 재배정하면 안 된다. 자동 추출 원인은 코드 확인 없이 미확인이다.

### F27 · 우선 2 · 번역의 의미 방향과 어색한 직역

화면에 함께 제공된 영문/번역 표제를 비교했다. `Which Stocks Have the Biggest Exposure to Anthropic’s Growth?`는 성장에 가장 많이 노출된/영향받는 종목을 묻지만 한국어는 `Anthropic의 성장에 가장 큰 영향을 미치는 주식은 무엇입니까?`로 **영향을 받는 대상→영향을 주는 대상**으로 바뀐다. 원문 기사 사실을 검증한 것이 아니라 두 표제의 의미 관계를 비교한 판단이다. FTX COO의 `made me physically throw up`을 `몸을 토하게 만들었다`로 옮긴 것은 부자연스럽다. DAL의 Earnings Call Transcript를 `실적 통화 기록`이라 하는 것도 전화 통화보다 실적 발표 컨퍼런스콜이라는 문맥을 약화한다. **방향:** 번역 존재 비율보다 의미 방향/관용구/금융 문맥의 품질을 먼저 확인하고 부족하면 원문을 병기한다.

### F28 · 우선 2·3 · 카테고리 이름과 기사 분류

카테고리 모드에는 `equity / earnings / energy / crypto / defense / geo / semi · 피드 분류 검토 필요`가 그룹 제목으로 나온다. **판정:** 내부 코드와 검수 상태가 사용자용 주제 이름을 대신한다. `defense` 아래 Moderna 제목과 NIH 암 백신 프로그램 설명이 표시되어 그룹 이름과 내용의 연결이 불분명하다. `semi` 아래 제조·AI 부채·Baby Bonds·석탄을 포함한 복합 영상이 있는데, 복합 소재의 다중 분류 또는 대표 주제를 설명하지 않는다. 원문 내용 전체나 분류 알고리즘은 검증하지 않았다. 주식/실적/에너지/크립토/지정학 등 한국어 이름과 미분류/기타를 명확히 보여 주고 잘못 묶인 샘플을 검토할 필요가 있다.

### F29 · 확인/우선 3 · 뉴스 더 보기와 상한 안내의 충돌

카테고리 모드36개 중12개에서 `12개 더 보기`를 누르면24개가 표시돼 **실제 확장은 정상**이다. 그러나 부모 접근성 설명은 `일치 N건 중 계약 상한만 이 화면에 표시됩니다(더 보기로 확장되지 않습니다)`다. **판정:** 행동과 도움말이 정반대다. '계약 상한/N건'도 사용자에게 내부 구현 표현이다. 최신 구현의 표시 수/전체 일치 수와 실제 확장 행동에 맞는 안내로 정돈해야 한다.

### F30 · 우선 3 · 뉴스 해석 문구의 정보량과 종목 문장 연결

중요 뉴스 여러 항목은 '주식/실적/매크로 뉴스입니다. 헤드라인 기준 톤은 중립이고, 관련 티커는…/시장 전체 영향 여부를 확인해야 합니다'라는 같은 틀을 반복한다. **판정:** 주제·티커·톤은 이미 배지로 보이는 정보라 이 문장이 읽을 내용이나 맥락을 거의 더하지 않는다. AI처럼 느껴지는 원인은 생성 여부가 아니라 반복·당연한 정보·구체성 부족이다. 의미를 더할 근거가 없다면 제목과 출처만 간결하게 표시하는 편도 가능하다.

COO 요약에서 섹터는 '시장보다 강하지만 힘이 빠지는 중'인데 마지막에는 '섹터와 종목이 함께 약합니다'라고 끝난다. 상대 위치/모멘텀 약화가 서로 다른 뜻이라 성립할 수 있으나 압축 문장에서는 그 차이가 지워진다. '섹터의 상대 우위는 남아 있지만 탄력이 줄고, 종목은 지수보다 약합니다'처럼 실제 관계를 연결하는 것이 명료하다. 하락 추세 종목의 다음 행동도 '돌파 전인지 확인'으로 고정되어 조사 질문이 현재 상태에 충분히 맞춰지지 않는다.

6차까지 모든 새 관찰을 통합했다. 이번 계속 점검은 앱 코드·데이터·버전·스킬을 수정하지 않았고 금융/AI 제출도 수행하지 않았다.

### F31 · 우선 2 · 본문 건너뛰기 후 새로고침하면 페이지가 비어 있음

뉴스에서 `메인 콘텐츠로 건너뛰기` 링크에 Enter를 눌렀다. 실제 초점은 DIV#main-content로 이동하여 **즉시 본문 이동은 정상**이다. 그러나 URL의 라우트 해시가 `#market-news`에서 `#main-content`로 바뀐다. 이 상태에서 새로고침하면 제목이 일반 AIO v57.31로 돌아가고 breadcrumb는 `AIO / main-content`이며 메인 영역에 공통 제목과 오늘 하위 메뉴만 남고 뉴스 본문이 없다. 이후 좌측 스크리너를 누르면 정상 페이지로 복구한다.

**판정:** 건너뛰기용 앵커와 해시 라우팅이 충돌하는 사용자 행동상의 결함이다. 초점 이동 자체가 실패한다고 기록하지 않는다. 키보드 사용자가 본문으로 이동한 뒤 새로고침하거나 이 주소를 다시 열 때 콘텐츠가 사라진다. 라우트 주소를 보존하면서 본문 초점을 이동하거나 라우터가 해당 앵커를 처리해야 한다. 코드 원인은 읽지 않았다.

### F32 · 우선 2 · 스크리너 탭의 방향키 이동 없음, Tab/Enter 우회는 가능

스크리너의 tablist에는 랭킹/팩터·레짐 등4개 tab이 있다. 랭킹에서 ArrowRight를 눌렀으나 초점과 selected=true가 그대로 랭킹에 남았다. 읽은 DOM에서4개 모두 button 기본 탭 진입 상태였고 tabindex 속성은 없었다. 실제 Tab으로 다음 팩터·레짐에 이동한 뒤 Enter를 누르면 selected=true와 tabpanel이 바뀌었다.

**판정:** 키보드로 기능에 접근할 수 있으므로 전체 조작 불가로 판정하지 않는다. 그러나 탭이라는 역할이 전달하는 방향키 탐색 기대와 실제 행동이 다르고, 모든 탭이 순차 Tab 이동에 포함된다. 탭 그룹의 방향키 이동/선택과 초점 규칙을 일관되게 제공할 필요가 있다. 실제 스크린리더 낭독과 모든 탭 그룹은 미검증이다.

### F33 · 우선 2 · 같은 비중이라는 새 설명과 표시된 비중이 모순

### F93 · 우선 2·3 · 남은 산업의 정의·인과·한국어 전달력

마진·비용 구조는 총마진 뒤에 인건비·연구비·감가상각을 고정비로 추가한다고 설명한다. 어떤 비용이 매출원가에 이미 포함되고 어떤 것이 판매관리비/연구비인지 산업마다 달라 감가상각을 총마진에서 항상 제외하는 듯한 문장을 정밀하게 해야 한다. 현금 투자면 ‘부담이 없다’는 대차대조표 문장은 직접 차입 의무가 없다는 뜻으로 한정해야 기회비용/유동성 소진 레슨과 일치한다. 구독 회사에 ‘몇 배 높은 값’, 예상보다 좋은 실적은 ‘오른다’ 등의 단정도 다른 조건과 전망 변화가 함께 작용한다는 범위를 밝혀야 한다.

### F112 · 우선 2·3 · 용어 정의의 화면 일관성과 공식 자료 대조

‘마켓 레짐’과 ‘시장 상태’ 정의는 미국6축에 환율을 넣지만 최신 실제6축은 달러·원자재를 포함하고 원·엔은 별도 참고다. ‘와인스타인 스테이지’는 Stage2를 ‘상승 수익 최대 구간/실시간 확인’이라고 말하지만 같은 사전의 Weinstein Stage Analysis는 방법론/사후에 더 분명한 관찰이라고 설명한다. 기술 화면은 종가 기준이며 시세 미수신 상태다. 표현을 실제 측정 기준과 맞춰야 한다. ‘BUY/SELL/HOLD’의 기존 이름을 행동 아닌 참고 분류라고 재정의하는 방식도 독자에게 자동 주문/행동 판단으로 읽힐 수 있어 현재 제품 용어와의 정합성 검토가 필요하다. 예전 옵션 용어가 남았다는 것만으로 은퇴한 옵션 라우트를 부활시키라는 뜻은 아니다.

외부 공식 원문을 제한적으로 대조한 두 항목은 별도로 구분한다. GNP 정의의 ‘자국민/국민 기준’은 국적 기준으로 읽히지만 [BEA GNP 공식 정의](https://www.bea.gov/help/glossary/gross-national-product-gnp)는 거주자가 제공하는 노동·자산을 기준으로 한다. 국적과 경제적 거주를 구분하도록 수정할 근거가 있다. 연준 대차대조표의 ‘2020년에 약4조에서9조 가까이’는 기간이 잘못 압축됐다. [연준 2021년11월 보고](https://www.federalreserve.gov/monetarypolicy/November-2021-Federal-Reserve-Balance-Sheet-Developments.htm)의2020-12-30 총자산은7.363조이고, [2022년2월 통화정책 보고](https://www.federalreserve.gov/monetarypolicy/2022-02-mpr-part2.htm)는2022-02-16에8.911조다. 2020~2022 확대로 기간을 밝혀야 한다. 해당 두 원문에 근거한 좁은 사실 대조이며356개 전부의 수치·법령·기술 사실 인증은 아니다.

국가부채/GDP, 외환보유고, 기축통화 비중 등의 변하는 숫자에는 기준연도/분모/원천이 없다. 서킷브레이커·세금·거래 시간은 제도/예외/적용일을 공식 원문과 대조하는 후속 과제로 남긴다. 일부 ‘0DTE 고위험·고보상’, ‘낮은 변동성에 적합’, ‘위스퍼 미달이면 주가↓’, ‘매도자에게 유리’는 다른 정의의 조건부 설명보다 단정적이다. 용어의 구조·조건과 실제 결과를 구분하는 편집이 필요하다. 모든 거래 전략 예시를 현재 종목에 대한 매매 지시로 분류한 것은 아니다.

### F113 · 용어 사전 인터페이스 · 분류 밀도와 작은 그림의 선택

모달은356개를 검색/분류로 좁힐 수 있고 분류 개수는 실제 결과와 맞는다. 하지만28개 분류가4줄의 작은 버튼으로 늘어서 내용 영역의 위쪽 공간을 많이 차지한다. ‘기술/차트분석’, ‘경제/매크로/거시·돈/경제 기본’, ‘배경지식/심화’는 분류 축이 섞여 독자가 어디에 있을지 예측하기 어렵다. 분류 체계 정리는 제품 제안이며 이번 감사에서 통합/삭제하지 않았다.

사전 본문은 하나의 긴 목록이므로 용어의 짧은 뜻→혼동 경계→관련 개념/실제 화면 연결이 적합하다. 모든 정의에 큰 그림은 필요 없다. 캔들의4가격, 듀레이션의 금리·가격 방향, 옵션의 권리/순손익, 범위 위치와 백분위 차이, 자금이 누구에게 들어가는지(신주/구주)는 작은 도식이 특히 유용하다. 법령/세율·단위 정의를 그림만으로 대체해서는 안 된다. 닫기×는 AX상 이름이×이고 모달은dialog가 아닌container로 나타났다. 실제스크린리더 전체 탐색/포커스 트랩 인증은 남는다. ## 10차 기록 파일 확인과 정적 검사 경계

사용자 요청·시각 검토·용어 관찰 자료를 중간 저장한 뒤, HANDOFF/REQUEST-CONTEXT/VISUAL-INTERFACE-REVIEW/LEARNING-REVIEW의 UTF-8 읽기, LF 줄바꿈, 대체 문자 없음과 로컬 링크61개(55+4+2)의 대상 존재를 확인했다. 감사 문서 범위의 git diff --check는 통과했다. 신규 untracked 파일까지 내용이 자동 검증된다고 확대하지 않고 별도 직접 파일 확인 결과를 남긴다.
