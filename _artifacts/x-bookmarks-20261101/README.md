## 4. 수집 → 선별 → 생성 → 연결 파이프라인 점검

### 수집
- **존재 이유:** 종가 기준 판정(가격·신용·거시)과 1차 원문(SEC·DART·FOMC)을 무료 원천으로 자동 수집한다.
- **정합성:** 저자들이 쓴 시장 숫자는 우리 값과 맞았다(HY 326bp, IG 89bp, PCE 3.6%, 금 -3.3%, 인텔 -28.6%).
- **빈칸:** 분기 현금흐름(TTM FCF·설비투자 합계)이다. 저자들이 가장 많이 쓴 숫자인데 수집하지 않는다.

### 선별 — 실적 요약 숫자 검증
- **의도:** AI가 뽑은 숫자가 원문 문장과 원문에 그대로 있을 때만 남긴다(환각 차단).
- **결함:** 저장된 59개 요약에서 289개 항목이 'number-not-in-source'로 버려졌다. 그중 129개는 숫자가 아니라 **기간 표기** 때문이었다.
  - 원인 표기: 가이던스의 연도("2026년 4분기 전망", "Q1 2027"), "3Q", "최근 12개월", "첫 9개월"
  - 버려진 항목 예: 아마존 TTM FCF, 인텔 4분기 매출총이익률 가이던스, 코카콜라·케이던스·스털링 연간 가이던스 전부
  - 콜 요약도 같은 문제를 겪었다. "2,200억 달러"처럼 억 단위로 바꿔 쓴 금액이 원문 "$220 billion"과 맞지 않아 버려졌다.
  - 결과: v59.44에서 약속한 '설비투자·잉여현금흐름 추출'은 58개 실적 중 설비투자 1건만 남았다.
- **수정(v59.56):**
  - 연도(앞에 $·쉼표가 없고 뒤에 단위가 없는 네 자리), nQ, 3·6·9·12개월 기간을 Q3처럼 기간 단어로 건너뛴다.
  - 억·조 달러 금액은 billion 값으로도 대조한다. 문장에 '달러'가 있을 때만 그렇게 하고, 억 원은 대상이 아니다.
  - 저장분으로 재현하면 129개 중 119개를 다시 살린다.
  - 진짜 불일치(한 항목에 하위 항목 숫자를 몰아 쓴 경우)는 그대로 버린다.

### 생성 — 시황 해석
- **의도:** 종가 근거·국면 판정·헤드라인·리서치 채널로 7–9줄 해석을 쓰고, 숫자마다 근거를 검증한다.
- **결함 1:** 실적 요약(event-briefs.json)을 입력으로 받지 않았다.
  - 10/30에는 원인을 일반 헤드라인 하나로만 적었다.
  - 같은 밤 저자들은 모두 아마존 현금흐름·인텔 가이던스부터 썼다.
  - **수정(v59.56):** `US_EARNINGS` 입력을 더했다(`scripts/producer/earnings-context.mjs`).
    - 대상: 직전 미국 종가에 첫 거래일 또는 3거래일 안의 반응이 닫힌 실적
    - 순서: 그날 발표 → 시가총액 상위 → 반응 크기
    - 담는 것: 원문 수치, 가이던스, 보도된 이유
    - 같은 줄을 검증 문맥에 넣는다. 재사용 키에도 넣어 새 실적이 들어오면 다시 쓴다.
- **결함 2:** 신용 판정이 5·20거래일만 봤다.
  - 그래서 석 달 동안의 하위 등급 확대가 문장에 없었다: HY +55bp, CCC +308bp, IG +11bp(8/6 → 10/29).
  - **수정(v59.56):** 판정 규칙은 그대로 두고, 판정 문장과 근거 표에 60거래일 하이일드·CCC·투자등급 변화와 등급 간 분화를 붙인다(`creditDispersion`, 임계값은 `RULES.credit.widen60dBp`·`cccGap60dBp`).
  - **권장안으로 진행:** 판정 자체를 바꾸면 시나리오·국면 판정 전체가 함께 움직인다. 그래서 이번에는 문장으로만 알린다.

### 연결
- **실적 → 시황 해석:** 위 수정으로 연결했다.
- **신용 → 지식:** 새 판단 틀('진짜 산업 위의 레버리지', '주도주 교체와 강세장 끝을 가르는 세 조건')이 시장 상태의 신용 축·매크로 이익 전망·테마로 연결된다.
- **지식 → AI 채팅:** 새 틀 3개가 채팅 검색에 연결된다. 테스트 질의로 확인했다.

## 8. 텔레그램 — 시각 자료와 기관·증권사 자료

- **지금 읽는 것:** 공개 미리보기(t.me/s) 4개 채널의 캡션 글자. 글에서 뽑는 숫자는 목표주가·투자의견 변경, 실적 대 추정치(가이던스 상향·하향 방향), 경제지표 대 예상, 개인 순매수 목록이다. 14일 2,353건 중 글이 있는 것은 2,289건이다.
- **안 읽는 것:** 이미지(차트·리포트 캡처)와 PDF 본문. AI Worker가 비용 보호로 이미지 입력을 거부한다(P1421). 캡션이 있는 이미지 글은 글로만 셌고, 캡션 없는 이미지 글 64건은 0점이었다.
- **v59.56 반영:** 첨부 종류·수와 문서 파일명을 기록하고, 파일명을 분류 문장에 더한다. coverage에 첨부 글 수, 사진 글 수, 문서 글 수, 캡션 없는 이미지 글 수가 나온다. 다음 수집부터 읽지 못하는 시각 자료의 양이 숫자로 보인다.
- **권장 다음 단계:** 첨부 비율을 일주일 본 뒤, 점수 상위의 증권사 노트 이미지만 하루 상한(예: 20장)을 두고 AI로 읽는 생산자 단계를 제안한다. Worker의 이미지 차단을 푸는 일이라 비용 결정이 필요하다.
- **기관 포지셔닝:** CFTC 생산자와 포지셔닝 위젯은 소유자 요청으로 퇴역했다(P1628·A09). 텔레그램 'flows' 태그 글(14일 89건)은 참고 목록으로만 둔다.
- **증권사 리포트 본문:** 전문 재배포는 하지 않는다(P715). 숫자(목표주가·추정치)와 제목, 요약만 쓴다.
- **향후 가이던스:** 1차 원문은 SEC 8-K 실적 요약(event-briefs)이 담당한다. 텔레그램은 방향(상향·하향)만 보조한다.
