3. **금리 상승의 레버리지 경로 단계 판정** (2037281440543760681): SOFR 급등 → 국채 베이시스 변동성 → 결제 실패(FTD) 순서로 디레버리징 단계를 매긴다. 데이터: SOFR, 베이시스, FTD, 10y. 화면: 시장과 매크로. 반증: FTD 증가 시 '초기 단계' 판정 철회.
4. **주체별 수급 소진 판정** (2037776014529737104): CTA 순숏·리스크패리티 매도는 컸는데 개인·연기금 매도가 작으면 숏 스퀴즈 위험 구간. 데이터: CTA 포지션 추정, 주체별 순매수. 반증: 호재에도 반등 없음.
5. **바닥 확인 조건 + 시나리오별 내부 지표 예상표** (2036910022144229808, 보조 2038137330137989579): 200일선 위치, FTD와 직후 분산일, 돌파 종목 후속 상승률, 시장 폭, VIX. 매크로 시나리오마다 내부 지표가 어떻게 보일지 미리 적고 대조한다. 2038137330137989579는 '사전에 적어 둔 매도 조건 + 촉매 일정표' 방식을 더한다. 화면: 기술적 분석/오늘. 반증: FTD 확인 시 약세 판단 철회.
6. **효율 기술 충격의 수요 영향 분해** (2037056837527461911): 전체 절감 = 적용 대상 비중 × 절감률. 적용 단계(추론/학습), 대체 여부(대역폭), 제번스 효과, 검증 규모를 따지고, 하락 원인을 선행 불안·포지션·서사로 나눈다. 최종 확인은 스팟 가격. 데이터: DRAM/NAND 스팟, 상대 수익률 vs SOX, 업체 설비투자. 화면: 테마와 섹터.
7. **실적 급락 해부 + 논리 훼손 조건 명시** (2021669224087802294): 시장 우려에 이름을 붙여 하나씩 반박하고, 논리를 깨는 조건(제품 램프 일정)과 가격 지지(주간 50선)를 같이 둔다. 비현금 비용은 현금흐름과 분리. 화면: 종목.
