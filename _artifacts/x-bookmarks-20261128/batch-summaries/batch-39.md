# batch-39 요약

글 3개, 결과 3줄. 이미지 3개를 모두 열었다(열지 못한 이미지 0개).

## 집계
- 분야: 기술적 1, 수급·심리 1, 테마·산업 1
- durable: 2 (3개 중)
- Codex 판정: 원장 없음 3 (맞음 0 / 부분 오류 0 / 틀림 0)

## 가져올 만한 방법
1. **강세 후보 스크리너 + 2차 확인 체크리스트** (2085704780010152132)
   - 방법: 52주 저점 대비 70% 이상 위, EMA8>EMA21, 가격>EMA60, ADR≥4.5%, 30일 평균 거래대금≥1천만 달러로 후보를 고른다. 그다음 매출 성장≥20% 또는 EPS 성장≥50%(전년비), 테마, 손절이 분명한 진입점으로 거른다. 스크리너 결과는 후보일 뿐 매수 신호가 아니다.
   - 데이터: 종가, 52주 저가, EMA 8·21·60, ADR, 거래대금, 매출·EPS 성장률, 테마 분류
   - 화면: 스크리너(후보 단계와 확인 단계를 나눠 보여 줌)
   - 반증: 글에 없음. 화면에서는 통과 종목의 이후 성과를 기록해 검증해야 한다.
2. **산업별 신고가·신저가 집계로 시장 폭과 분열 읽기** (2085780044094292238)
   - 방법: 신고가 대 신저가 비율로 전체 폭을 본 뒤 산업별 건수로 주도 산업과 약세 산업을 나눈다. 둘이 함께 많으면 양방향 장세다. 상대강도 상위 종목은 200일선 부근 눌림을 지속 후보로 본다.
   - 데이터: 종목별 52주 신고가·신저가, 산업 분류, 상대강도, 200일선
   - 화면: 테마와 섹터(시장 폭 막대는 오늘이나 시장과 매크로에 둘 수 있음)
   - 반증: 글에 없음
   - 수치(2026-08-07): 신고가 73%(240건), 신저가 27%(88건). 신고가 쪽 1위는 반도체 754, 신저가 쪽 1위는 생명공학 376.
3. 두 글은 부딪히지 않고 이어진다. 1번은 개별 종목의 추세 조건이고, 2번은 그 종목이 속한 산업이 신고가 쪽인지 신저가 쪽인지 보여 준다. 스크리너 후보에 "소속 산업의 신고가·신저가 순위"를 붙이면 테마 확인 단계를 숫자로 바꿀 수 있다.

## 전달 방식에서 배울 점
- **조건 칩 줄 + 미니 차트 격자** (2085704780010152132 그림 1): 적용한 필터를 칩으로 한 줄에 드러내고, 결과는 같은 기간(6개월)의 일봉+거래량 소형 차트를 3열로 깐다. 225종목을 표보다 빨리 훑게 해 준다. 스크리너 결과 보기에 옮길 만하다.
- **비율 막대 한 줄 + 산업 카드 두 열** (2085780044094292238 그림): 맨 위 녹색·적색 비율 막대가 전체를 보여 주고, 아래 좌(신고가)·우(신저가) 카드가 히트 수 내림차순으로 "어느 산업에서"를 보여 준다. 같은 산업이 양쪽에 동시에 나오는 것(인프라 소프트웨어, 반도체, 항공우주)이 바로 보인다.
- 종목 칩 안에 횟수를 작게 붙여, 이름과 강도를 한 덩어리로 읽게 한다.

## 읽지 못한 것
- TradingView 스크리너 링크와 체크리스트 등록 페이지는 열지 않았다. 필터 조건은 그림의 칩으로 확인했지만, Perf % 필터 두 개의 값은 그림에 보이지 않는다.
- Highs/Lows 화면의 'hits' 집계 기간과 정의가 그림에 나오지 않는다.
- 2085282192041914416은 블룸버그 기사를 글쓴이가 요약한 것이고 원문은 없다. AI 데이터센터의 급격한 부하 변동이 변압기 수명, 전압, 고조파에 주는 부담을 다룬다. 글쓴이도 피해 규모에는 논쟁이 있다고 적었고, 수치나 판정 틀이 없어 durable=false로 두었다.
