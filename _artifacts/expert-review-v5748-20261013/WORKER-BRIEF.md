작성: 2026-10-13. 코디네이터: Claude (aio-64). 검토 4건(오늘·시장 상태 T01~T22, 거시·테마 M01~M22, 종목·스크리너 S01~S22, 포트폴리오·리서치·AI #1~#25)을 작업자 5명이 파일 소유권을 나눠 반영한다.

## 반드시 지킬 것

- **소유한 파일만 수정한다.** 다른 작업자 파일이 필요하면 바꾸지 말고 보고서에 "필요한 변경"으로 적는다.
- `index.html`은 여러 작업자가 각자 지정 구간만 고친다. Edit은 작게 나누고, 파일이 바뀌어 Edit이 실패하면 그 구간을 다시 Read한 뒤 재시도한다.
- **레거시 파일 줄 수 래칫:** `js/aio-chat.js`(8209), `js/aio-workspace.js`(2651), `js/aio-core.js`, `js/aio-data.js`, `js/aio-kr-data.js`, `js/aio-pages.js`, `index.html`은 줄 수가 늘면 CI가 실패한다. 순감소나 동일을 유지한다(한 줄로 합치기, 죽은 코드 제거). 확인: `node scripts/ci-decomp-hotspot-check.mjs`.
- **브라우저(Playwright·Chrome)를 띄우지 마라**(PC 메모리 16GB 공유). 전체 QA(`qa-runner full`)도 돌리지 마라. 코디네이터가 마지막에 한 번 돌린다.
- 실행해도 되는 것: `node --check <file>`, `node scripts/ci-esm-core-unit-check.mjs`, `node scripts/ci-architecture-contract-check.mjs`, `node scripts/ci-runtime-contract-check.mjs`, `node scripts/ci-control-char-check.mjs`, 그리고 고친 영역과 관련된 `scripts/ci-*-check.mjs`나 fixture. 데이터 생산 스크립트(`scripts/fetch-*`, `build-*`, `refresh-*`, `sync-*`)는 실행 금지다. 수정은 허용한다.
- 커밋·push·`record-fix`·`bump-version`은 하지 마라. 코디네이터가 한다.
- 결함을 고치면 가능한 한 실행 가능한 회귀 검사를 기존 검사 스크립트에 추가한다. 추가 위치 예: `scripts/ci-esm-core-unit-check.mjs`(ESM 도메인), `scripts/ci-review-integrity-unit-check.mjs`(포트폴리오), `js/aio-tests.js`(레거시).
- Windows: Python으로 파일을 쓸 때는 `newline=''`를 쓴다. node heredoc에서는 역슬래시가 사라지니 Edit 도구를 쓴다.
